# 音MADの映像の作り方（ネットで調べたこと、2026-10-31）

## 緩急と全体の構成
- 映像の切り替えは「音楽の山場」に合わせる。柴又は変わらないように見えて、音素が増える・猫の登場・賢者タイム・覚醒・余韻の山場ごとに映像が替わる（la_0274 の note）。
- レイアウトはおよそ8小節に1回替える（WRSG の分析）。人は同じ映像を長く見ると飽きる。ただし替えるほど前の映像を捨てることになり、山場とずれると盛り上がる所が減る。
- 1つ目の技にコマ落ち・イージングをかけ、次の技との差をつける（きゅうり流）。
- 音割れ・ハイスピードは盛り上がるが疲れるので、緩急をつけたほうがよい（scrapbox の DJ 系メモ）。決め所のある曲が映える。
- 段取り: 音を先に作り、小節ごとの行を作って素材・台詞の位置を穴埋めで決める → ラフコンテで構図を決める → 作りながら直す（unchikong の note、aviutl.info）。
- 「何の素材が鳴っているか」を映像で分かるように見せる。台詞の場面は人物を中央・手前に出す。

## 動きの技
- 揺れ: 拡大してすぐ戻す（イージング）、震えの強さを時間とともに直線で下げる、最初の数コマに一番強い衝撃（イージング23）、ブラーも同じ減衰。突然の強調として使い、すぐ収める（竹達アーカイブ通信）。
- キックに合わせて拡大すると、映像がリズムに乗って見える。レンズ補正もどきでゆらゆら揺らし、モーションタイルではみ出しを埋める（la_0274）。
- 点滅は手で置く。縁取りだけを残した絵を点滅に使う。
- シーンチェンジは回転型と拡大縮小型の2種を使い分ける（きゅうり流）。

## 色と質感
- 周辺ボケ・光量・色収差・トーンカーブ・コントラストを下げる。背景は情報量と明るさを落とす（ハーフトーン、乗算で重ねる）。

## 2号の動画で確かめたこととの照合
- Plasticookie の測定（1枚を10〜30秒持つ、区間ごとに地が替わる）は「山場で替える・およそ8小節」と合う。
- TECHNO MUSIC先輩・Dandelion は、地と窓を曲の進みに合わせて増やし、人物は後半まで出さない。
