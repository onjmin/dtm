# BB劇場の調べ物（2026-11-01、同日に測り直し）

所有者の bb1（「RRMの3分クッキング」）への指摘: **棒立ち・展開や構成に面白みが無い・下ネタが無い**。bb2（「二日酔い☆」）の後に「分析が足りない」「なの厨とか調べて」。最初の版は4本を2つの数（切り替え/分・動き）で見ただけで、台詞・音・視聴者の反応を見ていなかった。測り直した。

## 文献から
- BB劇場は BB素材（切り抜いた立ち絵や短い動画）を人形劇のように動かして話を作る型。淫夢の「BB先輩劇場」が元で、クッキー☆では「SIREN cookie」（sm20833820、2013-05）からジャンルになった（ニコニコ大百科「BBクッキー☆劇場」「BB先輩劇場」）。初期は1分未満の日常もの、後にバトル・ホラー・ほのぼの・社会派へ広がった。
- 区分: ほのぼの（最多）・泣ける・ホラー・バトル・従軍・映画的・漫画的（クッキー☆解説Wiki）。
- 話はキャラから作る。「キャラから脚本を貰う」（note、Nahl）。
- **なの厨（なの厨兄貴）**（ニコニコ大百科「なの厨」）: クッキー☆の BB を作る投稿者。名目は BB素材の配布で、その「使用例」の BBクッキー☆劇場がクッソ汚い（脱糞・放尿・飲尿・食糞・性行為）ため、投稿すると運営に消されるのが常。キテレツ大百科のアニメ素材を多く使う。似た作品には「なの厨チャレンジ」のタグが付く。掲示板では「きたない・くさい・あたまおかしいが揃っているが面白い」「雁木（真理）の源流」と言われる。原本はほぼ消えていて、残るのは他人の再投稿。
- **雁木真理**（ニコニコ大百科）: シュールで支離滅裂な BB先輩劇場の投稿者。「雁木チルドレン」と呼ばれる後続を生んだ。2015 年から月1本。

## 分かったこと
1. **割りすぎない。長く引いて見せる。** 伸びた本はカット 8〜25/分、ショットの中央値 1.4〜4 秒で、1割は 6〜11 秒そのまま見せる（引きの中で何人も同時に動く）。bb2 は 2.4 秒ごとに機械的に割り、6 秒を超える絵が一つも無い。前回「カットが足りない」とした結論は測り違いの上に立っていて、割る回数ではなく**割らずに見せる所と、割る所の差**が要る。
2. **クッキー☆の「場所」に乗る。** NYN の材料屋・ICG の菓子工房・UDK 邸・RU 姉貴の家など、界隈で決まった店や家がそのまま舞台になる（強盗☆・エアコン・知能テスト☆）。見る側は場所だけで誰の話か分かる。bb2 は淫夢の写真の地で、クッキー☆の世界が無かった。
3. **よく知られた型をなぞる。** 強盗☆は洋ゲーの強盗もの（ロード画面「NYNICG2」、監視カメラの REC 画面、WANTED の手配書に ¥114514・¥364364）、KFC→「KFJ」。なの厨は**キテレツ大百科**（題字「使用例」、場所の札「UDK邸」「HNS姉貴の家」、アニメの背景）、Skype の着信、偽の動画サイトの透かし。笑いの多くは「その型の中にクッキー☆の人が入っている」ずれから来る。
4. **大勢を並べる。** 1画面に 5〜10 人。脇に知らない人が混ざり、コメントは「誰？」を繰り返す（強盗☆で「誰？」が10回単位で何度も）。脇役が勝手に何かしているのが見どころになる。
5. **反応の山は筋の転び目と終わり。** 12本中5本は最大の山が最後の1割（ダッぷはント 250/255 s、強盗☆ 125/131 s、エアコン 70/79 s、なの厨系 120/123 s・315/337 s）。オチを最後に置き、そこで一番大きく転ぶ。火事☆は後半で笑いが消え「！？」「こわい」「正体表したね」に変わる（NYN が放火犯だったホラーへの反転）。笑いだけが反応ではない。
6. **絵と字で笑わせる。** エアコンは風で人が吹っ飛ぶ動き、すべり台は滑る動き。なの厨系では字幕「VIRTUALSEX」をコメントが復唱し、汚い所（「よりによって白いところで拭く」）で草が 34。台詞の中身より、目で分かる出来事が山を作る。
7. **なの厨の型**: 青地の BB素材を並べる配布パート → 「使用例」。キテレツ大百科の日常アニメの枠（題字・場所の札・夕焼けの橋）を借り、その中で排泄・性の汚い出来事を淡々とやる。モザイク、淫夢の実写の顔の差し込み、黒地の暗転。ほのぼのした器と中身の汚さの落差が芯。
8. **確かめて外したもの**: 「無音の間の直後に反応が来る」は、12本・1324 区間で直後の反応が平均の 1.03 倍（他は 0.97 倍）で、効いていない。

## bb2 に足りないもの（次に作るなら）
- 割る回数を減らし、**引きで長く見せる場面**（大勢が同時に動く）と、**ここぞで寄る場面**を分ける。
- 淫夢の写真でなく、**クッキー☆の決まった場所**（材料屋・菓子工房・誰かの家）を舞台にする。
- **知られた型を1つ借りる**（日常アニメ・料理番組・ニュース・洋ゲーなど）。中身は下ネタ・汚いネタで、器との落差で笑わせる（なの厨の型）。
- **脇役**を置いて勝手に動かす。
- 笑いは台詞より**目で分かる出来事**（吹っ飛ぶ・滑る・字幕の大写し・汚いもの）で作り、**最大の山を最後の1割**に置く。

分かったこと:
1. **「ウケる」は草だけではない。** 一番コメントが濃いのは 30 秒前後の一発合成（261〜358/分）で、中身は「は？」「！？」の困惑。型パロディと使用例は「88888888」（作りへの拍手）。どの型も終わりに「やったぜ」の合唱が来やすい。笑いの率（草・ｗ）は 3〜27% とばらつき、伸び方とは揃わない。
2. **型ごとに割り方が逆。** 本気の型パロディは元の映像の編集の速さをそのまま真似る（27〜42/分、モンタージュは 0.6 秒）。一発合成と使用例はほとんど割らず、1枚の絵を 13〜26 秒見せて合成のおかしさだけで持たせる。「何回割るか」は型の側が決める。前の節の「割りすぎない」は日常・番組ものにだけ当てはまる。
3. **借りる型は「よく知られた映像」。** サッカー日本代表の煽り映像、JOJO の OP とスタッフ名の字、薬物映画の「one week later」とモンタージュ（クッキー☆の牛乳と小麦粉を白い粉に見立てる）、テレビの CM、育児番組のいないいないばあ、おたより番組の黒板。元を知っている人ほど、ずれと再現の細かさの両方で反応する。
4. **一つのネタを最後まで押し通す。** 一発合成は 30 秒で1ネタ、型パロディも1つの型から外れない。筋を何度も転ばせる作りは少ない。
5. **シリーズになる人が強い。** ああああ（NYN の短い身体ギャグ5本）、しずかに（NYN と ICG の番組5本）は、場所と顔ぶれを固定して中身だけ替える。

次に作るなら、型を先に決めてから割り方を決める:
- 一発合成型: 30 秒・1枚の絵・ほぼ割らない。困惑を狙う。
- 本気の型パロディ型: 元の映像の編集の速さと字の出し方まで真似る。拍手を狙う。
- 日常・番組型（bb3 はこれ）: 決まった場所・長回し・シリーズにできる形。
