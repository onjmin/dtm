# 台詞イントネーション作曲の作り方（作例の実測にもとづく）

> **2026-10-28 夜: 作者本人の手順（ももも味「台詞イントネーション作曲、台詞からメロディーを作るのってどうやってる？」moaji, 2021-12-24）**
> 1. BPM を決める（♩=100〜130 を好む。1拍に最大4モーラ＝16分）。
> 2. 普通の音MADと同じ台詞合わせ（タイムストレッチ）でリズムを先に済ませる。
> 3. Melodyne で**モーラ単位に音程を補正**して十二平均律へ合わせ、MIDI に採譜してシンセで鳴らして確かめる。
>    音階は**ペンタトニック（ヨナ抜き）を多用**（全音階はメジャーの4・7度、マイナーの2・6度がトライトーン・アボイドの原因になりやすい）。
>    **台詞の最後の音を主音にしたスケール**を選ぶ（B♭で終わるなら B♭マイナーペンタ）。半音が欲しければヘキサトニック。
>    抑揚に厳密に従わなくてよい。リードシンセにグリッサンド・ポルタメント。
> 4. コードは**メロディーから付ける**（ペンタ由来の旋律はダイアトニックコードで完結させやすい）。先にコードを組むこともある。
> 5. 構成（素材が少なければループと工夫で尺を伸ばす）。
>
> → 私の「声に音程補正なし」（セント分布が生の台詞と同じ）は誤り。Melodyne は音の中心だけを動かし揺れを残すので、フレーム単位のセント分布では見分けられない。
>
> セリフ合わせのコツ（scrapbox lec-a「セリフ合わせ」）: 長い子音（t/s/z）は格子を中心に前後へ散らし母音を格子へ／前の母音から本体の母音までの距離が音素の聞こえに効く／強拍に強い音（間を埋めるときは弱拍）／息継ぎ後の母音は1単位後ろへ／繋ぎ目は強いドラムの位置／音程変更は ±3 半音が限度・上昇下降の向きを揃える／伸縮は言葉の区切りで切って伸ばすとハキハキする／三連は多用しない。
>
> 評論（ニコニコ大百科・o390mmhg・nazomem）: 魅力は「不自然なピッチの変化もなく」声と曲が合うこと、台詞そのものから曲を作るので歌モノに聞こえる（旋律重視の聴き手向き）、ストーリー構成。作り手が少なく知名度が低い・作曲技術が要る、が課題。

> **訂正（2026-10-28 後半）**: 下の「拍頭へは寄らない」「声に音程補正なし」は誤り。
> - R4（位相の集中度）は、立ち上がりが4つの16分位置に均等だと0になり、拍頭に乗る点があっても検出できない。位置ごとに数えると、拍頭は めめめ 32% / Okaeshi 34%（偶然25%）、強い音節の上位25%では めめめ 50%（beat_hist.json）。
> - 元配信（YouTube pHgl3vGfYkE）と DTW で照合すると、曲の台詞は元の 1.15〜2.05 倍に**不均一に**引き伸ばされ、台詞により 0〜+1.5 半音**移調**されている（src_compare.json）。「無補正」と言えるのは、1音ずつ半音へ吸着させる補正が無いことだけ。
> - 自作 v2 の配置は、台詞を前の台詞の後ろへ16分1個空けて連ねただけで、小節・拍と無関係だった（BPM に合って聞こえない原因）。

作例: sm34094775「めめめのサイコロが！」（ももも味, 2018, 132.5BPM）、sm38275737「Okaeshi」（同, 2021, 120.2BPM）。
音源は refs/（yt-dlp で取得、gitignore）。声は Demucs（htdemucs）で分離。めめめは inst 版（SoundCloud araittt/off24bit, 完成版より +312ms）も使用。
測定スクリプト: ref_extract.py / ref_analyze.py / ref_pcshift.py、結果 ana_meme.json / ana_okaeshi.json。

## 1. 実測でわかったこと

| 項目 | めめめ | Okaeshi | 生の台詞（エア本） | 偶然・でたらめ |
|---|---|---|---|---|
| 声の音高の半音からの平均ずれ | 23.2 セント | 20.7 | 23.2 | 25 |
| ±15 セント以内の割合 | 0.33 | 0.43 | 0.36 | 0.30 |
| 音高が46ms平らに留まる割合 | 0.37 | 0.39 | 0.35 | — |
| 伴奏のチューニング | +4 セント | 0 | — | — |
| 音節の立ち上がりの16分への偏り R16 | 0.39 | 0.54 | — | 0.04 |
| 同 8分 R8 / 拍頭 R4 | 0.11 / 0.06 | 0.09 / 0.11 | — | 0.04 |
| 声の音名が伴奏の上位3音に入る率（ずらし0） | 0.41 | 0.38 | — | 他のずらし 0.14〜0.36 |
| 声の音名が変わった直後の伴奏のその音の増え方 | −0.001 | +0.004 | — | 0 |

読み取り:
1. **声に音程補正はかかっていない**（めめめは生の台詞と同じ分布。Okaeshi はわずかに半音寄り）。
2. **伴奏のチューニングも動かしていない**（A=440 のまま）。台詞の音高は半音から平均 20〜23 セントずれたまま鳴っている。
3. **音節の立ち上がりは16分グリッドに強く揃えてある**が、8分・拍頭には偏らない。16分のどこからでも入る（シンコペーションが多い）。
4. **伴奏の和音は声の音高に合わせてある**（ずらし0で一致が最大）。ただし伴奏は声を1音ずつ追っていない（句の下で和音を保つ）。
5. テンポは 120〜133BPM。16分≒1モーラ（話速 8〜9 モーラ/秒）に近い。
6. 声はほぼ途切れない（声のある時間 約 69%、分離した声の音量が −30dB 以上の時間 96%）。

## 2. これまでの試作との違い

| 項目 | 作例 | 私の試作 |
|---|---|---|
| 声の音高 | 原音のまま | WORLD で音階へ固定（v1〜v5） |
| 立ち上がり | 16分へ揃える、拍頭へは寄せない | v1〜4: 16分へ丸め（近い）。v5: 句頭を拍頭へ（逆） |
| 和音 | 声の音高から付ける、句ごとに保つ | v1〜2: 固定2コード。v3〜5: 小節ごとに歌へ合わせる（近い） |
| テンポ | 素材ごと 120〜133 | 150 固定 |
| 曲の型 | 素材ごと | 全曲同じ（構成・音色・王道寄せ） |

## 3. 作り方（実測に合わせて改めたもの）

1. 素材の台詞を句で切る（whisper で中身確認、整列で音節位置）。
2. テンポは素材の話速から決める（16分≒1モーラ）。
3. 音節の立ち上がりを16分へ揃える。**声の音高は変えない**（時間方向の切り貼り・伸縮だけ）。句頭を拍頭に寄せない。
4. 揃えた声の音高（補正しない値）から、句ごとに和音を選ぶ。声の音名が和音の構成音かテンションになるもの。伴奏は1音ずつ追わない。
5. 伴奏の旋律は声と別に作ってよい（めめめでは別曲のサビ編曲が高音パートで並ぶ）。
6. 構成・音色・ノリは素材ごとに決める（全曲共通の型を使わない）。

## 4. まだ測れていないこと

- 16分へ揃える方法（音節ごとに切って置くのか、句ごと伸縮か）。原素材（めめめの桃鉄実況 YouTube pHgl3vGfYkE）と照合すれば分かる。
- 伴奏の和音の種類（ダイアトニック中心か、テンションが多いか）。採譜が要る。
- 台詞の選び方・並べ方の規則（何を繰り返し主題にしているか）。
