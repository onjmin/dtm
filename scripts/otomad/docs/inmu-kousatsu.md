# 淫夢についての考察（音MAD の素材として）

出典: ニコニコ大百科「真夏の夜の淫夢」「淫夢語録」、Wikipedia「真夏の夜の淫夢」、note「オンライン空間の文化とその実践に関する人類学的考察―『淫夢』を事例として―」、word-dictionary.jp「淫夢」、note「淫夢ネタとは何か？その歴史と問題点を整理する」。

## 1. 成り立ち

- 元は COAT の BABYLON シリーズ『Babylon Stage 34 真夏の夜の淫夢 ～the IMP～』（2001）。2007 年にニコニコ動画へ転載され、2008 年ごろから MAD の素材になった。
- 今の「淫夢」は1作品の名前ではなく、国内のゲイ向けビデオ（COAT・ACCEED・サムソン など）の出演者と台詞の総称。出演者は「淫夢ファミリー」と呼ばれる。
- 台詞は「淫夢語録」として、元の場面から切り離してどんな状況にも当てはめる言い回しになった。

## 2. 何が面白がられているか（素材の性質）

- **語録の汎用性**: 短く、言い切りで、文脈を選ばない台詞ほど広まる（「やりますねぇ」「そうだよ（便乗）」）。種類の多さと汎用性の高さが特徴とされる。
- **空耳**: 聞き取りにくい発声を別の言葉に聞き替える（「ジャッキーチェン」「ドアラ」「アイーン」）。空耳は語録そのものになる。
- **棒読み・素人の演技・迫真**: 台本を読む素人の声の不自然さ・場違いな熱演が笑いの元。括弧注釈（迫真）（震え声）で受け手が演技を評する文化がある。
- **内輪の合図**: 知っている人だけが分かる言葉として、共同体の内外を分ける。
- **背徳感**: アダルト作品が出どころであること自体が拡散の一因とされる。

| 系統 | 主な素材 | 声・演技の傾向 |
|---|---|---|
| COAT / BABYLON（本編） | 第1〜4章（TNOK・野獣・KMR・MUR）、迫真空手部・迫真相撲部 | 若い男性の素人演技。台詞が短く語録化しやすい |
| サムソン | ガバ穴ダディー・課長壊れる・現場監督・ケツデカ課長 | 中年男性。喘ぎと空耳が中心 |
| ACCEED | ゆうさく（配達・現場作業員・ウリセン…） | 業務の言い間違い・丁寧語 |
| KBTIT（拓也） | ごちゃまぜ・インタビュー・ラグビー… | 調教師の口上、ドスの効いた命令口調 |
| 関西クレーマー（カーリー） | 心臓マッサージ・寿司職人・ルームサービス・優しいクレーマー・料理人解体ショー | 関西弁のクレーマー役。同じ演者が毎回同じ型（理不尽なクレーム→和解）を演じる |
| その他・ノンケ | aiueo700・Syamu・QVC福島 など | 一般人の配信・通販番組 |

## 4. 曲作りへの示唆

- **素材の一貫性**: 同じメーカー・同じシリーズ・同じ演者でそろえると、声質・録音の質・演技の型・世界観がそろい、曲として一つにまとまる（サムソン3本の例）。系統をまたぐと寄せ集めに聞こえる。
- **台詞の選び方**: 知られている語録・空耳を核にし、その系統で「型」になっている台詞（クレーマーなら 苦情→謝罪→和解）で流れを組む。
- **扱わないもの**: 暴力や虐待の場面・子どもとして描かれた人物の素材。性的な語・下ネタの素材は使ってよい（所有者 10-31）。出演者は実在の人で、差別的な笑いとして批判もある（Wikipedia・研究者の指摘）。素材は手元だけで使い、公開物や git に入れない。
