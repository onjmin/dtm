# 2号兄貴（2号.）の作風の考察

出典: ニコニコ大百科「2号兄貴」、Yahoo!知恵袋、note「2号.兄貴リスペクト界隈(界隈曲)について」（Cvmber50mE）、Enpedia。音の実測は docs/research/kaiwai-lineages.md（他の方の耳コピ8曲を比較群59曲と比べたもの）。所有者の言葉:「淫夢の汚い素材で裏に流れている曲がいいのが2号スタイル」。

## 1. 立ち位置

- 2012〜2016年ごろのニコニコの音MAD職人兼作曲家。膳・淫夢・クッキー☆の MAD が中心。代表曲「Amber」「柴又」。作風を真似た「リスペクト界隈曲」が多数ある。
- **素材だけ借り、曲は自作する**。既存曲に台詞を合わせる普通の音MADとも、台詞から旋律を作る台詞イントネーション作曲とも違う。
- 面白さの核は**落差**: 汚い・下品な淫夢素材の裏で、セブンスの効いたおしゃれで耳に残るテクノが鳴っている。曲が主役で、台詞は合いの手・味付け。

## 3. 台詞イントネーション作曲との違いと、作り方への示唆

- 2号スタイルでは**曲（手書きの旋律と和音）が先で主役**。台詞は曲を邪魔しない所に、拍に合わせて短く打ち込む。台詞を旋律にする必要はない（音程は調に寄せて濁らせない程度）。
- 曲の質を上げるのは: 手書きのペンタトニックのリード（16分と3連、休まない、4小節の動機を ABAB で回す）、セブンスと 2-5 の進行（2拍ごと）、145BPM の4つ打ち、セブンスのブロック和音の刻み。
- 素材は1系統にそろえる（[otomad-material-consistency]）。汚さ・下品さが落差を生む。性的な語・下ネタは使ってよい（所有者 10-31）。暴力・虐待・子どもとして描かれた人物は扱わない。
