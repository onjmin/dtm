## 作り方の手がかり（コメントから）

### 道具は無料ソフトだけ

コメントによると、使っているのは次のとおり。
- **REAPER**: 題名「真冬の夜の神社.RPP.bak」、コメント「reaper でDTM」。
- **VocalShifter**: guitar.mp4 のタグとコメント。
- オリジナル曲集では「使われている音源・ソフト等がすべてフリー」と書かれている。

### guitar.mp4（2015）＝ 声をギターにする手順

コメントから読める流れ:
1. 「ンアー」を一定の高さで伸ばす。
2. VocalShifter で旋律のリズム・音程に合わせる。
3. 何度も複製して重ねる（「copy copy copy」）。
4. 歪ませてギターにする（「歪み先輩」）。

画面は作業画面と文字の説明で、コメントでは「迫真技術部 音MADの裏側」と呼ばれている。

### 表情をつけられた歌声.mp4（2016）＝ 台詞から歌を作る

クッキー☆の声で「今日もいい天気」を歌わせている。画面には発音記号が出るらしい。
- コメントに「/ɾù/」「/ɾú:ù/」「tænki」「発音記号兄貴」「中国語の発音講座かと思った」とある。
- 声調の記号（ù ú）は音の高さを表している。
- 「最近のボイロ界隈で使われる技術」「iからaの息は不自然すぎだろ」というコメントもある。

台詞イントネーション作曲と一番近い作品で、**音の高さを文字で見せる**という映像の作りの手本になる。

## 映像の作りの共通点（推定）

- 素材の動画を切り貼りする作りではない。文字・作業画面・実写・図で見せている。
- 講座の4本はどれも「テキスト見本」（文字で説明する見本）。
- 説明文は「初投稿です」だけで、題名は素っ気ないファイル名風（.mp4・.zip・.RPP.bak）。

## 私たちの MAD 動画への示唆

- 素材の映像がほとんど無くても、2号式は成り立つ。文字と図が主役でよい。
- 台詞イントネーション作曲では、**モーラごとに音の高さの位置へ字幕を出す**のが、「表情をつけられた歌声」の発音記号の見せ方にあたる。
- 他人の絵（東方のイラストなど）は要らない。著作権の点でもこちらが安全。

## unj-reze の音MAD 機能（OtomadMaker）を使うか

結論: 使うのが妥当。ただし、字幕（文字）の層だけは unj-reze に足す必要がある。

**そのまま使える所**
- 時間軸が dtm の MML（1小節 = 192 ステップ、BPM は 1 つ）。台詞作曲も、同じ形式の song.mml を DAW から書き出している。
- 生の台詞と刻みは16分の格子に置いているので、ステップに直しても時刻はずれない。
- song.wav を backing に置き、映像用のトラックを muted にすれば、絵だけを曲に合わせられる。
- 演出（zoom・shake・flash など）、場面転換、画面構成の型、音の高さで窓の縦位置を変える pitchY、mp4 の書き出しがすでにある。
- 素材は IndexedDB に置かれ、mp4 をローカルに書き出すだけならどこへも上がらない。

**足りない所**
- 文字の層。モーラごとの字幕を音の高さの位置に出す仕組みが無い（設計書でも「余力」扱い）。
- 時刻表から manifest を作る口が無い。Python 側で OtomadManifest の JSON（MML・素材・トラック・backing）を書き出し、エディタの「JSON を読み込む」で開く。
- 動画素材は約60秒（1800コマ）を超えると fps が落ちる。絵と文字が主なら影響は小さい。

### 共通点

- **中央に1つの窓か対象**を置き、周りは模様・万華鏡・幾何学の地で埋める。
- 地と窓は曲の構成に合わせて増え、変わる。人や台詞の主は、最初は隠し、後半で出す（TECHNO の顔、Dandelion の板の増え方）。音の作りと同じ「隠してから落とす」。
- 色は1曲ごとにほぼ1系統（TECHNO は紫・青、amber は暗い赤、曲集は曲ごとに単色）。
- 講座（2015〜2016）は、黒地に白い明朝の見出しと作業画面だけ。音の高さは VocalShifter の線そのものを見せている。

### 台詞イントネーション作曲の動画への示唆

- 「表情をつけられた歌声」の型がそのまま使える。黒地に白い明朝で台詞のモーラを、音の高さの位置に出す。VocalShifter の線の代わりに、補正前と補正後の音程の線を重ねて描く。
- 絵が要るのは中央の窓1つだけ。周りは幾何学・万華鏡で埋めてよい（OtomadMaker の mirror・敷き詰め・円形回転の型で作れる）。
- 生の台詞を隠す区間は、窓を幾何学だけにしておき、最後のサビで話者の絵と字幕を出す。
