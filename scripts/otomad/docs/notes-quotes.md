# 台詞イントネーション作曲 試作2「エア本語録」

## 狙い（1文）

有名な語録だけを元の話の順に並べ、1モーラ＝16分・抑揚＝旋律のまま歌わせる。短い語録は2回続けて叩きつける。

## 振り切る軸

1. **モーラ＝16分の機関銃**（試作1と同じ）。語録の言い回しは変えず、置き場所だけグリッドへ。
2. **語録だけで物語を組む**：つなぎの台詞を入れない。電話（もしもしっ）→ 驚き（イ゛エエエエ）→ 決め台詞（自分らしく輝いていく仏法）→ 歓喜（面白かったねー）→ パーン で終わる。

## 普通にしておくところ

- 2コードの往復、4つ打ち、150BPM。
- 前奏は「ンーーーー」「ワンツーワンツースリー」をそのままカウントに使い、ドラムは入れない。
- フックは「シャバダバッタバ×3 → Foo☆」。

## 試作3（「もっと良い曲」への手直し）

声の扱い（2軸）は変えず、伴奏だけを「普通に良い」水準へ上げる。
- 和音は2コード固定をやめ、小節ごとに声へ合う三和音を選ぶ（王道進行 IV–V–iii–vi の流れを優先、区間の終わりは V、最後は I）。
- 区間ごとに密度を変える：前奏（パッドのみ）→ A（キック・ベース）→ フック（全部＋クラッシュ）→ B → ブレイク（キック抜き）→ 盛り上げ（スネアロール）→ 最終フック → パーン。
- 裏拍オクターブベース、裏拍のコード刻み、16分アルペジオ、フックで「シャバダバ」をシンセが重ねる。ステレオと残響。
