# 淫夢 × TECHNO MUSIC先輩型 1（techno1、2026-10-31）

狙い（1文）: 野獣先輩の「これもうわかんねぇな」の抑揚から起こした1小節のリフを、同じ野獣の叫び「アアッ」で作ったシンセに最初から最後まで弾かせ（反復の一点張り）、元の台詞と顔は41小節目まで隠して落とす。

## 参考元で測ったこと（YouTube の再掲 3JhmS-SIkOQ → refs/nigo/sm16432546_yt.mp4、コメント無し）
- 切り替え毎分1.4回。3分半を1つの場面で通す。動き（コマ差）は 2.5（Plasticookie の本編より小さい）。
- 黒地に放射状の扇形の円盤、紫・青・桃。中心に多面の円。扇は音に合わせて伸び縮みし、拍で回る。
- 明るさ: 0〜30秒は暗い（5〜15）→ 36秒で一気に明るむ（51）→ 以後 30〜45。音量はほぼ平ら。
- 人物: 20秒ごろから中心の円に顔が1コマずつちらつく（8分ごと）→ 82秒で顔が円盤いっぱいに出て回る → 144秒から人物を円周に並べた万華鏡（動きが最大 14〜19）→ 終盤は万華鏡の中心に顔。

## 作り（techno1_build.py・techno1_video.py）
- 124 BPM、A マイナー、80小節（約2分35秒）。伴奏まで Python（自前のキック・クラップ・ハット、ノコギリのベースとパッド）。
- リフ: 「これもうわかんねぇな」を16分へ伸縮 → モーラごとに A マイナーペンタ → 採譜（無声のモーラは直前の音で埋める）。1小節10音。叫び「アアッ」の母音を WORLD で各音へ合わせ、tanh で歪ませる。前奏はローパスを 350→2500 Hz へ開き、抜きで絞って開き直し、終わりで閉じる。
- 和音はリフから: リフ全体に一番よく入る2つ（Am7・Dm7）を2小節ずつ往復するだけ。
- 素材の pyin がほぼ全部を無声と読む（雑音が多い）ので、モーラの音程は harvest で取り直した。plasti2 の一転攻勢の野獣の台詞も同じ理由で補正が効いていなかった可能性がある。
- 構成と緩急: 前奏（暗い・リフだけ）→ 9小節キック → 17小節パッド・クラップで明るむ → 25小節「こ」の声打楽器と16分 → 40小節目後半を空けて「こ」のどもり → **41小節目に生の「これもうわかんねぇな」（リフの元）と顔** → 生の台詞を2小節ごと（おまたせ・こ↑こ↓・しょうがないね・大丈夫でしょ・曇ってきたな）→ 57小節 抜き（キック無し、ノイズの上昇）→ 65小節 山（16分のベース、飽和を強める、+4 dB）→ 77小節 閉じて最後に生の台詞1本。
- 生の台詞は伴奏の −6 dB。測定: 句頭の拍頭率 1.0、強い音節の拍頭率 0.68、抑揚 同じ14／平ら3／逆0、旋律が和音に入る率 0.64（台詞の音は和音の外も多い。合否には使わない）。
- 映像: 切らない。扇の数を区間で 3→4→5→6→8 と増やし、明るさを区間で上げる（前奏 0.12 から）。キックで 4.5% 拡大、41・65小節目の頭に減衰する揺れと白飛び2コマ。BB は顔（フェイスBB）と立ち姿（ゲス顔）だけ、紫に染める。
