# サムソン × 2号式 2（samson2go2）

## 狙い（1文）

samson2go1 が良かった3点に振り切る。旋律はペンタトニックだけで跳ね、リズムは付点・3連・16分・長い音を混ぜる。声（「センチメンタル」の母音）でもう1本のリフを弾かせ、曲の中に覚えられる旋律を2本置く。

## 振り切る軸

1. **ペンタの跳躍と変化するリズム**: サビは C マイナーペンタ（C E♭ F G B♭）だけ。3度・4度で跳ね、付点8分・16分・3連・6〜8個ぶんの伸ばしを1小節の中で混ぜる。G7 の上は G と F だけを踏む。
2. **声のリフ**: Aメロとイントロは、母音シンセが和音の音を「2・1・2・3｜2・2・1・3」の切り方で跳ねるリフを弾く（samson2go1 の 3・3・2 とは別の切り方）。

## 声の楽器と台詞

- 刻み（元の波形を PSOLA で）: サビの伸ばしの下に「くるくる」、2回目のAメロの句末に「シュタイナー」。
- 打楽器: 「てゐー！」の「て」をスネアに。
- 生の台詞（PSOLA、少なく後半へ）: 16小節 Do it!（サビへ）、41〜47小節 あ… → あい… → あいた… → あいたたた、61小節で曲を切ったあと 最高ォ～ッ！、63小節 すごいよー。

## 普通にしておくところ

- C マイナー、152BPM、64小節。
- Aメロ: A♭M7｜G7｜Cm7｜B♭7（1小節1和音）
- サビ: Cm7 B♭7｜A♭M7 G7｜Fm7 B♭7｜E♭M7 G7（2拍ずつ。最後のサビの終わりは Cm7）
- ブレイク: Fm7｜Gm7｜A♭M7｜G7
- 4つ打ち・16分ハット、8分オクターブのベース、エレピの裏打ち、サビのグロッケン。
- リードは −1 dB、声の楽器は −4 dB、生の台詞は −6 dB。
