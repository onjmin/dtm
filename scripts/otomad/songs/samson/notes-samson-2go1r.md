# サムソン × 2号式 リメイク（samson2go1r、2026-10-31）

## 狙い（1文）

samson2go1 の伴奏・リード・声の楽器は1音も変えず、「性的な語を使わない」で伏せていた代表の空耳（オッパゲドン・おまんこロックマン・気持ちんぽ・サイコガン・しゃぶりTIME・オッパラディン）を解禁して、生の台詞を14→28か所に増やし、ブレイクは台詞を和音へ合わせてつなぐ主旋律にする。

## 振り切る軸

1. **台詞の物量**: 2回目のAメロから最後まで、2小節に1つ以上の台詞が途切れず落ちる。最後のサビは毎小節。
2. **ブレイクで台詞が歌う**: 41〜48小節はリードが無いので、台詞を主旋律として隙間なく並べ、音の中心をその時刻の和音（半音で下がるセブンス）の音へ寄せる。47小節の「アア～～～」を伸ばして、49小節の頭に「きもちんぽ」の「き」を落とす。

## 変えないところ

- daw.json・acc/lead の録音・vinst.wav は samson2go1 のまま（samson2go3 の教訓: 作り方を変えると良かった所も失う）。
- イントロ1〜8小節は台詞なし。生の台詞は伴奏の −6 dB。

## 作業

- `samson_2go1r_build.py` → `samson2go1r/`（vraw.wav・placement.json・check）。mix は `samson2go_mix.py` をそのまま使う。

- Aメロ1（11・15）: 怖いねぇ・ちょっと待っててや → 16.5 Here we go!
- サビ1（20・24）: オッパリヤ・おまんこロックマン（リードの伸ばしの下）
- Aメロ2（25.5〜31）: しゃぶりTIME・ペロペロ舐めち・シーチキンがほしい・オッパラディン
- サビ2（34〜40）: サイコガン・気持ちよくしちくり・細菌入っちゃう・我慢できない

- 最後のサビ（51〜63）: ジャッキーチェン・ハイチュウ・ロックマン・ドアラ・入っちゃう×3・delight・いっぱい入っちゃ・最高ォ～ッ

## 測った値（合否ではなく目安）

句頭の拍頭率 0.81、強い音節（上位25%）の拍頭率 0.87、抑揚の上下 同じ56／平らになった35／逆0、ブレイクの和音との半音衝突 2/28 モーラ、生の台詞が鳴っている時間 51%（samson2go1 は 16%）。整列図は samson2go1r/align.png。47小節後半の 0.9 秒の空きは「アア～～」の前の息継ぎとして残した。

## 高い音を控えめに（2回目、所有者の指示）

- リード: ノコギリ波 → Flute、G6 より上は強さを段々下げる（D7 で 74/127）。混ぜる量は −1 → −2 dB。
- グロッケン → 1オクターブ下の Celesta（強さ 90）。旋律・和音・リズムは変えていない（`samson2go1r_daw.py`）。
- 伴奏とリードは録り直し（scratch/speech-songs/samson2go1r → samson2go1r/ へ写す）。
- 測定（サビ1）: 2 kHz 以上 −12.1 → −21.4 dB、リードの重心 2435 → 1150 Hz、リード−伴奏 −8.5 → −11.9 dB。最後のサビの完成音源で 2 kHz 以上 −12.8 → −18.3 dB。
- 【直し】1回目の書き出しはリードが約 1.0 秒早かった（伴奏の回だけ録り始めが 1.04 秒遅れ、samson2go_mix.py は伴奏の位置でリードも置くため）。リードは lead.npy の最初の音で別に時刻合わせ（+1.009 秒、さらに +20ms）→ lead_al.wav。16分格子への位相は伴奏 20.2・リード 17.9・声の楽器 20.2 ms でそろった。
- 評価: 使う（2026-10-31、リードの時刻を直した版）。
