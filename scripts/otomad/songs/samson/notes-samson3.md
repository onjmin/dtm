# サムソン3：くるくるチェン大狂詩曲 (Samson 3: Kurukuru Jackie Rhapsody)

## 1. 意図（1文）
低音域の日常的な会話型スタッカート詠唱から、サビで1オクターブ跳躍するペンタトニックの疾走旋律へと急展開し、最後はE7(♭9)の導音G#から主音A（Am9）への完璧な終止で解脱する、落差と和声のカタルシスに振り切った台詞イントネーション歌唱曲。

## 2. 振り切る2つの極端な軸

### 軸1: 極端な音域・抑揚コントラスト（低音語り詠唱 vs オクターブ跳躍ペンタ飛翔）
- **Aメロ（第9〜24小節）**:
  日常会話のボソボソとした低音域（MIDI 57〜62 / A3〜D4）に音程を揃え、16分グリッドのスタッカート詠唱（「怖いねぇ」「ちょっと待っててや」「あいたたた」「だめだめだめ」等）として平坦かつリズミカルに推進。
- **サビ（第25〜40小節、第49〜60小節）**:
  一転して1オクターブ上の高音域（MIDI 69〜76 / A4〜E5）へと跳ね上がり、「くるくるくるっ、くるっ！」「ハイチュウハイチュウ」「ジャッ！キー！チェンッ！」の空耳フレーズが鮮やかに舞い踊る。Lead 1（square）およびチェレスタ（Celesta）の16分アルペジオが旋律を全面バックアップ。

### 軸2: 和声のカタルシスと終止（王道セブンス進行と完全終止）
- **サビの王道進行（第25〜40小節）**:
  FM7 → G7 → Em7 → Am7（4-5-3-6王道進行）および FM7 → G7 → E7 → Am7（副ドミナント導音）の豊潤な7th和声の上に、台詞イントネーションのモーラ音程を厳密に接着。
- **第63〜64小節の劇的な完全終止（The Grand Cadence）**:
  第61小節の Dm7、第62小節の G7→C→FM7 を経て、第63小節で Bm7♭5 から E7(♭9)（導音 G# を含む強い緊張のドミナント和音）へ突入。そして最終小節である第64小節の1拍目頭（ステップ0）で主音 A（MIDI 69）と同時に Am9（A, C, E, G, B）が全音符で炸裂し、すべての緊張が快感へと昇華する完璧な完全終止を迎える。

## 3. 楽曲スペック
- **素材**: サムソン 25素材（ガバ穴ダディー・課長壊れる・現場監督2 より厳選、性的語句ゼロ）
- **手法**: 台詞イントネーション作曲（Praat PSOLA再合成によるフォルマント・子音保持、16分グリッド吸着、Amペンタトニック音程補正）
- **調**: A minor (Am)
- **テンポ**: ♩=126 BPM
- **小節数**: 64小節
- **伴奏トラック**: 豪華7トラック（Lead 1, Synth Bass 1, Synth Bass 2, Pad 2, Electric Piano 1, Celesta, Lead 2）＋ 4つ打ちドラム（four_clap_16hat）

## 4. 構成と大胆な選択が現れる小節
- **第1〜8小節（Intro）**: Pad と EP のファンクな16分裏拍コンピングで静かに開始。「どぅーいっと！」「ヒアウィーゴー！」の煽りから、第5小節で4つ打ちドラムとベースが突入。
- **第9〜24小節（Verse A1）**: 【軸1の実証】低音域（57〜62）のスタッカート語り詠唱。日常会話の抑揚を活かした16分ハキハキ進行。
- **第25〜40小節（Chorus B1）**: 【軸1・軸2の実証】一気にオクターブ跳躍（69〜76）。FM7–G7–Em7–Am7 王道進行に乗せて「くるくるくるっ」と「ハイチュウ」が駆け抜け、「ジャッキーチェン」で最高音 A5 へ突き抜ける。
- **第41〜48小節（Interlude）**: ドラムとベースのファンキーなブレイク。「アイーン」「ドアラ」「シュタイナー」「象課長」「アーチャー」「ゴリラ」の矢継ぎ早な合いの手と、Lead 1の上昇オブリガートがE7sus4→E7へと緊張を高める。
- **第49〜64小節（Chorus B2 & Finale）**: 【軸1・軸2の極限】Lead 2（sawtooth）が1オクターブ下でユニゾン参戦し、最高潮の音圧に。
- **第63〜64小節（The Grand Cadence）**: 【軸2の頂点】Bm7♭5 → E7(♭9) の導音 G# から、第64小節1拍目の Am9 完全終止（Root A）へ美しく着地。
