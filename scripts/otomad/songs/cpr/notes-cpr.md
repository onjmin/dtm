# 関西クレーマー（カーリー）× 2号スタイル

## 狙い（1文）

カーリーの理不尽なクレームの台詞の裏で、手書きのペンタトニックのリードが休まず走るセブンスのテクノ（145BPM）を鳴らし、「汚い素材×おしゃれな曲」の落差で押し切る。

## 振り切る軸

1. **手書きの走るリード**: F マイナーペンタ（F A♭ B♭ C E♭）だけで、16分と3連の動機を4小節ブロックで ABAB に回す。ブレイクの4小節以外は休まない。最後のサビは全音上（G マイナー）へ転調。
2. **全部セブンスの2拍和声**: Aメロ Fm7–B♭m7｜E♭7–A♭M7｜D♭M7–Cm7｜Fm7–C7、サビ D♭M7–Cm7｜B♭m7–E♭7｜A♭M7–Gm7♭5 C7｜Fm7（ⅣM7・2-5・短調の 2-5-1）。

## 普通にしておくところ

- 素材は関西クレーマー（カーリー）欲張りセットだけ（ルームサービス・寿司職人見習い・心臓マッサージ・優しいクレーマー・料理人解体ショー）。同じ演者の同じ型（苦情→謝罪→和解）で流れを組む。
- 台詞は合いの手として拍頭から打ち込む。強い音節を拍頭へ伸縮し、音の中心を調のペンタへ寄せて濁らせない（作者の手順）。
- 4つ打ち＋裏の開きハット、8分オクターブのベース、セブンスのブロック和音の刻み、パッド。
