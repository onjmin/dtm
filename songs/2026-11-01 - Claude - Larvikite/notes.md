# Larvikite（2号兄貴リスペクト、インスト）

- 150 BPM・A マイナー・56 小節（約 1分32秒）。`#mode=advanced` の MML。
- 土台: 自動作曲 `kaiwai_2go_lead` の seed 2（セクションは intro / verse / chorus / bridge / outro を指定）。
- 聴く: `song.mp3`（この MML を DTM の再生経路でそのまま録ったもの）。生成器の素の出力は `raw.mml` / `raw.mp3`（同じ seed）。
- 作り直す: `npx tsx "songs/2026-11-01 - Claude - Larvikite/build.ts" <出力フォルダ>`（`lib.ts` は `scripts/compose/strata-compose.ts` の生成・書き出し部分の写し）。

## 意図（1文）

「ラドレミーレドー」の半小節の主題を、イントロの予告から最後の小節の前まで、2小節ごとの頭にしつこく戻し、リードは E7・Gm7・Bm7-5 の上でも A マイナーペンタの5音から一度も出ない。

## 振り切った軸

1. **しつこい主題**: 主題 X（16分の「タタタター・タター」、3音目から4音目へ食う）を、Aメロは2小節ごと、サビは4小節の句の頭すべてに置いた。Aメロの3・7小節目は主題を1段下（ソラドレードラー）と反行（ラソミレーミソー）にして、同じ形の変奏だと分かるようにした。
2. **ペンタの一点張り**: リードは ラ・ド・レ・ミ・ソ だけ。E7 の上は ミ・レ・ソ（♯9）、Gm7 の上は レ（5度）とラ（9度）、FM7 の上は ラ（3度）へ着地させ、ペンタのまま和音に合わせた。2号兄貴の手本 4/8 曲が旋律を完全なペンタで書いている（`docs/research/kaiwai-lineages.md`）。

## 素直にしたところ（生成器のまま）

構成（イントロ4・Aメロ8・サビ16・全音下のAメロ8・サビ16・アウトロ4）、進行（Am7 E7 | Am7 Gm7 | C7 FM7 | Bm7-5 E7 と Am7 | Gm7 | C7 | FM7）、ベース、ドラム（four_clap_16hat_snare）、パッド・エレピ・クリスタルの刻み、楽器、ミックスの値。

## 手を入れたところ

| トラック | 生成器 | この曲 |
|---|---|---|
| t0 リード（Lead 2 sawtooth） | Aメロは毎小節の音階下降、サビは同じ1小節を16回、最高音 G7 | 全部手書き。Aメロは 4〜5 オクターブ、サビはその1オクターブ上（A5〜C7、C7 は各サビに1回だけ） |
| t1 重ね（Synth Brass 1） | サビの裏で16分2音の合いの手 | サビのリードの下に3〜4度の重ね。ペンタで3〜5半音下 → 無ければ和音の音 → 無ければ休み、を伴奏と半音でぶつからないように選ぶ |
| t3 サブメロ（Lead 4 chiff） | Aメロで E4〜B♭4 の持続 | 外した。リードと同じ音域で別の線を歌い、主題が聞き取りにくくなるため |
| t14 ソロ（Distortion Guitar） | サビでリードの1オクターブ下の別の線 | 外した（同上） |
| t6 パッド | サビ締めの Dm7 E7・FM7 E7 で F6 を伸ばす | E6 に替えた。F6 は E7 の G♯ と短9度でぶつかり、リードの E6 と真上で半音になる |

2回目のサビは最後の1小節だけ、3連で回ってアウトロ（Aメロの高さ）へ降りる形に変えた。

## 確かめたこと

- **MML の読み戻し**: `song.mml` を `parseMML` で読み戻し、t0・t1 の全音符（開始・音高・長さ）が意図どおりと一致。生成器のトラックは長さが16分の格子へ1〜2 step 丸まる（アプリの書き出しと同じ挙動）。
- **ぶつかりの場所**: リードと重ねの「拍頭か8分以上の音」が、伴奏の音の半音上（短9度・短2度）か真上の半音になる所は 0。最初の稿では 57 か所あり、長7度上（Gm9・FM7 の響き）を除いて、次を直した:
  - Aメロ6小節目の伸ばしが A4 で、クリスタルの A♯4 と半音 → D5 に着地
  - Aメロ7小節目の A4（8分2つ）が、全音下の2回目では G4 になりパッドの G♯4 と同じ高さで半音 → ソ・ミへ
  - サビ4小節目の終わりで E7 の上に A5 を1拍伸ばしていた → ミへ着地
  - イントロ4小節目の主題（Bm7-5 の上に C6 の8分）→ レ・ラだけの形へ
- **リードの帯の位置**（目安で、合否ではない）: 占有 0.95（サビ）・16分以下の音 51〜56%・3連 12%（サビ）。手本の2号兄貴は 16分 30% 以上 8/8、占有 77〜93%。
- **音量**（DTM の再生経路で、リードだけ・伴奏だけを別々に録って比べた）: 1.2〜4 kHz でリードが伴奏より +5〜+8 dB（アウトロだけ +4.7）、4〜10 kHz で +5〜+10 dB。サビはクリスタルの16分の刻みが厚いので差が一番小さい（+5 dB）が、リードは埋もれていない。全体のピーク 0.98・クリップ 0。

## 自分の評価

- 生成器の素の出力（`raw.mp3`）は、Aメロに主題が無く（毎小節が音階を下るだけ）、サビは G7 まで上がる同じ1小節が16回続く。耳に残る線が無いので、そのままは出さない。
- この版は「主題が何か」がイントロの3小節目で分かり、Aメロ・サビ・アウトロのどこで聴いても同じ主題に戻る。サビで1オクターブ上がり、2和音ずつの進行の上でもペンタの響きが崩れない。これを出発点として渡せる水準と判断した。
- 弱いと思う所: 2回のサビが最後の1小節を除いて同じ（2号兄貴の4小節ブロックの使い回しの範囲だが、32 小節ぶん同じ線が続く）。主題の形そのもの（ペンタの上行と戻り）はありふれていて、印象はしつこさに頼っている。

## 確かめていないこと

- 実際に耳で聴いてはいない（エージェントは音を聴けない）。音量・帯域・ぶつかりの場所は録った音とノートから見ただけ。
- サビのクリスタル（t10、16分の4音和音）がうるさく感じないか。
- 全音下の2回目のAメロ（G マイナー）からサビ（A マイナー）へ戻る所の段差が、上がった感じに聞こえるか、つぎはぎに聞こえるか。

## 所有者に訊くこと

- 出発点として使うか／最初に直す場所／理由を一言。
- 主題のしつこさ（サビの句の頭がすべて同じ2小節）は、足りないか、多すぎるか。
