# 歌声エンジンの調べ物（VOICEVOX・AI-MGRoid）

2026-10-31 の調査の記録。その時点で分かったことと、採った案・採らなかった案の理由を残す。後から更新はしない。
採った案（VOICEVOX）の今の仕組みと使い方は [../voicevox-sing.md](../guide/voicevox-sing.md)。

## 1行でいうと

**dtm に組み込めたのは VOICEVOX だけ。** AI-MGRoid は2種類あり、ACE Studio 版は外から呼ぶ口が無く、2021年の自作ソフト版は配布物が今は動かないので不採用。Google Colab で動かす案も規約と安定性の理由で見送った。

## きっかけ: ずんだランドはなぜブラウザでずんだもんがしゃべるのか

[ずんだランド](https://zundamon.satoru.net/) は、ブラウザの中で声を合成していない。事前に VOICEVOX で作った mp3 を流しているだけ。

- `voice/lines.json` にセリフの文と VOICEVOX のスタイル番号（`3`・`7` など）が並ぶ。
- `avatar.js` の `speak()` が `voice/{key}_{index}.mp3` を読んで Web Audio で鳴らす。途中に `AnalyserNode`（口パク用と見られる）と `StereoPanner` を挟む。
- 用意したセリフしか話せない。

## dtm でずんだもんを歌わせる方法の比較

| 案 | 中身 | 結論 |
| :--- | :--- | :--- |
| A. UTAU 音源を `.koe` にして足す | 今の koe の仕組みにそのまま乗り、ブラウザだけで歌える | 使えるずんだもんの UTAU 音源があるか、規約で組み込めるかを確かめていない |
| B. VOICEVOX の歌唱 API | 楽譜をエンジンに送り、WAV を受け取って鳴らす | **採用。** すぐ試作でき、ブラウザから直接呼べた（CORS が通る） |
| ほかの AI 歌声（NEUTRINO・DiffSinger 系のずんだもんなど） | 楽譜から歌うエンジン | 試していない。B で作った「音符と歌詞を時間つきの楽譜にする」部分は流用できる |

## AI-MGRoid（MGR姉貴の AI 歌声）

「AI-MGRoid」と呼ばれるものは2つあり、どちらも VOICEVOX 形式ではない。VOICEVOX に入れるにはモデルを学習し直す必要があり、現実的ではない。

### 1. 廻音グルACE AI（ACE Studio 用の音源）

- 無料で公開され、二次創作に使ってよいと説明されている。UTAU 版の MGRoid は dtm に入っている（`mgroid`）が、こちらは別物。
- ACE Studio はデスクトップアプリで、手元の PC で合成する方式（[ローカルレンダリング](https://docs.acestudio.ai/ai-rendering/local-rendering)）もある。ただし外から呼ぶ API は見当たらず、音源をアプリの外で動かすこともできない。
- **不採用（自動では組み込めない）。** 使うなら手作業で、dtm から MIDI か MusicXML を書き出す → ACE Studio で歌わせる → できた音声を伴奏の音声として読み込む。

### 2. 2021年の自作ソフト「AI姉貴UTA版」（[sm39231377](https://www.nicovideo.jp/watch/sm39231377)）

Google Drive で配られている `AIAnekiSinging v0.1.zip`（約2.4GB）を落として中身を調べ、WSL で動かそうとした。

**中身**: 楽譜から歌うソフトではなく、歌声の音声を MGR姉貴（または BNKRG）の声に変える**声質変換**ソフトだった。

- `convert`: 変換の本体。Linux（x86-64）用の実行ファイル。
- `lib/`: PyTorch 一式（約4.3GB、CUDA 11.0 版）。
- `model.bin`: 学習済みモデル（約430MB、暗号化されている）。
- `run.py`: 入力を 24kHz にそろえて `convert` に渡す。
- `AIAnekiSinging.ipynb`: **Google Colab 用のノートブック**。Drive に置いて実行する手順で、NEUTRINO の Colab 用ノートブックを参考にしたとある。もともと Colab で動かす前提の配布物。
- `refs/`: 歌い方の参考にする音声。

**規約（LICENSE.txt）**: 無料で報告も不要。作者を偽る、政治・宗教の賞賛や批判、誹謗中傷、公序良俗に反する、キャラクターのイメージを大きく損なう使い方は禁止。変換した音声の公開は禁止されていない。ソフトの再配布については書かれていないので、同梱せず各自の手元で動かす形が無難。新しい版が出たら旧版は使用停止、作者が停止を知らせたら従う、ともある。

**つなぐとしたら**: 二段構えになる（dtm の楽譜 → VOICEVOX か koe で歌う → AI姉貴UTA版で MGR姉貴の声に変える → 再生）。元の歌声の発音とタイミングはそのまま残るので、仕上がりは元の歌声しだい。

**WSL で試した結果: 動かなかった。**

1. WSL の Ubuntu に展開し、Python の環境（librosa など）を用意した。起動に要る OpenSSL 1.1 は、Ubuntu 公式の旧パッケージからライブラリだけ取り出した（システムには入れない）。
2. Colab 以外で動かすには、起動時に読む環境変数 `COLAB_GPU` を自分で設定する必要がある。
3. 付属のサンプル音声の先頭10秒を変換しようとした。GPU でも CPU でも「Loading model...」のあと、エラーの文言なしで失敗した。
4. 実行ファイルの文字列を調べると、モデルを読み込むときに作者のサイトの `https://cookie.fan/aisinger_ver.json` を取りに行く作りだった。今は 404 で、取れないとモデルを読み込めずに終わる。
5. 偽のファイルを返すサーバーを立てれば先へ進む可能性はあるが、作者がオンラインで管理している仕組みを迂回することになり、規約（作者の停止の知らせに従う）にも反しかねないので、やっていない。
6. 動いたとしても、同梱の CUDA 11.0 版の PyTorch が RTX 5060 Ti（2025年の世代、compute capability 12.0）の GPU で動くかは試せていない。

**不採用。** 使うなら作者（@ByoukaAnshou）か配布元の Discord で、今も使えるか・新しい版があるかを確かめるところから。落とした配布物と WSL の環境（約7GB）は削除した。

## Google Colab でエンジンを動かす案

Colab でモデルを動かし、トンネル（cloudflared・ngrok など）で API キー付きの受付口を開けば、dtm からは VOICEVOX と同じく「フレーズの楽譜（か音声）を送って音声を受け取る」形で呼べる。dtm 側の作りはほぼ使い回せる。

**見送った。**

- 無料の Colab は、Web サービスとして外部に公開する使い方や、外からのアクセスを中継する使い方を規約で禁じている。
- 放置すると切れ、1回の利用時間にも上限がある。そのたびに公開 URL も変わる。
- AI姉貴UTA版は Colab 前提の配布物だが、上のとおり今はモデルを読み込めないので、Colab に載せても動かない。
- 同じ構成なら、手元の PC で Strata のようにキー付きで公開するほうが安定し、規約の問題もない。
