# 外部のサウンドフォント（.sf2）で鳴らす

トラックの「音源」で **外部 SoundFont（.sf2）**（`#t<n>font=ExtSF2`）を選ぶと、そのトラックの楽器（GM の番号）に当たる楽器を、読み込んだ .sf2 から鳴らす。.sf2 に無い楽器は、警告を出して既定の FluidR3 で鳴らす。

## 使い方

- **ファイル**: トラックの音源で「外部 SoundFont（.sf2）」を選び、出てきた欄で .sf2 を選ぶ。ファイルは MML に書き出されない（受け取った相手の手元に無いため。同時再生の音声と同じ）。
- **URL**: 同じ欄に .sf2 の URL を入れて「読込」。MML には `#sf2=<URL>` と書かれ、共有リンクや再生専用プレイヤーでも鳴る（URL の置き場所が CORS を許している必要がある）。
- 読み込み元はページで1つ。全トラックで共通に使う。
- **バンク**: 同じ欄の「バンク」に番号（0〜127）を入れると、そのバンクのプリセットだけから選ぶ（MML では `#t<n>font=ExtSF2_<バンク>`）。キャラごとにバンクを分けた .sf2（レ淫棒など）で、GM の番号だけでは選べない楽器を鳴らすのに使う。空なら下の「楽器の選び方」のとおり。バンクはトラックごと。

```
#sf2=https://example.com/MySoundFont.sf2 #t0font=ExtSF2 #t0inst=Acoustic Grand Piano
@0 t120 o4 c4 e4 g4 >c4;
```

## 仕組み

- 既定の音源バンク（FluidR3 など）は、配信元の WebAudioFont 形式の JS を `<script>` で読む。外部の .sf2 は**データとしてだけ読み、コードは実行しない**（`src/instruments/sf/sf2-parser.ts` の `parseSf2`）。読んだサンプルとゾーンを既存の再生の仕組み（`SoundFont.fromZones`）に渡すので、エンベロープ・ベロシティ→明るさ・ヒューマナイズは他のバンクと同じに効く。
- 読む範囲: プリセット → インストゥルメント → サンプルの2段のゾーン（グローバルゾーン込み）、鍵盤範囲、ルートキー、調律、ループ、アドレスのオフセット、16bit のサンプル。ベロシティ範囲は見ない（各鍵で最初に当たったゾーン）。ドラム（バンク 128）、24bit の下位、ROM サンプル、モジュレーターは使わない。
- 楽器はバンク 0 の同じ番号を優先し、無ければドラム以外の同じ番号。バンクを決めたトラック（`ExtSF2_<バンク>`）は、そのバンクの同じ番号だけ（無ければ警告を出して FluidR3）。
- URL は http / https だけ（`normalizeMediaUrl`。`;` `#` 空白・制御文字・引用符を含むものは受けない）。大きさは 256MB まで（Content-Length を信じず、読みながら数える）。壊れた・細工されたファイルは、範囲外を読む前に例外にする。
- 取りに行くのは楽器が要るとき（再生の準備・トラックの音源を読み直すとき）。
- テストは `scripts/test/check-sf2.ts`（テストの中で最小の .sf2 を組み立てて読む。壊れたファイル、`#sf2=` の往復も見る）。

## 確かめたこと（2026-10-31）

- テストで組み立てた .sf2（正弦波1本、ピアノ＝0番、鍵盤 48〜72）を `#sf2=` で読み、デモの DAW（ヘッドレスの Edge）でピアノのトラックの4音が .sf2 のサンプルで4分音符の間隔で鳴った。
- 楽器がリード（80番）のトラックでは、.sf2 に無いので FluidR3 に落ちた（警告つき）。

## 確かめたこと（2026-11-09、バンク）

- 虹.のレ淫棒（`https://onjmin.github.io/inc-sf2/niji/20171022/Rainbow_SoundFont.sf2`）を `#sf2=` で読み、`#t0font=ExtSF2_33`・楽器ピアノ（0番）のトラックを鳴らすと、4音ともバンク 33 の 0 番（UDK「VAN」、10985 サンプル）で鳴った。DAW の「バンク」を空にすると、バンク 0 の 0 番（野獣「オォン！」、24326 サンプル）に変わった（デモの DAW で、鳴らした AudioBuffer の長さで見分けた）。
