# NEUTRINO で歌わせる（試作）

> まっさらな PC に入れて鳴らすまでの手順（ほかのエンジンと共通の準備・`pnpm engines` でのまとめての起動を含む）は [local-engines-setup.md](local-engines-setup.md)。このページはこのエンジンの細かい話。

歌詞トラックの音源に NEUTRINO の歌い手を選ぶと、利用者が公式から入れた NEUTRINO で歌わせる。
NEUTRINO はコマンドラインで動くソフトなので、ブラウザからは手元の中継サーバー（`scripts/misc/neutrino-server.ts`）を通して呼ぶ。
dtm は NEUTRINO 本体も歌声ライブラリも同梱しない。規約の解釈と、やること・やらないことは [../research/neutrino-terms.md](../research/neutrino-terms.md)。

## 使い方

1. [NEUTRINO の公式サイト](https://studio-neutrino.com/downloads/)から本体（Windows 版 Tau v3.2 以降）を落として展開する。使う歌声ライブラリも落として `model/` に入れる。
2. 中継サーバーを起動する（NEUTRINO を入れた PC で）。

   ```bash
   npx tsx scripts/misc/neutrino-server.ts --neutrino <NEUTRINO のフォルダ>
   ```

   既定は `http://127.0.0.1:50022`。`--port` で変える。NVIDIA の GPU が無いときは `--cpu`。
   dtm のページを file: で開いて使うときだけ `--allow-file-origin` を付ける（既定では断る。公開サイトでも sandbox 付きの iframe で `Origin: null` を作れるため）。
3. dtm のページを**手元で**開く（`pnpm dev` のデモなど。localhost・127.0.0.1・file:）。歌詞トラックの音源の「NEUTRINO（要サーバー起動）」から声を選ぶ。MML では `@@0 nt_reina どんぐりころころ…` と書く。

公開サイトなど手元以外で開いたページでは、VOICEVOX と NEUTRINO の声は選択肢に出ない（`src/voice/local-engines.ts` の `isLocalPage`）。MML に書かれた値は消さずに保つ。

## 仕組み

- **フレーズとトラック**: フレーズの切り方は VOICEVOX と同じ（休符・ブレス・語りで切る）。NEUTRINO は1回呼ぶたびに約4秒の立ち上げがかかるので、フレーズごとには呼ばず、トラックを休符で区切った「区切り」ごとに合成し（`splitNeutrinoTrack`。区切りが無ければトラック全体）、出来た音声をフレーズの範囲に切って並べる（下の「待たずに鳴らし始める仕組み」）。シーク・ループ・途中から鳴らす処理は VOICEVOX と共通（`src/voice/lyrics.ts` の `runExternalTrack`）。
- **切り出し**: フレーズの切り出しは、最初の音の 0.3 秒前から次のフレーズの切り出しの頭まで。隣どうしは重ならないので、同じ音が二重に鳴らない。
- **楽譜**: VOICEVOX 形式の楽譜（フレーム単位）を秒へ戻し、テンポ 60（4分音符＝1秒、divisions 960）の MusicXML に書く（`scoreToNeutrinoMusicXml`）。小節をまたぐ音はタイで分け、歌詞はタイの頭にだけ付ける。
- **中継サーバー**: 受け取った MusicXML を一時フォルダに書き、`bin/musicXMLtoLabel` → `bin/neutrino`（`-m` で GPU）の順に呼んで WAV を返す。合成は1件ずつ。127.0.0.1 でだけ待ち受ける。`Host` ヘッダーが手元のこのポートでない呼び出し（DNS リバインディング）と、手元以外の Origin（`127.` で始まる公開ドメインや `Origin: null` を含む）からの呼び出しは断る。2026-10-31 のセキュリティレビューで、最初の版はこの3つが通っていたのを直した。歌声ライブラリの名前は `model/` にあるフォルダと完全一致だけ通す。
- テストは `scripts/test/check-neutrino-score.ts`（楽譜とフレーズの切り出し、手元判定。NEUTRINO は呼ばない）。

## 待たずに鳴らし始める仕組み（2026-11-01。手元のエンジン共通）

手元のエンジン（VOICEVOX・NEUTRINO・OpenUtau・Sinsy）は、koe のように1音ずつブラウザの中で作れないので、合成の終わりを待つと鳴り始めが遅れる。そこで、先の分を順に合成しながら、残りが間に合うと見込めた時点で鳴らし始める（`src/voice/lyrics.ts`）。

- **区切り**: VOICEVOX はフレーズ1つずつ。NEUTRINO・OpenUtau・Sinsy はトラックを 0.2 秒以上の休符で区切り、最初は 4 秒以上、あとは 20 秒以上の歌ごとに1つの楽譜にする（`LOCAL_ENGINE_CHUNKING`）。区切りの境目は、トラック全体で切るときと同じ所で受け渡し、余白が二重に鳴らないようにする。
- **頼む順番**: エンジンは1件ずつしか作れないので、どのトラックでも曲の頭（再生位置）に近いものから先に頼む（`src/voice/priority-queue.ts`）。
- **鳴らし始める時**: 出来た区切りから、エンジンごとに1回の合成時間を「立ち上げ ＋ 歌の秒数 × 係数」と当てはめ、残りが全部「鳴る2秒前」までに出来ると見込めたら再生を始める（`waitUntilAhead`）。前奏の後から歌うトラックなら、そのぶん待たずに鳴り始める。
- **外れたとき**: 見込みより遅れたフレーズは途中から鳴り、コンソールに「合成が間に合わず、途中から鳴らしたフレーズがあります」を1回出す。
- 一度作った所は、ページを開いている間は dtm が、OpenUtau はページを閉じてもフレーズごとにキャッシュするので、2回目からはすぐ鳴る。

海鬼月（どのエンジンも歌3トラック。前奏があり、歌は 13.8 秒から）で、作り置きの無い状態から DAW で鳴り始めるまで（RTX 5060 Ti）:

| エンジン | トラック全体を待つ（前の作り） | 今 |
| :--- | :--- | :--- |
| VOICEVOX | 18 秒 | 1.7 秒 |
| Sinsy（音程補正あり） | 32 秒 | 2.6 秒 |
| DiffSinger | 66 秒 | 11 秒 |
| NEUTRINO | 53 秒 | 12 秒 |
| ENUNU（PyTorch GPU 版） | 266 秒 | 95 秒 |

どれも頭から44秒を録って、合成が間に合わない警告は出なかった。NEUTRINO は、出来た区切りが1つのうちは立ち上げを見分けられず控えめに見積もるので、2つ目が出来るまで待つ。ENUNU は3トラック合わせると歌の長さより合成に時間がかかり、間に合う所まで待つぶん、これより短くならない（もっと縮めるには ENUNU のサーバーを並べる必要があるが、口が SimpleEnunu と OpenUtau の両方に決め打ちで、外部ソフトの書き換えになるのでやらない）。DiffSinger は OpenUtau を起動するたびに声のモデルを読み込み直す。OpenUtau を起動しっぱなしにする改造で数秒は縮むが、本家に無い改造を持ち続けることになるのでやらない。

## 確かめたこと（2026-10-31、RTX 5060 Ti・NEUTRINO v3.2.2）

- 初めて動かすときだけ、GPU の準備で2分20秒ほどかかる。2回目からは、43秒の曲を約9秒、4秒のフレーズを約4秒で作る。
- dtm が書いた MusicXML で、レイナ・めろう・ずんだもんが楽譜どおりの高さ（±0.1 半音）で歌った。子音は拍の少し前から歌う。
- デモの DAW（ヘッドレスの Edge）で `nt_reina` のトラックを再生し、2つのフレーズが伴奏と同じアンカーから計算どおりの時刻に置かれた。音源の選択肢に NEUTRINO の7人が出て、琴葉茜では規約のリンクが2つ出た。

## 制約

- 中継サーバーと NEUTRINO が無いと鳴らない。他の声で代わりに鳴らさず、コンソールに警告を1回出すだけ。
- トラックを編集すると、そのトラック全体を作り直す（1分の曲で10秒ほど）。
- 歌えるのは単旋律だけ。声のフェード（`↓` `↑`）、オクターブ重ね、声質のつまみは効かない。
- 出力を声質変換の入力にしない（NEUTRINO の規約 §5 で禁止）。
