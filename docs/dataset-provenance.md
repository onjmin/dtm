# 素材の出どころ台帳

自動作曲が使う素材（`src/compose-phrases.ts` など）が、**どのデータから作られたか**を
バージョンごとに記録する。

## なぜ要るか

素材の一部は外部コーパスから作る。そこに「パブリックドメインとして投稿されたが
実はそうでなかった」ものが混じっていた場合、**どのバージョンまでが影響を受けるか**を
後から言えなければ是正のしようがない。全部を疑うか、何もしないかの二択になる。

だから書き出すファイルにバージョンを埋めてある。

| 形式 | 埋まる場所 |
|---|---|
| MML | `#ver=2.1.16`（full / 共有リンク用の mini の両方） |
| MIDI | テンポトラックのテキストメタ `dtm 2.1.16` |
| MusicXML | `<identification><encoding><software>dtm 2.1.16` |

手元のファイルを見れば、この表を引いて素材の由来が分かる。

## 申告が誤っていたときの手順

1. 該当ファイルを `tools/melody-model/exclude.txt` に追記する
2. データセットを作り直す（`scripts/export-dataset.ts`）
3. 素材を作り直す（`scripts/calibrate-phrases.ts` など）
4. **バージョンを上げる**（`package.json` と `src/version.ts` の両方。
   `scripts/check-version.ts` が一致を検算する）
5. 下の表に「影響のあったバージョン」として追記する
