# 界隈曲の映像の作り方（あめふらし・エイ・あねもねぐりっち）

界隈曲（自作曲・カバー）の MV を、自前の描画（PIL）で作ったときのノウハウを工程順にまとめる。音MAD の映像（窓・BB・一転攻勢）は [video-making.md](video-making.md)。

- あめふらしがえきにおりてくる（11-03）: 自作の界隈曲。黒地に枠が1つ、水だけが曲を通して増え、3番のサビで初めて枠が消えて色のある海の駅になる。ドット絵の人物。
- あのエイがまたおよいでくる（11-13）: 自作の界隈曲。2つの版を作った。駅のドット絵の版（表と裏の駅が回り込む）と、図形と字だけの版（黒地・線・ひし形・字、間奏だけドット絵の風景）。
- あねもねぐりっち 束音ロゼ版（11-06〜11-08）: カバー。所有者が原曲 PV を模写したスプライトで組み直した。宣伝用の縦ショートも作った。

個別の技は次にある。ここは作品をまたいで使い回せる作りと、所有者の指摘をまとめる。

- 原曲 PV の語彙で組むカバー MV: [techniques/pv-pixel-cover-mv.md](techniques/pv-pixel-cover-mv.md)
- ドット絵の歌動画の型とバグの型: [techniques/pixel-video.md](techniques/pixel-video.md)
- ドット絵の人物の描き方: [techniques/pixel-character.md](techniques/pixel-character.md)
- 白黒の文字PV（Scratch 風）: [techniques/scratch-fx.md](techniques/scratch-fx.md)

## 0. 骨組み

3本とも同じ作りで、これを使い回す。

- **動きは全部、曲の楽譜（音符の JSON）から決める**。小節・拍・16分の位置、どの声部がいま鳴っているか、歌詞のモーラの鳴り始め。音源を解析して拍を取らない。曲を直したら楽譜を書き出し直すだけで映像が合う。
  - ドラムは楽譜に無いことがある。そのときは伴奏の書き出しと同じ決まり（区間の種類・最後の小節・次がサビか）で、映像の側でも打点を並べ直す。2か所で同じ決まりを書くので、片方を直したらもう片方も直す。
- **小さい論理画面で描いて、最近傍で整数倍に拡大する**。480×270 を 4倍で 1920×1080、8倍で 3840×2160。ドットは点の格子を守り、拡大の前に滑らかな処理を入れない。
  - YouTube には 8倍（4K）で上げる。1080p で上げるとドットがつぶれる（[pixel-video.md](techniques/pixel-video.md)）。
  - 1080p を基準にした倍率（倍率 ÷ 4）を持っておき、粒・ぼけた塵の大きさと速さに掛ける。4K でも見え方が変わらない。
- 1コマずつ描いて生の RGB を ffmpeg の標準入力へ流す。拡大は ffmpeg の `scale=…:flags=neighbor` で（Python で拡大して流すより速い）。H.264・crf 15〜16・yuv420p・AAC 256k、`-movflags +faststart`。
- 引数を揃える: `--scale`（倍率）、`--fps`、`--from/--to`（一部だけ書き出す）、`--still 秒,秒,…`（その時刻のコマを一覧1枚に）、`--sheet`（小節の位置で試し描き）。全編を書く前に、試し描きで場面の頭を確かめる。
- 音だけ直したときは映像を描き直さず音を差し替える（`-c:v copy`）。

## 1. 映像の仕掛けを1つ決める

所有者「MV演出も映像を凝ってほしい」「挑戦的でハイセンスな映像」。立ち絵を並べて終わりにせず、曲の詞から**曲全体を通して変わっていく1つの仕掛け**を先に決める。

| 作品 | 仕掛け | 曲との対応 |
|---|---|---|
| あめふらし | 黒地の枠の中だけに場面。水位が曲を通して上がり、Bメロ2で枠からあふれ、3番のサビで枠が消えて色のある海の駅 | 区間ごとの水位を表で持つ。色を出すのは最後の山だけ |
| エイ（駅の版） | 画面に表と裏。表＝海の駅（キリコ、エイは背中）、裏＝逆さの駅（ロゼ、エイは腹の顔）。歌い手が替わると縦に回り込む。最後のサビは水面で上下に割れる | 回り込みは1拍かけて。歌い手の行で決める |
| エイ（図形の版） | 横線1本で上が表・下が裏。人は縦棒、エイはひし形。棒は1本ずつ倒れて靴の点だけ残り、ひし形が増える | 人の数が減っていく＝曲の進み |
| あねもねぐりっち | 原曲 PV の語彙（黒地・灰色の円の計器・縦のひらがな・灰色のブロックの乱れ）で組み直す。計器をアネモネの花の形に | 計器は伴奏の 36 帯で開く |

- 仕掛けは字で説明しない。音なしで見て分かる形にする。
- 色や画面の広がりは**最後の山まで取っておく**（黒地 → 最後に色、枠の中 → 最後に枠が消える、線の上下 → 最後に割れる）。
- 題名は画面に入れない。

## 2. 音と絵を1対1にする

拍に合わせて「何かが動く」だけでなく、どの音で何が動くかを決めて、見て音が分かるようにする。

- **キック**: 枠の線がキックで太くなって戻る。エイの大きさが `1 + 0.2 × exp(−経過 / 0.11 秒)` で脈打つ。
- **スネア・クラップ**: 人の棒が 0.06 秒震える。
- **拍の中の位置**: 人物は拍の頭で深く曲げ、拍の後半で伸びる（4コマを拍の中の位置で選ぶ）。拍の頭で着地させる。語りや間奏でも速さを半分にしない。
- **歌っている声**: 画面の端に声ごとの小さな枠を並べ、鳴っている間だけその人物の顔を出し、音の高さぶん線を伸ばす。
- **旋律・分散和音**: 間奏の風景で、ソロの音ごとにエイが海から跳ねる（長い音は手前で大きく、短い音は遠くで小さく）。分散和音の音の高さの所で波が十字に光る。
- **泡**: 歌った高さに小さな輪を出し、線から離れていく。水の中で歌う人物は口から泡（1拍に多くて1つ）。
- **ドラムの譜面**: 枠の下に 16 マスの打楽器の並びと、和音の帯（和音ごとに色）を出す。いま何が鳴っているかが見える。
- **場面転換を音の段に合わせる**: あめふらしの墨はフィルのスネアごとに広がり、音が抜ける最後の1拍で全面を覆い、サビの頭のキックで晴れる。エイの間奏の風景は線から上下へ1拍で開き、最後の1拍は半音の8音に合わせて8段で閉じる。

## 3. 歌詞

- **字はそのモーラが鳴った時に出す**。歌詞は `{漢字|モーラ数}` の形で書き、漢字1語に何モーラ当たるかを持つ（`{今日|2}も{朝|2}から`）。歌のかなと表示の字をモーラ数で対応させる。
- 縦書きは、今の行を右端に、前の行を左へ送って暗くする。行の終わりから2小節で消し、場面が変わったら消す（あめふらし）。原曲が頁型なら頁型にする（あねもねぐりっち、[pv-pixel-cover-mv.md](techniques/pv-pixel-cover-mv.md)）。
- **字をピアノロールにする**（エイの図形の版）: 歌詞のモーラを、2小節を横幅にした時刻の位置と、音の高さの位置（中央の音から ±9 半音まで、1半音 5 px）に置く。歌ったモーラは明るく、下に長さの線を引き、鳴った瞬間だけ線を太くする。声部（主旋律と別の歌い手）で色を分ける。行の上下どちらに出すかは行のまん中の時刻で決め、行の間は変えない。
- 字は 8 点のドットフォント（美咲ゴシック）。字の下が切れないよう、8×8 より広い所へ基準線で描いてから 8×8 を切り出す。
- **区切りと折りは全行を手で決める**。助詞で自動に区切ると「おちたの／で」のように崩れた。
- **字のはみ出しを全編で検査してから書き出す**。縦書きの関数は、下の端を越える字を描かずに記録し、全編を 1/8 秒ごとに描いて記録が1つでもあれば止める。横のピアノロールは、行の最後のモーラの位置が画面の内に入るかを最初に全行確かめる。所有者に「枠から文字が出る凡ミスをなくして」と言われた（試し描きのコマだけ見ていて気づけなかった）。

## 4. ドット絵の絵作り

- **光を場面ごとに当てる**: 場面の光（朝・甘い・冷たい・雨・灯り・海）を、絵の上と下に掛ける色、光の来る側の縁に足す色と向きで表に持つ。人物も小物も描いた後にその光で塗り直す（足元ほど暗く、光の側の縁だけ光の色）。素材をそのまま貼らない。
- **色の段を減らしてドット絵の粒にする**: 空や海のグラデーションは色の段を並べ、段の境は 4×4 の網（Bayer）で混ぜる。なめらかにしない。水の色も段で塗り分ける。
- **ざらつき・汚れ・錆**: 1ドットの粗いざらつき、2ドットのかたまり、点でまだらに暗くする汚れ。2倍の点に置くので細かくなりすぎない。
- **粗い格子**: 細かく描いた風景を 480×270 → 240×135 に落とすとき、平均して網をかけ直し、まわりと大きく違う点（星・電線・きらめき）だけは残す。
- **コマ落ち**: 間奏の風景の絵だけを 16 分音符ごとに止める（拍の格子に乗る）。乱れる所は 32 分。窓の開け閉めや上に重なる物は 30 コマのまま。
- **奥行きは実寸で組む**: 線路と電柱は1点透視をメートルで組み（焦点の画素、目の高さ、枕木の幅と間、電柱の間と高さ）、1つの速さ×時刻で流す。線路と電柱がずれない。
- **雲**: 平らな底に玉が段（手前は大きく、奥は小さく）に積もる形。光の来る側ほど明るく、底の縁を光の色、頭は空に溶ける色。孤立した1点は消す。
- **雨**: 歌詞の「あめがふる」で降り始め、歌い終わりで止む。粒ごとに「落ち始めた時に降っていたか」で決めるので、止むときは空中の粒だけが地面まで落ちて終わる。奥の雨は物の後ろ、手前の雨は物の前。雨雲で物の色にも影を落とし、地面は暗くなって水たまりが広がる。物の端からしずくがふくらんで落ち、止んだ後も少し続く。
- **人物**: 1ドットずつ図で置く（計算で塗らない）。光は左上の1方向、影は右下にかたまりで置いて色相を冷たい方へずらす。輪郭は部位ごとの暗い色。肩は丸く、頭は小さめ、服に光と影。所有者「肩の角を落とす、顔を小さく、服の陰影」。手本は rpgen-walk の MV 素材。詳しくは [pixel-character.md](techniques/pixel-character.md)。
- 歌っていない人物は描かない。人物は向いている方向へ動かす。
- **原曲 PV の動きは推測しない**。原曲の動画をコマで測って、跳ねの周期・振り・まばたきの間隔を合わせる（[pv-pixel-cover-mv.md](techniques/pv-pixel-cover-mv.md)）。

## 5. 乱れと点滅

- **高速の色替え・点滅はしない**。書き出しながら、前のコマとの平均の明るさの差が 18 を超えたコマを数えて表示する。場面転換以外で出たら直す。
- 乱れ（横の帯ずらし＋赤と青のずれ）は、音が詰まっていく所だけ、詰まるほど大きく、0.07 秒だけ出す。画面全体でなく人物の絵に掛ける（あねもねぐりっち「グリッチは画面でなくキャラの絵にかける」）。
- 人物はグリッチだけで出る（0.35 秒で 14 → 0）。不透明度のフェードは「イージング不要」と言われた。
- カメラは固定。ゆっくりした横揺れは「なくして」と言われた。
- 終わりは最後の1秒で黒へ落とす。

## 6. 縦のショート（宣伝用）

あねもねぐりっちで、本編の最後のサビ（約 34 秒）をショートにした。

- 横の 4K を縦に切ると歌詞か人物が切れる。論理画面を 270×480 にして、そのサビのショットを縦に組み直す（計器は上、人物は下、縦の歌詞は左上、大きな字は2倍）。
- 隠れる所を避ける（論理の点で、下 125・右 35 の y 220〜400・上 40）。ニコニコのショートは上 200 px・下 500 px（1080×1920）。
- 最後に数秒の告知（所有者「最後のシーンに数秒くらい告知入れて」）。告知の字は1字ずつ 0.035 秒で出し、出るときだけ人物と同じ乱れを掛ける。題名の題字は入れない。
- 音は本編の書き出しから切る（頭 15 ms・終わり 0.36 秒のフェード）。

## 7. 確かめる

- 字のはみ出しを全編で自動に数え、1つでもあれば止める。
- 試し描き（小節の位置か秒の一覧）で、区間の頭・場面転換の前後を見る。静止画は書き出しと同じ見た目（粗い格子・コマ落ちの止めた時刻）で並べる。
- 明るさの急変の数を書き出しの最後に出す。
- 4K は時間がかかる（1080p の4倍強）。描き出しの途中で止まると mp4 が壊れるので、別名に書いて読めることを確かめてから置き換える。
- 渡すときは、どの版を見ているかをファイルの時刻で確かめてもらう。

## よくある指摘と直し方

| 指摘 | 直し方 |
|---|---|
| 映像が凝っていない | 曲全体で変わっていく仕掛けを1つ決め、色や広がりを最後の山まで取っておく |
| 枠から文字が出ている | 全編を描いてはみ出しを自動で検査し、あれば書き出しを止める |
| ドット絵が安く見える | 肩を丸く・頭を小さく・服に光と影。場面の光で塗り直す。手本と並べて拡大で比べる |
| PV と合っていない | PV をコマで測り、振り・跳ねの周期・まばたきを合わせる |
| 歌詞の区切りがおかしい | 区切りと折りを全行手で決める |
| カメラの揺れ・フェードがいらない | カメラは固定、出入りはグリッチだけ |
| YouTube でドットがつぶれる | 8倍（4K）で上げる |
