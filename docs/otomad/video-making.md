# 音MADの映像の作り方（桔梗☆・柴又系クッキー☆）

2本の音MADの映像を作って所有者から受けた指摘と、作りの数値を工程順にまとめる。

- 桔梗☆（11-08〜09）: 界隈曲「桔梗」のカバー。初代クッキー☆ → 一転攻勢で淫夢。花びらの窓。所有者「素晴らしい」で投稿（sm47024472）。1920x1080・30fps。
- 柴又系クッキー☆（11-15）: 柴又の型のオリジナル曲。材料屋の場面 → 一転攻勢で淫夢 → 二転攻勢で RRM。手本の動画の配置と効果を借りた窓＋小窓。1280x720・30fps。第7版まで直した。

手本の動画の真似を頼まれたときも、この文書と how-to-make.md §7 の作りは外さない。手本の置き方・動き方はこの上に足す（sz2〜sz5、11-18〜19: 手本だけを写して「何が鳴っているか」の絵が抜けた）。渡す前に、この文書の項目を1つずつ照らす。

ENU☆ で分かった映像の基本（ドット絵の倍率、字のせり上げ、点滅しない）は [how-to-make.md](how-to-make.md) の「7. 映像を作る」にある。ここはそれに足すことを書く。基準は [rules.md](rules.md)。

## 0. 作りの骨組み

どちらも同じ作りで、これが使い回せる。

1. 音を組むときに、**鳴った時刻と誰の何の音か**を出来事の一覧に書き出す（台詞・旋律・伴奏・低音・打楽器）。映像はこの一覧だけを見て動かす。音を直したら一覧も作り直されるので、映像がずれない。
2. 絵の素材は先に窓の大きさにそろえて置き場へ書き出し、一覧（名前 → ファイル）を作る。描画のたびに BB を切らない。
3. 1コマずつ PIL で描き、生の RGB を ffmpeg の標準入力へ流して、ミックスの wav と一緒に書き出す（H.264・yuv420p・AAC 256k。符号化の設定は `scripts/otomad/lib/venc.py`）。
4. 開始秒・終了秒を引数で取れるようにして、直した所だけ書き出して確かめる。時刻のリストを渡すとその時刻のコマを PNG で書く口も作っておく。
5. 音だけ直したときは映像を描き直さず、音を差し替える（`ffmpeg -c:v copy`）。

鳴った瞬間の反応は指数の減衰でつける: `p = exp(-(今 − 鳴った時刻) / τ)`、τ は弾み 0.08〜0.09 秒、光り 0.35 秒。大きさは `1 + 0.05〜0.10 × p`。

## 1. 窓の仕掛けを題材から作る

先駆者の動画がある曲は、先駆者の窓の並べ方と配役を測って**同じにしない**（桔梗☆の先駆者は横並び3窓と万華鏡）。

### 桔梗☆: 花びらの窓

- 桔梗の花の5枚の花びらを窓にする。花びら＝役（台詞・伴奏・旋律・低音・打楽器）、中央の丸＝区間の主役。
- 花びらの形は根元が細く、外へ広がり、先が尖る（幅 ∝ u^0.6 × (1−u)^0.38、u は根元からの割合）。開き o（0〜1）で長さと幅を変える。
- 鳴るたびに花びらが弾み（×1.07）、暗い膜が晴れて光り、ふちの線が太くなる（5 → 12 px）。鳴っていない花びらは 45% の明るさ。
- 区間ごとの動き（音の構成と1対1）:
  - 前奏はつぼみ → 主役が出る小節で、その花びらが 0.5 秒で開く
  - サビで全部開き、2小節ごとに 72° 回る（0.3 秒のイーズ）
  - UDK 詠唱でしおれて（開き 0.55）ゆっくり傾く → 一転攻勢の前の 3.5 小節で閉じる → 2拍の黒
  - 一転攻勢で地の色を替えて 0.15 秒で咲き直す。区間ごとに回り方を変える（逆回り、1小節ごとに 36°、2小節で1回り）
  - 最後のサビは外側にもう1重（36° ずらして 1.32 倍、後ろに）
  - 終わりは6小節かけてつぼみへ
- 地は中心から外へのグラデーション＋紙の粒＋うすい桔梗紋。初代は桔梗色、淫夢はアイスティーの琥珀色。花びらには影を落とす。

### 柴又系: 窓＋額＋壁紙＋小窓

手本の動画（sm45639945）の型を借りた。所有者「動画は sm45639945 の配置や画面効果を真似して」。

- 中央に窓（いま喋っている声の場面）、その後ろに鏡写しの額（旋律の声の主。絵の左上の四半分を上下左右に鏡写し）、いちばん後ろに壁紙（支える声の主の色、周辺を暗く落とす）。窓は黒ふち。
- 声の連打で、窓の絵が裏返し → 逆さ → 小さく → 菱形 と替わる。8分より細かい連打では替えない（速すぎる切り替えを避ける）。
- キックで中央からクリーム色の輪が広がる（0.36 秒で半径 150 → 450、太さは細っていく）。スネアで左右に弧。戸や割れる音は輪を3重に。
- 左右に小窓を4つずつ（左: 旋律・和音・粒・アルペジオ、右: 低音・裏拍・刻み・打楽器）。その音色の**元の台詞が流れている場面**を出し、鳴るたびに弾ませる。所有者「今何の素材が鳴っているのか表示するために小窓形式も併用」。
  - 旋律の音ごとに BB のコマを進める（喋る顔の口が動く、踊る SZ が踊る）。

## 2. 絵は「その音が流れている場面」から取る

所有者「アイコンみたいに表示する絵は、対応する音声が流れているシーンがよい」「クッキー☆は紙芝居なので抽出しやすいはず」。詳しくは [techniques/voice-icon-bounce.md](techniques/voice-icon-bounce.md)。

### クッキー☆: 本編と波形で照合する

- 本編を落とし、使っている台詞・伴奏・低音・効果音のファイル（本編の音から切ったもの）の時刻を探す。
  - 両方を 4 kHz に落とし、台詞の頭 1.2 秒で正規化相互相関（FFT の畳み込み）。窓のエネルギーに中央値の 0.3 倍の下限を付け、無音の所で割って当たりが跳ねないようにする。
  - 1位と2位の比（鋭さ）も記録する。当たりが弱いものは、話の順番から入るはずの範囲に絞って探し直す。
  - BGM 入りの本編では、600〜3500 Hz の帯域の包絡で照合すると低域に引っ張られない。BGM カット版の本編があればそちらで照合する。
- 当たった時刻に少し足した所（+0.38 秒）のコマを ffmpeg で1枚取る。場面の切り替わりでぼけるコマは人物ごとにずらす。下の台詞枠は切り落とす（高さの 76% まで）。
- 窓の比に切るとき、人物ごとに横の中心を決めて顔が切れないようにする。窓に出す絵を全部並べた一覧を1枚作って、顔が切れていないか確かめる。
- 伴奏の花びらは、小節ごとにいちばん多く鳴った素材の場面にする。音ごとに替えると絵が速く替わりすぎる。

### 淫夢: その声の場面の BB

- 立ち絵で済ませると「白い服のものになっていて違う」と言われた。声の場面の BB を使う: 野獣＝咆哮の顔、遠野＝気持ちよさそう（顔の寄り）、MUR＝そうだよ、GO の注文＝携帯をいじる、KMR＝嬉しそう、NSDR＝指さしまわる。
- 絵が手元に無い人物は、台詞ごと絵のある人物へ替える（AKNM → GO）。
- BB を窓へそろえる:
  - 四隅の色で青背景か緑背景かを決め、その色と他の2色の差で抜いて1画素縮める。
  - **全コマを通した枠で切る**。コマごとに切ると大きさが揺れる。
  - 背の高い絵（全身）は頭のあたりを正方形に取る。
  - 色の淡い BB（アイスティーのグラスの寄り）は彩度 1.8 倍・コントラスト 1.35 倍。
- 動きの BB は、鳴るたびに頭から再生するもの（打楽器・ベース）と、ずっと回すもの（踊り・笑顔）に分ける。
- 使わないもの: 裸の上半身が大きく映るコマ（ふてぶてしい・グラスを持つ・微笑）、使用例の題字と別の場面が混ざる BB、水着・タオルの絵。BB は全コマを一覧で確かめてから選ぶ。
- 淫夢の絵は画像も動画も強めに崩す（所有者「モザイクや、ぐにゃぐにゃ化」）:
  - 波の歪み: 行ごとに横へ2つの正弦の和でずらす（幅 24 px、位相は 1/6 秒ごとに進める）、暗い赤に寄せる
  - モザイク: キックで粗く（29 px）、0.12 秒で細かく（7 px）戻る
  - 小窓・跳ねる BB にも同じ処理

### 主役の層が薄いとき

本編に場面の無い持ちネタの台詞（同じ人物の素材フォルダから足したもの）は、その人物の BB（踊る SZ）のコマを出す。絵の無い台詞を空欄にしない。

## 3. 一転攻勢・二転攻勢の見せ方

- 前触れ: 数小節前に、画面の右下の隅へ暗い赤の小窓（歪み＋モザイクの淫夢の人物）を、小声の淫夢の台詞が鳴ったときだけ出す。
- 直前: 決め台詞 → 2拍の間、地を 35% まで落とす（桔梗☆は真っ黒）。花なら閉じる。
- 一転攻勢: 地の色を替える（桔梗色 → 琥珀色、和柄 → 暗い赤）。配置は同じまま中身だけ替える。淫夢の区間は字のふちの色も替える。
- 二転攻勢（柴又系）: 決め台詞「こんなもの」→ 割れる音で輪を3重に広げて元の作品へ戻る。額をその人物の BB にする。

## 4. 題材の飾り（音なしでひと目で分かる物）

字を使わず、物で題材を見せる。柴又系で京都を出すのに使ったもの:

| 飾り | 作り | 出す所 |
|---|---|---|
| 和柄の帯 | 上下 26 px、紫の地に金の七宝つなぎ（3倍で描いて縮める） | 全編 |
| 壁紙 | 青海波（同心円を半段ずつずらして敷く）を2色で、周辺を落とす。色は区間ごと | 全編 |
| 雑コラ | 主役の絵に立烏帽子・扇子（いらすとやから切り抜き）。絵ごとに頭のてっぺんとこぶしの位置を割合で持ち、扇は持ち手をこぶしへ合わせて回す | 主役の台詞 |
| 舞い落ちる物 | サビはイチョウ、Cメロは紅葉、二転攻勢は桜 | 区間ごと |
| 蹴鞠 | 区間の主役の BB を、キックからキックへ放物線（高さ 150 px）で左右に跳ねさせ、回す | SZ・淫夢・RRM の区間 |
| ふすま | 和紙の地・黒い縁・金の霞・丸い引手。節目の 0.3 秒前から閉まり、頭で閉じきって 0.35 秒で開く | 区間の節目 |
| 名所 | 千本鳥居（イントロ）、鹿威し（スネアで傾く）、五山送り火、お寺、ぶぶ漬け（終わり） | 区間ごと |

- 京都風の BB は「貴族／平安／麻呂／公家／舞妓／着物／和装／京都 × BB素材・クッキー☆・淫夢」で検索した。使えたのは和装の RRM（sm30661259）と喋る顔の RRM（sm27448500）。配役に合わない BB は使わない。
- 小物は描かずに素材から（BB → いらすとや）。

桔梗☆では、区間の頭で小さな花びら（8角の星形）を4小節かけて舞わせた。

## 5. 字

- 台詞は小節の頭から 1.5 秒＋長さに応じて（最大 3.4 秒、詠唱は 5 秒）出す。1字ずつ 35ms ずつ遅らせて、0.1 秒で下からせり上げ、最後の 0.25 秒で消す。
- 長い台詞は語の切れ目で2行に分ける表を持つ（「アイスティーしか／なかったけど良いかな？」）。
- 書体を区間で替える（初代は游明朝、淫夢は雁木フォント）。ふちの色も地に合わせる。
- 柴又系は字幕を入れなかった（窓と小窓で誰が喋っているか分かる）。題名はどちらも入れない。

## 6. 確かめる

- 全編を書き出す前に、窓に出す絵を全部並べた一覧を1枚作る（顔が切れていないか、裸や題字が混ざっていないか）。
- 区間の頭・一転攻勢の前後・効果ごとの時刻を指定して、コマを PNG で出して見る。
- 確かめられるのは止めたコマだけで、動き（弾み・回転・蹴鞠）は見ていない、と渡すときに書く。

## よくある指摘と直し方

| 指摘 | 直し方 |
|---|---|
| アイコンの絵が音と合っていない | 本編と波形で照合して、その音が流れている場面のコマを出す |
| 淫夢の絵が違う（白い服の立ち絵） | その声の場面の BB にする。無ければ台詞ごと替える |
| アイコンが空欄 | 同じ人物の BB を切り抜く。持ちネタの台詞は踊る BB で |
| 何が鳴っているか分からない | 左右に役ごとの小窓を並べ、鳴るたびに弾ませる |
| 淫夢の絵がそのまま | 波の歪み＋モザイクを窓・小窓・跳ねる BB の全部に |
| 京都らしさが無い | 字を使わず、和柄・雑コラ・舞い落ちる物・ふすま・蹴鞠で見せる |
| BB の大きさが揺れる | 全コマを通した枠で切る |
