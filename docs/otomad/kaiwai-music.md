# 界隈曲の音楽の作り方（あめふらし・エイ）

海鮮系の界隈曲を、所有者の歌メロから、または一から書いて、dtm の歌声と自作の伴奏で仕上げたときのノウハウを工程順にまとめる。映像は [kaiwai-video.md](kaiwai-video.md)。

- あめふらしがえきにおりてくる（11-02〜11-03）: 所有者の MML のサビ（33〜40 小節の歌メロと伴奏）を元に、ほかの区間・ソロ・対旋律・ハモリ・歌詞を手で足した。D#m、131 BPM。第1版から第10版まで直した。
- エイの回遊動線（旧題「あのエイがまたおよいでくる」、11-13）: 旋律・和音・歌詞・対旋律を全部手で書いた。あめふらしの続きの話。C#m、140 BPM、90 小節。伴奏とミックスはあめふらしの第10版の作りを写した。

カバー（あねもねぐりっち 束音ロゼ版）の録り方とミックスは [techniques/ust-cover.md](techniques/ust-cover.md)。流派の実測は [docs/research/kaiwai-lineages.md](../research/kaiwai-lineages.md)、歌詞の規則は [docs/design/lyric-design.md](../design/lyric-design.md)。

## 0. 流れ

1. 手本の原曲を YouTube から取って測る（音色・左右・帯域・波高率）。測るだけで git に入れない
2. 楽譜を書く（TypeScript で手書きの旋律を並べ、MML と音符の JSON を書き出す）
3. 声を dtm で録る（声部ごとに1体ずつ、乾いた声で）
4. 伴奏を楽器ごとの音に描き出す
5. 声と伴奏を混ぜ、仕上げる
6. 測って比べる（原曲と同じ物差し、音声認識で歌詞の聞き取り）

指摘はたいてい、原曲を測らずに決めた所から来た。迷ったら先に測る。

## 1. 原曲を測ってから音を作る

あめふらしの第2版（Surge XT の工場プリセット＋サイドチェイン＋長い残響）は「Suno で作ったみたいな AI 臭さ」「界隈曲の音色じゃない」と言われ、「YouTube の動画から調べたほうがいい」と指示された。耳コピの MIDI は音符は分かるが、音色の証拠にならない。

- 海鮮の代表曲を `python -m yt_dlp` で落とし、自作と同じ物差しで測る:
  - 左右の相関（全体と、400 Hz 以上の帯域ごとのコヒーレンス）
  - 帯域ごとの音量（低域は 90 Hz 未満・90〜250・250〜800・800〜2.5k・2.5〜6k・6k 以上）
  - 波高率、16分ごとの音量の揺れ（ドラムの抜け）
  - 中域の音の山と谷（刻みが途切れるか）
  - キックの基音、BPM（低域の立ち上がりの自己相関）
- 分かったこと（海鮮3曲）:
  - **左右がほぼ別物**。左右の相関 0.18〜0.57、400 Hz 以上のコヒーレンス 0.13〜0.43（第2版は 0.8〜0.98）
  - 高域は控えめ、波高率が大きい（潰していない）
  - キックの基音 41〜52 Hz
  - 中域の刻みはほぼ途切れない（段差 3 dB 以内）
- 所有者の書いた小節があれば、それも dtm で録って同じ小節を帯域ごとに比べる。あめふらしのサビは「浮遊感が足りない」と言われ、和音でなく 90 Hz 未満が所有者の版より 14 dB 多いのが原因だった（[techniques/audio-mix.md](techniques/audio-mix.md)）。
- 比べるための録音は曲の頭から 24 小節目付近まででよい（全体を録ると時間がかかりすぎる）。

## 2. 楽譜を書く

### 2.1 渡された旋律と伴奏は替えない

第1版・第2版は「私が提供した部分のクオリティに匹敵していない」と言われた。

- 所有者の和音・ベース・エレピは、音もベロシティもそのまま置く。半音のこすれを避けるために替えない。
- 和音を決め直すときは、サビの旋律の音が和音の音になるように半小節ずつ決める。所有者のサビの和音（G#m7 → C#7 → F#M7）は解決の途中から始まるので、旋律が着地せず浮いたままになる。これが浮遊感の元なので残す。
- 足す旋律は関数や移調で作らず、**手で書く**。手書きの記法を作っておく: `"D#5:3 C#5:1 r:2 | …"`（数は16分、`|` で小節を区切り、16 になるかを確かめる）。表の8分を強く、裏を弱く（所有者の v100/v84 と同じ付け方）。

### 2.2 区間の旋律の作り

海鮮の歌メロの実測（2度 56〜70%、音域 12〜21 半音）に入っているかを、書き出すたびに数える。

| 区間 | 作り |
|---|---|
| Aメロ | 四抜き（D#m なら F# G# A# C# D#）の8分を中心に、低い所で語る。2小節の句 a b c d、句末に息継ぎ。句は 12〜13 音 |
| Bメロ | 4分と付点で伸ばして引き、7小節目で高い所（C#6・D#6）まで駆け上がって、サビの弱起へ落とす |
| サビ | 2小節の句を4つ。同じ形を1段下で返すと覚えやすい。サビ後半の3句目だけ、1段上へ持ち上げて伸ばす新しい句に差し替える |
| Cメロ（落ち） | 小節を 3:3:2 で歩く同じ形を繰り返す。和音は長調側へ開く。伴奏を落として白玉、最後の2小節で8分に戻してサビへ |
| Dメロ | 低く語り、句の終わりを伸ばす。最後は属和音の上で止める |
| イントロの主題 | 1拍目から矩形波で始める。サビの形を先に聞かせる。5小節目からベースとエレピが入る |
| 終わり | 前半の句だけ弾いて、5度の音を伸ばす |

- サビの進行の例（エイ）: Ⅳ→Ⅴ→Ⅲm→Ⅵm を2拍ずつ、4小節目と7小節目の属7で短調へ引き戻す。あめふらしは最後を Ⅴ7sus4 → Ⅰm（A#7sus4 → D#m）で閉じた。
- 構成は場面ごとに長さを変えてよい。エイ: 声だけのサビ頭 4 → 主題 4 → A → 別の歌い手の場面 4 → サビ → 切れ目 2 → A（掛け合い）→ B → サビ×2 → 間奏 4 → 別の歌い手 4（水の中）→ サビ×2 → 終わり 4。

### 2.3 界隈曲の聞かせ所を全部入れる

第1版は和音の音を並べた刻みと固定形のアルペジオだけで、聞かせ所が無かった。

| 層 | 作り |
|---|---|
| 声の重ね | 下のハモリ: 主旋律と同じ言葉で、下の 3〜9 半音の和音の音。4・5度を優先（原曲の同時2声は 4〜5度 35%・3〜6度 27%）。上のハモリ: 上 3〜5 半音で、合わせて3声で和音を歌う。層は段階的に厚くする（サビ1は後半の2句から、最後のサビで3声）。主旋律のオクターブ重ねはしない |
| 裏の声 | 別の声がサビの偶数小節に8分4音で囁く（駅の放送） |
| サビの対旋律 | 矩形波。歌の隙間（8分休符）と伸ばす音の所にだけ、和音を崩した4音・8音を手で書く。歌が細かい小節は空ける。句ごとに頂点を上げる |
| 間奏のソロ | 歌の句を残し、歌が句1・3、ソロが句2・4で答える。四抜きで歌メロの句の家族から作る |
| キラキラ | オルゴールの16分アルペジオ。2オクターブに広げ、2小節で一巡りする波の形。イントロで主題の前に鳴らし、歌の中では1番サビの後から |
| ベース | ソーベース（大きめで支え続ける）。句の変わり目の最後の8分は、次の根音へ全音で入る音。Bメロは伸ばして裏で押す |
| サブベース | 1オクターブ下の白玉。ただし浮遊感を出したいサビ・間奏には入れない |
| エレピ | Aメロは裏8分の小さな刻み、Bメロは伸ばして4拍目に押す、サビ・間奏は 3:3:2 |
| パッド・弦 | Aメロ1・2は入れずに薄く。弦は Bメロで歌の上を半小節ずつ動く1本の線 |
| 高い持続音 | サビと間奏の上に、和音が変わっても動かない音（G#、合わない和音の小節だけ F#） |
| 生音の打楽器 | ウッドブロックのポコポコ。Aメロ2から、A とサビで合いの手の形を変える |
| 効果 | サビの前の1小節にシンバルの逆回し、イントロの頭と落ちの下に海の音 |

- エイの間奏のソロは、あねもねぐりっちの間奏を調べて作った: 16分の「回る形」を1段ずつ上げ下げして繰り返す／句の終わりに32分の連打／6連符で駆け上がってから長い音／7小節目で詰まり（16分×2 → 32分×2 → 64分×4）、8小節目で伸ばして半音で落ちる。上の声が旋律、下の声が3度か4度下の2声。
- 和音を積むときは、近い音に和音の音を積む。半音で隣り合う2音（M7 の7度と根音など）は下の音を1オクターブ上げてほどく。
- **こすれの点検**: 指定の長さ以上の音と、その時の和音の音が半音でぶつかる所、ハモリと歌が同時に半音でぶつかる所を数えて出す。

### 2.4 歌詞

詳しい規則は [lyric-design.md](../design/lyric-design.md)。

- ひらがなで1音符1モーラ。伸びる音は あ・い で終える（長く伸びる合唱は あ・い・う だけ）。
- 報告の形で、暮らしの場に海のものが入り、周回ごとに悪化していく。行末で韻を踏む。
- **聞き取りやすさを測って直す**: 身近な語と普通の文にする。は行・つ・し で句を始めない。題名の語は題名の句だけに残す。
- 掛け合いは行ごとに歌い手を替える（1・3行目と2・4行目）。

### 2.5 声の割り当て

- 主・下のハモリ・上のハモリ・裏の声を、所有者の指定の歌い手に割り当てる（あめふらし: 蓄音キリコ・束音ロゼ・革命シヨ・響化アル。エイ: キリコとロゼの2人だけ）。
- 歌い手を絞る曲では、同じ人が場面によって主を歌う（ロゼが別の側の声として主を歌う場面を2か所に割る）。

## 3. 声を録る

- 楽譜から声だけの MML を声部ごとに作り、dtm 本体の歌声合成で1体ずつ実時間で録る（`scripts/speech-melody/rec/make-dist-rec.mjs` の後で録る）。残響・コンプ・フェードは切って、乾いた声を取る。
- 録る道具のブラウザは、子のプロセスが残ってプロファイルを掴んだままになり、次の録音が始まらないことがあった。プロセスの木ごと終わらせる。
- 録った声は伴奏の格子から場面ごとに少しずつずれ、途中で飛ぶ。**句ごとに音符の位置へ置き直す**:
  - まず全体を、音符の頭と声の立ち上がりが最も重なる位置へずらす（録音は再生より先に始まる）
  - 休みで句に分け（短すぎる句は前へつなぐ）、句ごとに「音符の頭から8割は鳴っているほど良く、音符の無い所は鳴っていないほど良い」点数で位置を探す。音の切れ目の近くは問わない
  - まず場面の広い範囲で探し、前の句から離れすぎる答えは近い方を選ぶ
  - 主の声と重なる所で、ハモリとのずれを直接測って詰める

## 4. 伴奏を描き出す

第3版から、代表曲の実測に合わせて次の作りにした（エイも同じ）。

- **素の矩形波・鋸波・正弦波**（Surge XT の Init）を、**左右別々に鳴らす**。声部ごとに左右の位置と細かいずれ（cents）を決めて、描き出しの時点で左右を分ける。
- **プリセット・大きなサイドチェイン・広げる処理・長い残響は使わない**。カバーで「ガラッと変える」と言われても、この音の中で変える。プリセットを使うなら1音ずつ高さを測る（Magic Music Box は1オクターブ上で 10 セント低かった）。
- **ドラムは FluidR3**（所有者の MML と同じ）。キックは基音 40 Hz のもので、代表曲の 41〜52 Hz に合う。サビ用に低域を削った軽いキックを別に持つ。
- 和音の刻みは次の刻みまで伸ばす（代表曲は中域がほぼ途切れない）。Aメロの裏打ちだけ短めに残す。
- サビと間奏だけ低域を削る（所有者の小節の軽さに寄せる）。
- ドラムは場面で形を変える: サビの前の小節はスネアの連打で持ち上げ、最後の1拍は打楽器を止めて弱起を聞かせる。サビは5小節目で開く（シンバルを足し、前半は細かいハットを抜いておく）。細部としてサビ後半の偶数小節にキックを1つ、4小節ごとの終わりに32分のハット、弱いゴーストのスネア。
- 声だけのサビ頭はドラムなし、最後の小節の後半だけスネアを転がして主題へ。サビの直前は伴奏を抜いて歌の入りを聞かせる。
- 楽器ごとに 48 kHz の左右 32bit の生データで書き出し、ミックスで読む。描き出しは決まった乱数で、作り直しても同じ音になるようにする。

### 効果音を楽器の役にする（エイ）

効果音はどれも拍の格子に置き、楽器の役を持たせる。

| 効果音 | 役 |
|---|---|
| 泡（正弦波の高さが跳ね上がる短い音） | 高さを和音の音にして、分散和音として鳴らす |
| スイッチの「カチッ」 | リムショット。Aメロで毎小節の 10、偶数小節は 7 も |
| 猫の鳴き声 | 素材の高さを基準に速さを変えて移調し、音階で鳴らす。歌の句の休みに和音の音で相づち、切れ目では主旋律、間奏はソロの合いの手 |
| 犬の吠え声 | スネアの位置（2・4拍）、サビ前はスネアの連打と同じ位置 |
| 鳥のさえずり | 4つに切ってハットの代わりに刻む（16分の型、裏8分に重ねる） |
| カラスの「カァ」 | 区間の頭でシンバルに重ねる |
| 駅のチャイム（正弦波のベル） | 曲の最後（発車） |
| ファンファーレ（鋸波を重ねた金管ふう） | 切れ目で属7を吹いて2番へ、最後のサビの後半の入りに主和音 |

## 5. 混ぜて仕上げる

- **パートの音量は鳴っている所の大きさで揃える**（パートごとに目標の LUFS）。
- **場面の大きさを付ける**: パートを揃えただけだとどの場面も同じ大きさになる。A は引いてサビで開く、を場面ごとの足し引きで作る。
- **歌っている間は、声の帯域だけ伴奏を少し空ける**（動的な EQ の代わりに、中域を分けて下げる）。
- **滑舌**: 子音の帯域を伴奏に埋もれさせない。
  - 声には仕上げの高域カットを掛けない（4.5 kHz と 9 kHz より上の削りは伴奏だけ）
  - 声の 4〜5 kHz を少し上げる
  - 歌っている間はハイハットの 5〜10 kHz も少し空ける（さ行・た行・か行とぶつかる）
  - 歯擦音は 5〜10 kHz が大きい瞬間だけ全体を少し下げて抑える
- **声を束ねる**: 主の声に薄い左右の重ね、付点8分のディレイ、残響。サビの2句目と4句目の最後の音だけを、左右に跳ねる付点8分の遅延へ送る。
- 低い所は真ん中に寄せる（サブの位相を崩さない）。キックに合わせて少し下げる（小さく）。キックの頭を丸めて、リミッターが全体を押し下げる量を減らす。
- 残響は8本の遅延線を行列（Householder）で混ぜる FDN。高域ほど早く減衰させる。
- 場面の効果: 水の中の場面（落ち）の頭で伴奏を 650 Hz まで閉じ、後半4小節で開く。終わりの2小節は閉じて沈める。声と泡には掛けない。
- **仕上げ**: 音色を整える → 全体を軽く締める（比 1.5）→ 歪みで密度を足す → 先読み 5 ms のリミッター（最小値を取り、同じ長さの移動平均でならしてから掛ける。急な段差が新しいピークを作らない）。ピークは4倍オーバーサンプルで見る。目標の大きさになるまで入力の大きさを合わせる。頭と終わりをなめらかにし、無音の尻を切る。
- 代表曲3本の帯域と比べて、出すぎた所を削る（エイでは 400〜800 Hz と 3〜6 kHz が 3〜4 dB 出ていた）。2〜6 kHz は原曲を超えないようにする（あねもねぐりっちで「高音によっていて耳が痛い」）。
- 目安: −12.7 LUFS、ピーク −1.3 dB。
- 書き出しと一緒に、声ごとのずらし量・パートごとの大きさ・全体の測った値を報告のファイルに残す。版を比べるときに使う。
- 仕上げ前のパート別 WAV（24bit 48 kHz）も残す。所有者が別に混ぜ直せる。

## 6. 確かめる

- 耳で聴けないので測る:
  - 原曲と同じ物差し（左右の相関・帯域・波高率・中域の途切れ）
  - 歌メロの2度の割合と音域、こすれの数
  - 区間ごとの LUFS とピーク
- **音声認識で歌詞の聞き取りを測る**: 歌の句ごとに音声認識（faster-whisper の large-v3）にかけ、書いた歌詞とモーラでどれだけ一致するかを出す。人の耳の代わりではなく、版を比べる物差し。混ぜる前と後で比べると、伴奏に埋もれた句が分かる。
- 渡すときは、変えたこと・測った値・確かめていないこと（耳で聴いていない）を分けて書く。

## よくある指摘と直し方

| 指摘 | 直し方 |
|---|---|
| Suno っぽい・界隈曲の音色じゃない | プリセット・サイドチェイン・広げる処理・長い残響をやめ、素の波形を左右別々に。原曲を測って比べる |
| 提供した部分のクオリティに匹敵していない | 渡された和音と伴奏を替えず、足す旋律を手で書く。声の重ね・対旋律・キラキラ・ソーベース・生音の打楽器・ソロを全部入れる |
| 浮遊感が足りない | 低域の量を測る。サビと間奏のサブベースを抜き、ベースとキックの低域を削る。解決しない和音を残す |
| 高音によっていて耳が痛い | 2〜6 kHz を原曲以下に |
| 歌詞が聞き取れない | 身近な語にする、句の頭の音を選ぶ、声の帯域を空ける、声に高域カットを掛けない。音声認識で測る |
| 声が伴奏とずれる | 句ごとに音符の位置へ置き直す |
