# ロイドとオクターブで声を太くする

- 台詞を歌メロへ合わせた声は、そのままだと伴奏に消えやすい。同じ読みをロイドに歌わせて重ね、上下オクターブも足す。

## やり方

- 音源: dtm の `.koe`（`src/voice/lyrics.ts` の `KOE_BASE_URL`）は先頭 `KOE\0`、4 バイトの長さ、JSON（sampleRate と phonemes の offset・length・pre・pitch）、16 ビットの波形。淫夢の50音は `【INM】シンセ.zip` の `50音(まさゆきロイド)` など（`AI/淫夢/パック/` へ展開、名前は cp932）。
- 1音ごとに子音は等倍、母音を音符の長さまで TD-PSOLA で伸ばす。音の頭は `pre` のぶん前へ置く。ロイドの元の高さと歌メロの差はオクターブ単位で寄せる。
- 無い音は近い音で代える（ぱ→ば、じゅ→じ＋ゆ）。`ー` は直前の母音、`ッ` は休み。
- 重ねる量の目安（台詞の本体を 0 dB として）: ロイド −3 dB、上下オクターブ −9 dB。
- 子音: モーラの頭 60ms だけ 2.4 kHz 以上を足す。フォルマント: TD-PSOLA の粒を伸縮する（上げると抜け、下げると太い）。
- 伴奏は声の間だけ 280 Hz〜6 kHz を下げる。低音は下げない。

## 試した作品

- ENU☆（11-05）: 第2版は声が伴奏に消えたと指摘された。上の処理で 1〜4 kHz の差が +13 dB になった。評価は未確認。

## はまりどころ

- 音声認識の一致はロイドを重ねるほど下がる。声が前に出たかの判定には、帯域ごとの音量差も合わせて見る。
- ドット絵のアセットは 4 倍で描き出されていることがある。風景に置くときは 1 点へ戻して格子を合わせる。
