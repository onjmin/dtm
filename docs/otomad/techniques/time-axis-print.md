# 括弧の時間軸に場面を刷る

- 画面は紙と1組の括弧だけ。括弧の中を時間の軸にして、音が鳴った時刻の位置に、その音の本編の場面を1ビットの網点で帯状に刷る。鳴っていない所は紙のまま残す。
- 題が記号の曲（「[ ]」）で、題の記号そのものを唯一の図形にする。字を出さずに題と「今何が鳴っているか」を見せる。

## やり方

- 色は3つだけ: 紙（236, 232, 221）、墨（18, 18, 20）、朱（232, 64, 28）。紙には ±4 のざらつきを毎コマ足す。
- **時間の軸**: 括弧の内側の幅を、区間ごとに決めた長さ（1〜2 小節）に当てる。窓の頭は小節に合わせ、窓が替わったら前の刷りを消す。曲を組む側が書き出した一覧（鳴った時刻・長さ・誰の何の音）だけを見て描く。
- **刷る**: 台詞のモーラ（または音符）ごとに、その時刻から長さの分だけの縦の帯を作り、帯の中に本編の場面のコマを置く。コマは灰色にして 1 ビットにする。刷り方は4種を持つ。
  1. 4×4 の Bayer の組織的ディザ（画素 3 px）
  2. 1 の白黒反転
  3. 横の万線（周期 9 px。明るさで線の太さを変える）
  4. 粗い網（画素 6 px）
- **場面の取り方**: 台詞ごとに、本編の音声と台詞の波形を 4 kHz で正規化相互相関し、当たった時刻のコマを取る。コマの下の台詞枠は切り落とす。当たりが弱いもの（相関 0.5 未満）は場面を出さず図形だけにする。
- **区間ごとの変化**（緩急を絵で付ける）:
  - 開く: 小さく閉じた括弧が、モーラが進むぶんだけ開く。
  - 種類を回す: 4 小節ごとに刷り方を替え、後半で朱の版ずれ（数 px ずらした朱の刷り）を重ねる。
  - 割る: 括弧を2組並べ、話す人ごとに左右へ刷る。
  - 反転: いちばん強い区間で地を墨に返し、白で刷る。
  - 消す: 決め言葉（「無い」）で、その帯を消して紙に戻す。
  - 閉じる: 終わりは括弧が1小節ごとに縮み、最後の1語で閉じて紙だけになる。
- **全編で1枚だけ色**: 伴奏を止める所で、小さい括弧の中に本編のコマを1枚だけ色のまま出す。白黒で通した後なので、それだけで山になる。
- **楽器の帯**: 上と下の細い帯を、伴奏の楽器の打点に使う（ドラムは墨の四角、声の楽器はその声の場面の小さなコマ、伸ばす音は線）。余白を崩さずに「今何の素材が鳴っているか」（[../video-making.md](../video-making.md) §1）を見せる。
- **拍**: キックで括弧の太さを 10 → 16 px に膨らませ、0.07 秒で戻す。
- 描画は PIL と numpy で1コマずつ作り、生の RGB を ffmpeg へ流す。書き出しは NVENC（[../../../scripts/otomad/lib/venc.py](../../../scripts/otomad/lib/venc.py)）。音だけ直したときは映像を描き直さず `-c:v copy` で音を差し替える。
- 作品の描画のスクリプトは手元だけ（`songs/kakko` の映像の組み立て）。使い回すときに `scripts/otomad/lib/` へ出す。

## 試した作品

- kakko1（「[ ]☆」、11-13）: 作り方の全体は [../material-cover.md](../material-cover.md)。評価はまだもらっていない。6 秒ごとの動きを測ると、サビより後奏の方が大きかった（サビの強さは反転と音量で付けた）。

## はまりどころ

- 窓の切れ目は小節の線に置く。区間の境目が拍の途中にあると、どの窓にも入らない時刻ができて落ちる（止めの区間の頭を区間の境目と同じ時刻にして直した）。
- 1 ビットにした場面は、元が暗いと墨の塊になる。刷る前に明るさを伸ばす。
- 余白の画面は止まって見えやすい。打点・括弧の拍・ざらつきの3つで、紙だけのコマでも動きを残す。
