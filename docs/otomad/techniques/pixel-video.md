# ドット絵の歌動画（界隈風）

- 黒地のドット絵・縦書き歌詞・拍で変わる光る箱という界隈の型で、カバー曲の動画を自前の描画（PIL）で組む。そのときの見せ方と、所有者に「バグ？」と言われた型。

## やり方

- **型**: 原曲の動画の型に合わせる。平らな背景や、増えていく群れは「AI slop 臭い」と言われた。背景は油絵風のドット絵にし、群れは実際に鳴っている声の数だけ出す。
- **原曲の動き**: 推測しない。YouTube の video を canvas に写してコマ送りで測る。
- **顔**:
  - 瞬きは不規則に 4〜7 秒ごと。
  - 驚きの顔は「><」にする。白目に点は「怖い」と言われた。
- **場面**: シーンチェンジは場面ごとに選ぶ。周回する物は、奥側をキャラの裏に描く。
- **歌詞**: 歌ったモーラまで白くする（[lyrics-text.md](lyrics-text.md)）。左右に語り掛けるパートは歌詞も左右に出す。
- **合唱**: 合唱する子の頭上に、担当の音の度数を縁取り文字で出す。出すのは歌っている間だけ。切り替わりで数字を少し跳ねさせる（数コマで 2〜3px 上げて戻す）。
- **間奏**: 間奏は「○○間奏」の札と、その声部の流れるピアノロールで見せる。
  - 手本は unj-reze の `lib/mv/mv-engine.ts` の `drawPianoRoll`。
  - 再生位置は左から 25%。未来の音は薄くする。
  - 音の頭で白く光らせ、元の色へ戻す。輪郭は広がって消える。
- **小物**: 靴が飛ぶ場面では片足を肌色にする。

## 試した作品

- 海鬼月カバー（11-03）: 上の型で作り、バグの型は下のとおり直した。

## はまりどころ

- **流れる背景と固定物のずれ**: 背景を場面のあいだ流すなら、背景に描いた光と重ねる物（月・その映り・標識）も同じずらし量で動かす。背景の関数がずらし量を返すようにしておく。
- **縮めた絵の固定寸法**: 大きさを変えて描く物（遠ざかるバス）は、窓・扉・車輪も同じ比で縮める。固定の px だとはみ出す。
- **合唱の担当がずれる**: 声を子に割り当てるときは、鳴り始めに決め、鳴り終わるまで動かさない。毎コマ低い順に並べ直すと、ある声が止んだときに担当がずれ、表示が一瞬だけ出て見える。間引きや出しっぱなしは原因の対処ではない。
  - 同時に鳴り始めた音は低い順に左から割り当てる。
  - それ以外は、直前の音が最も近い子に割り当てる。
