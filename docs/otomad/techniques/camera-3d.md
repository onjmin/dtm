# 3D のカメラ（全天球の地面投影・板の向き・被写界深度・リプレイ）

- 全天球写真から 3D の闘技場を作り、立ち絵の板をその中に立ててカメラを動かす。平たい横滑りの絵を出さないための器。
- 手本の撮り方は [research/bb-theater.md](../research/bb-theater.md) の「バトルクッキー☆の撮り方」。

## やり方

- **地面投影**: 全天球写真を球に貼り、下半分を平らな地面へ投影して、板の足元が地に着くようにする。
- **板の向き**: 素材の左右向き（例 RU 80=左, RU 81=右, YJ_rush=左）と移動方向を一致させる。後ずさり（ムーンウォーク）を出さない。切り返しでは向きを守る（味方は左から右、敵は右から左）。
- **Z 軸の動き**: 奥から手前への巨大化ダイブ、手前から奥のビルへのキリモミ吹っ飛び、高度に連動した床の影。
- **カメラワーク**: 回り込み（オービット）・追い撮り・肩越し（手前に大きくぼかした背中、奥に小さく相手）・360° 弾丸時間・ドリーズーム・見下ろし／見上げ。溜めはゆっくり寄る。
- **ショットの大きさを極端に振る**: 豆粒の引きと、目・拳・足だけの寄りを交互に。
- **被写界深度**: 手前と奥をぼかし、ラックフォーカスで視線を移す。
- **リプレイ**: 決着を3角度で見せ直す。

コード: bb8 の `*_video.py`（手元の `songs/bb/`）。次の作品で使い回すなら `scripts/otomad/lib/` へ出す（[../README.md](../README.md) の「移し替えの残り」）。
