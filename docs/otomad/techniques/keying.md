# 青背景・緑背景の抜き方、字幕の消し方

- BB素材（ブルーバック・グリーンバック）を透過の連番 PNG にする。集める・落とす・貼るまでの手順は [../bb-flow.md](../bb-flow.md)。

## やり方

- 地の色を画面の縁から推定し、色差（Cb・Cr）で抜く。明るさのむらに強い。
- 縁を 1px 削ってぼかし、地の色のにじみ（青なら青の成分が他の 2 色を超える分）を消す。
- 道具: `scripts/otomad/tools/bb_fetch.py key`。

| 見えたこと | 直し方 |
|---|---|
| 地が残る | `--color 0000FF` で地の色を渡す。`--tol` を上げる |
| 絵の中まで抜ける（青い服・緑の髪など） | `--tol` を下げる |
| 縁に地の色の線が残る | `--erode 2` |
| `bbox` が画面全体になる | 黒い頭出しや字幕のコマが入っている。`--ss`・`--to` で外す |

- 字幕の消し方: 手元の作品メモにある方法を写す（未記入）。
- 背景が単色でない実写は、この道具では抜けない（人物を切り抜くモデルが要る。未試行）。
- パックに透過済みの PNG があればそちらを使う。
