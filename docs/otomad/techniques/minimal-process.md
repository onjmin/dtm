# ミニマル音楽の手順を見せ場にする

- ライヒの手順（2人が同じ音型からずれる phase、休符を1音ずつ埋める substitution、1人ずつ抜ける）で、声だけの曲を組み、映像は鳴っている音と1対1の楽譜にする。

## やり方

- テンポは核にする台詞に合わせる。歌っている台詞は WORLD で音程と1音の長さを測り、調とテンポをそこから決める。
- 声の楽器: 声の立ち上がり 30ms で共鳴器を叩いたマレットに短い母音を混ぜる。声の息は母音の芯を伸ばして sin の山にかける。太鼓は子音の頭とサイン波を重ねる。
- ずれ: 1脈分を1小節かけて前へ動かし、次の1小節は揃えて止める。
- 埋める順は、拍の頭 → 遠い音 → 間の音にすると、最後まで何の台詞か分かりにくい。
- 映像: 全音符の表（events.json）から楽譜を描く。紙・墨・朱の3色と 60px の方眼に絞り、顔は網点にする。

コード: 手元の `scripts/otomad/songs/cookie/cm18_build.py`・`cm18_video.py`。

## 試した作品

- cm18: 所有者の評価待ち。

## はまりどころ

- WORLD の f0 を一定にするだけでは高音が暗い。4.5 kHz から上を少し持ち上げた。
- 素材の中に長い詰め合わせの音声が同じ名前で混じる（ICG「1.飽きちゃった」は 35 秒）。使う前に長さを見る。
- 正規化パックの顔は大きさが揃っていても、全身と胸から上が混ざる。透過の外接矩形の上から正方形に切ると、頭に寄る。
