# 声の音程の糸をワンカットで飛ぶ MV

- 実際の声の音程から引いた1本の線を 3D の空間に置き、カメラを切らずに全編その線を追う。音の高さと映像が1対1になる。

## やり方

- **世界の座標**: 横は曲の時刻（1 秒 430）、高さは出力後の声の MIDI（1 半音 17）。モーラの字をその位置に立てる。
- **字の量**: 今のモーラだけ大きく光らせ、先の字は小さく薄く、過ぎた字は 1 秒ほどで消す。全部同じ強さで出すと重なって読めない。
- **カメラ**: 小節のキーで「後ろ・上・横・先を見る距離・傾き・画角」を補間する。横から見ると音程の線がそのまま譜面になり、後ろからだと線の中へ飛び込む。
- **色の解放**: 途中まで人の絵を網点の1色刷りにして、山場で初めて色を出す。
- **枠を破る**: 窓の中に世界を閉じ込め、山場でギザギザの多角形に広げて全画面へ。窓の外には札・縦書きの歌詞・16分の札を置く。
- **筒**: 絵を対数極座標（`v = 326 * log(r)`、横 2048 のとき等角）で貼ると、引き伸ばされず、顔が渦に連なる。`1 / r` だと端が流れてしまう。
- **台詞に応じた仕掛け**: 「すべる」で字が落ちる、「ストップ」でカメラが1拍止まって追いつく、「踊れ」で字が跳ねる。

コード: 作品のスクリプト `scripts/otomad/songs/cookie/cm24_mv.py`（手元）。床はレイで求めて半分の解像度で描くと、傾けても速い。

## 試した作品

## はまりどころ

- 視線が線とほぼ平行だと、続くモーラが同じ場所に重なる。サビは鳴っている字だけ残す。
- 人の板はカメラと反対側に立てる。同じ側だと画面を覆う。
- 窓を早く狭めると、並んだ人が切れる。人の並ぶ幅より先に狭めない。
