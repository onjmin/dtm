# 語録をモーラごとに直す

- 語録は録音の質がまちまちで、環境音や小さな声のまま音高を動かすと耳障りになる（所有者 11-05）。HSK のようなきれいな声にも同じ処理をかける。

## やり方

1. 環境音を引く。静かな 12% のフレームからノイズの形を測り、短時間フーリエ変換でスペクトルから引く。残す量の下限は −22 dB。SNR が低い素材ほど強く引く。
2. 言葉の間を切る。20ms の音量がピークの 9% を下回る所を落とす。環境音が大きい TNOK「おいゴルァ免許見せろ！」は、言葉の間がピークより約 65 dB 下がった。
3. モーラに分ける。音の変わり目と音量の谷に加えて、カ・サ・タ行は有声から無声に変わる所、ナ・マ・ラ行などは音量の下がる所を手がかりにする。男声は高さの読み取りの下限を 55 Hz にする（90 Hz だと読み違える）。
4. 音符へ合わせる。伸ばすのは母音だけで、子音はそのままの長さで残す。音高はフレームごとに音符へ合わせる（所有者 11-05「モーラごとに分割して伸縮も調整してメロディにちゃんとピッチ調整」）。外れ値は読み違いなので補正に入れない。
5. モーラごとに音量をそろえる（−6〜+4 dB）。そのあと飛び出す音節を行の中央値 +3 dB までに抑える。
6. 長さの上限。語尾の無声音は長く伸ばさない。男声の語録は 1.3 倍までにして、余りは繰り返す。

## 試した作品

- ENU☆（11-05）: SNR が低かったのは DB「やべぇよ…」7 dB、NYN「かわいい声でないじゃん」11 dB、DB「悪くないです」13 dB、TNOK「おいゴルァ…」14 dB。評価は未確認。耳では聴いていない。

## 高音を削る

- ローパスのカットオフ: 打楽器 6.5 kHz、声 9 kHz、音圧を上げる部分 10 kHz。ENU☆ は 8〜12 kHz が手本より 2〜4 dB 多かった（手本 −20〜−24 dB、ENU☆ −18.6 dB → −24.5 dB。帯域の割合）。
- 打楽器はピークでそろえると尖った音だけ小さく聞こえる。40ms の音量でそろえる。ピークより 19 dB 小さい素材もあった。
