# 文字PV・モーラの字幕・ト書き・札

- 台詞の文字を画面に打ち込んで見せる技。根拠は [research/inmu-cookie-staging.md](../research/inmu-cookie-staging.md) の「文字PVの作り方」。

## やり方

- **字はモーラが鳴る瞬間に1字ずつ出す**。語ごとに出すと、伸ばしたモーラの字が音より先に見える。単語ごとは没入感が強いが、半拍ずれると行ごとより見苦しい。
- 1行は画面幅の 70〜85%・最大2行。日本語字幕は1秒4文字が目安（6文字まで負担は変わらない）。強い見せ方は最も強い1〜2行に限る。
- 単色の地と太字。フォントは1〜3種、合いの手は縁取りだけで本文と分ける。
- 文字は動いた後に読める静止時間を取る。
- **括弧のト書き字幕**:「（迫真）」などを1拍遅れで出す。1曲で数回まで。
- **漢字1字の札**: 区間の頭で中央に出し、区間見出しにする。
- **音の高さの位置に字幕**: モーラごとの字を音の高さに合わせて縦に置く（2号「表情をつけられた歌声」の型、[research/nigo-video-research.md](../research/nigo-video-research.md)）。
- 語呂合わせ（114514・810・1919）を時刻・数値に隠す。

## 試した作品

- dande3: 画面を台詞の文字で埋め、16分ちょうどに単語を打ち込む。札・ト書きも使用。止め→サビ2は良い。1回目のサビ前の引き算が無い、B で目立つ要素が4つ、A・B がスライドショー化、オチ前の1拍の止めが無い（[research/inmu-cookie-staging.md](../research/inmu-cookie-staging.md)「dande3 を照らした結果」）。
- ENU☆: 声の無い人物だけ字体と色を変え、問いの後に字で返事をさせる（台詞の字は太いゴシック、返事は明朝の緑）。字が遅れて追う・字が雨になって落ちる・暦のマスが音で埋まる、など台詞の意味から動きを決めた。評価は未確認。
