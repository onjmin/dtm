# 台詞の抑揚をそのまま主題にする

- 耳に残る旋律を先に作って声を曲げるのでなく、短い語録の中から、もともと音階にきれいに乗るものを探して主題にする。動画の 0 秒から鳴らす（所有者 11-05「開幕耳に残るようなメロディ」）。

## やり方

1. 筋に合う 1 秒前後の語録を候補に挙げ、モーラごとの音高を測る（`scripts/otomad/lib/mora_voice.py` の `boundaries`・`mora_pitch`）。
2. 音高の並びを見て、どの長調にも短調にも合わせずに、並びが度数としてきれいになるものを選ぶ。上下の動きが 4 度以上あるものほど覚えやすい。
3. 音高はほとんど動かさず（`fit` の `keep=.5`）、長さだけ小節へ置き直す。3-3-2 のようにはねるリズムにすると、話し声のまま歌に聞こえる。
4. 主題の音が全部和音の色になる和音を選ぶ。伴奏に合わせて主題を変えない。
5. 高い鈴の音でうっすら主題をなぞり、次の小節に答えの合いの手を置く。主題と答えで 2 小節にして繰り返す。

## 映像と揃える

- 主題の字を LED のように字ごとに出す。
- 音に連動するアイコンは、場面の中の物にすると邪魔にならない（エレベーターの操作盤のボタン）。

## 試した作品

- cm25（11-05）: TIS「更なる高みへ」が変ニ長調の 1 1 5 3 / 2 4 3 1 だった。128 BPM で 1 小節へ置き、Gbmaj9 の上で鳴らす。音声認識では主題だけの所は読めるが、全部入りの所は崩れる。評価は未確認。耳では聴いていない。

## はまりどころ

- 無声で始まるモーラ（「さ」）は高さを読み違えて低く出る。`fit` では読み違いの飛びを揺れに入れないが、音符の指定は読みで確かめる。
- 物音を楽器にするときは、いちばん強い部分音で高さを決める。チーンは部分音が 2015・3728・5809 Hz で倍音の関係になく、下げると少し濁る。
