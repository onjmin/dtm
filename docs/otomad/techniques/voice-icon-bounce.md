# 声のアイコンを弾ませる

- 今鳴っている声・キャラのアイコンを画面に出し、モーラの頭ごとに弾ませて震わせる。音MADらしく見える（所有者 11-05）。

## やり方

- アイコンは決まった場所に置く。音の高さの位置には置かない（所有者 11-05「ピッチの位置じゃなくて単にリズムに同期させて振動させたりするだけでそれっぽくなる」）。
- モーラの頭から 0.09 秒で減衰する動きを、拡大 1.3 倍・上へ跳ねる・左右の小刻みな揺れに使う。
- 合唱は人数分を横に並べ、声が切れたら 0.45 秒で消す。
- 顔は絵の上部を丸く切り、輪を人物の色にする。声の無い人物には鳴らさない。

## 絵はその音声が流れている場面にする（桔梗☆、11-08）

- 所有者「アイコンみたいに表示する絵は、対応する音声が流れているシーンがよい」「クッキー☆は紙芝居なので抽出しやすいはず」。
- 初代クッキー☆の本編は sm9720246「【東方合同動画企画】魔理沙とアリスのクッキーKiss」（29 分 39 秒）。`bb_fetch.py get sm9720246 --genre クッキー☆` で AI/クッキー☆/BB/ へ。前半の約 270 秒が神社の場面（立教大学前まで の RU・UDK・HNS・YMN）、そのあとに 0068〜0445 のドラマが番号順に並ぶ。
- 時刻の出し方: 本編の音を 4 kHz にし、台詞のファイルの頭 1.2 秒と波形の相関（窓の大きさで割る）で最大の所。無音の窓で割ると値が爆発するので、窓の大きさの下限を中央値の 0.3 倍にする。包絡（帯域の大きさ）での照合は外れが多かった。当たりの鋭さ（2 番目との比）が 1.5 未満のものは、番号の前後から入るはずの範囲に絞って探し直す。
- コマは時刻 +0.5 秒（台詞の 4 割まで）。下の字幕帯（約 18%）を落として正方形にする。暗転の中で鳴る効果音（ドンッ）は、絵のある近いコマ（2 秒前）にする。
- 花びらは人物ごとでなく役ごと（台詞・伴奏・旋律・低音・打楽器）にし、鳴った素材の場面を出す。伴奏は小節ごとにいちばん多く鳴った素材の場面にして、絵が速く替わらないようにする。
