# 音量の上下・ダッキング・ラウドネス

- 声と伴奏のどちらを上にするかは型で決まる。書き出しのラウドネスはそろえる。

## やり方

- **2号式**: 曲が上。生の台詞が鳴る区間で 声 − 伴奏 = −5〜−12 dB（[research/nigo-mad-analysis.md](../research/nigo-mad-analysis.md) §4）。
- **台詞イントネーション作曲・カバー**: 台詞が主旋律なので、声が鳴っている所で声を伴奏より 3 dB 上にする（`kaisen_mix.py`、[speech-melody/README.md](../../../scripts/speech-melody/README.md) §9-2）。
- **ラウドネス**: -16.0 LUFS / True Peak -1.5 dBTP（EBU R128 準拠）。耳に刺さる高域・過大低音を切り、突発的な音割れを無くす（bb7）。
- **緩急**: 音も区間で3段以上に分ける。映像だけ段を付けて音が平らなのは失敗（dande3 は 12〜84 秒がずっと −11 dB）。
- 台詞の層（voice.wav）にはリバーブ・圧縮・音量の自動調整をかけない（§9-4）。

## 試した作品

- samsonnigo1: 台詞 +3 dB → 2号式としては逆。
- dande3: 音が平ら → [rules.md](../rules.md) の緩急に足した。
- bb7: -16 LUFS / -1.5 dBTP。

## 声を一括で持ち上げる釣り合いが、個別に下げた音量を打ち消す（海鬼月）

- 「声 − 伴奏 ≈ +1 dB」の自動の釣り合いを、ある声（主役）の鳴っている所で、音量を当てたあとの声で測っていた。主役を −2→−4→−6 dB と下げても声全体がその分持ち上がり、主役の大きさはほぼ変わらなかった。「もう少し小さく」を 4 回言われた。ログの一括の持ち上げ量は +3.6→+5.4→+8.6 dB と増えていた。
- 直し方: 釣り合いの基準は、調整する音量から切り離した固定の重みで測る。
- 測り方を変えたら、ほかの声を前回の書き出しと同じ大きさに戻す。ほかの声まで動かさない。
- 声ごとの音量を変えたら、一括の持ち上げ量が動いていないかログで見る。

## 飾りの楽器（海鬼月）

- 飾りの楽器を主旋律並みの音量にしない。鉄琴は「金切り」と言われた。
- 合成のベルも鉄琴に聞こえた。合成音より sf2（GeneralUser GS）の録音を先に試す。海鬼月では最後に Music Box にした。

## 緩急を残して −16 LUFS にそろえる（bb17）

- `loudnorm=I=-16` を1回だけかけると動的モードになり、静かな所を持ち上げて緩急を消す（bb17 の題字が −34 dB のはずが −16 dB になった）。全体のゲインだけ動かす: `ebur128` で測った値との差を掛け、はみ出す所だけ柔らかく抑える。
- 急な立ち上がりの効果音（ノイズ入りの thump）は AAC にするとピークが大きくはみ出す（書き出す前 0.68 → 後 1.0）。ノイズを減らして数十サンプルならすと収まる。確かめるのは wav でなく、書き出した mp4 を戻した音。
