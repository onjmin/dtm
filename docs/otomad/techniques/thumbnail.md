# サムネと題

- 本編から切り出さず、専用のコマを作って動画の末尾に1秒足す。`thumbnail.png` にも書き出す。作例は `dande2_video.py` の `thumbnail()`。

## やり方

- 伸びたクッキー☆音MAD（LAB=01☆・論理空軍☆など12本）に倣う: 字はほぼ載せない（12本中2本、それも動画の中の題字）。表情のはっきりした顔を2人ほど、画面からはみ出すほど大きく寄せ、色を濃くして画面いっぱいに描く。白い縁取りで立ち絵を行儀よく並べると「ダサい」。
- 素材の透過 PNG を使い、切り抜きの縁が画面の中に出ないように置く（四角い背景付きの絵もあるので確かめる）。ニコニコは 16:9 に切って見せるので、顔は上下 90px を除いた帯に収める。
- ネタバレしない: 後半で出る人・暗転や転調の見た目など、オチは載せず前半の人だけで組む。
- 題はクッキー☆音MADの慣習に合わせて短い語＋☆にする（例「LAB=01☆」「論理空軍☆」「harvest cookie☆」）。【】で説明を付けない。

## 試した作品

- dande2（`thumbnail()`）。どの作品で「ダサい」と言われ、どう直したかは手元のメモから写す。
