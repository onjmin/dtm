# ドット絵のキャラを本物に似せる

- 東北系キャラ（ずんだもん・四国めたん・東北イタコなど）を数十 px のドット絵にするとき、形を記憶や小さな絵から推さず、公式 3D モデルと所有者の手本で確かめる。

## やり方

- **3D で確かめる**: 公式 3D（zunko.jp・BOOTH の pmx）を `scripts/otomad/tools/model_view.py` で正面・横・後ろから描き出す。Blender は要らない。

  ```bash
  .venv-speech/Scripts/python -I scripts/otomad/tools/model_view.py <pmx のパス> <出力 png>
  ```

  上段に全身、下段に頭の拡大が並ぶ。モデルは素材なので git に入れず、作業フォルダに置く。所有者の手本画像があればそれが正。
- **形の言葉は字どおりに描く**:
  - 「台形」は上が平らで、横がゆっくり広がる形。1 行に 2px ずつ広げると三角に見える。
  - 「扇形」は弧の帯。
  - 「下線の上に載せる」は重なりの順の指示。
- **色数**: 髪は地・明・濃の 3 色と輪郭まで。色を足すと「こてこてで髪の質感から離れる」と言われた。
- **立体**: 筒のように塗る（縁を濃く、芯を明るく）。下へ落ちる影を足す。首はあごの陰なので、肌の影より一段濃い色にする。
- **まつげ**: 上まつげと、閉じた目の横線は高さ 2px（1px より可愛い）。下の行は目より 1px 外へのばし、目尻も 1px 外へ出してそろえる。上の行は外の角を 1px 削る（2px のばすと広すぎた）。
- **頬**: 赤みは目の下に半円ほどの広さで置く（上 2 行は 5px で外の端は薄く、下 1 行も頬の色で 3px。薄い色にすると肌に紛れて欠けて見えた）。2〜3 点では小さい。眉はまつげから 1 行あける。
- **左右対称**: 左半分を描いて鏡に写す。髪の色を後から塗り替える処理があるなら、髪以外の固定の色（カチューシャの白・飾り）には髪と別の字を使う。

## 確定した形（所有者が直したもの）

- **めたん**
  - 額は台形。
  - 前髪は分け目から外へ下がる 2 本の太い束。先は巻かない（巻くと「しっぽ」）。顔の横に垂らさない（垂らすと「もみあげ」）。
  - カチューシャは白いフリルの扇と、左右の白いハート。前髪の上端を帯の下の線の上に載せると立体に見える。
  - ドリルは巻きの段を分けて描く。
- **ずんだもん**
  - 前髪は真ん中の束が少し片側へ寄って目の間へ下り、先が細くなる。横の束は目の上まで。束の間に額が小さくのぞく（左右対称の太い束は似ていなかった）。
  - 耳（枝豆のさや）は頭のてっぺんに載り、頭の幅より外まで長く、ほぼ水平。豆が 3 つ並ぶ。斜めに立てるとうさぎの耳に見えた。
  - 横髪の外の輪郭はまっすぐ下ろす（外へはねると側頭部が突き出る）。内の房は顔に沿ってあごまで下り、先が内へとがる。
  - 胴と腰は細い。腰に濃い線を入れる。
  - しっぽはうなじ（髪の後ろ）から生え、本人の左の肩の後ろへ下りて、先がかたつむりの殻のように巻く（公式フィギュアの前と後ろで確かめた）。正面の絵では、根もとを髪の下に隠し、肩の外（向かって右）へ垂れ下がって巻いた先がのぞくように描く。腰の横から垂らす・腰から上へ立てると、動物のしっぽの角度に見えた。
  - 合唱隊などの脇役はマスコットの姿にし、人間体より小さくする。マスコットは丸い大頭・黄色い点のさやの耳・右寄りに下がる前髪の房・細い手足・巻いたしっぽ。口は濃い線だけで、開くと下にピンクをのぞかせる（ピンクで挟むと唇に見える）。
- **イタコ**
  - 前髪は真ん中分けで、細い額が目の上まで同じ幅でのぞく。分け目の上に小さな髪飾り。
  - 耳は大きな三角の狐耳。横髪に赤い玉の髪留め。
  - 白い着物。襟は紫で 2px の V 字（太いと「太すぎる」）。袖は体と輪郭で分けた振袖で、裾ほど青緑。
  - 半透明ピンクの天女の羽衣を巻く。腰から下へ、黒地で先が赤い帯が垂れる。
  - 3D モデルのテクスチャでは玉がピンクだった。色は公式の立ち絵（zunko.jp の素材）で確かめる。

- **キリコ**（元絵 suzuhete.wixsite.com/home）
  - 前髪で片目と頬を隠す。見えるのは片目と口元。隠す面積が狭いと別人に見える。
  - 前髪は短冊。まっすぐ下りる地の帯と太さ 2px の影の帯を並べ、帯の長さと始まる高さを変える。
  - 上着は前が開いていて、黒いインナーが首から腰まで見える。
  - 脚は黒いタイツを長く見せ、靴の毛皮は足首に置く。ひざの高さに置かない。
  - テールは前髪と同じ色にする。
- **シヨ**（元絵 kakumeisiyo.my.canva.site）
  - メガネは下の縁だけ描く。つなぎも描かない。縁は濃くする。薄いと「消えた」と言われる。
  - 猫耳カチューシャのヘッドホン、白い布かけ、冥途服、ニーソ。
  - 体が少し左を向いているので、ひざも左へ曲げる。
- **アル**（元絵 hibikaaru.wixsite.com/aruofficial）
  - 目は細く、メガネのフレームは四辺とも描く。

## 目・髪・手（あめふらしがえきにおりてくる）

- **目**: 太いまつげ（2px）の下に、上が濃く下が明るい瞳。両側に同じ幅の白目を置くと正面を向く。
  - 白目を片側だけに置くと、視線が左右に向いて見える。
  - 瞳を黒い輪で囲み、真ん中に白い点を置くと「怖い」と言われた。
  - 両目の間を詰めない。女性キャラの目は大きめにする。
  - 閉じた目は高さ 2 マス。開いた目のまつげや目尻の点を残さず、一緒に動かす。
- **髪**: 全身のドット絵では地と影の 2 色と輪郭で足りる。縦の帯を並べて塗ると円柱に見える。
  - 1px の線や孤立した点は「謎の線」に見える。影はくさびや帯のまとまりで置き、太さと長さに差をつける。
  - 同じ高さに短い影を 2 つ並べると目に見える。
- **手の大写し**: 比率（細く長い指、狭い手のひら）で見せ、関節やシワは描かない。甲か手のひらかは爪で分かるようにする。
- **ひざの曲げ**: 脚の行を抜いて左右に振ると余分なドットが出る。ひざより上を脚ごと 1px ずらし、腰を下げる。脚の外にある髪の先や手は体と一緒に動かす。
  - 両ひざを外へ開くのは男性だけ。女性は同じ向きにそろえる。
- **腕**: 手から逆算して描き、ひじは腰の高さに置く。女性は肩を控えめにする。
- **腕を動かす差分**（踊り・手を振る）: 左右を別々に作る。
  - 途中のコマは線を引く処理で作らず、角度ごとに点の表で手描きする（30°・60°・水平）。上げ下げは 1 コマで飛ばさず、0.25 秒ほどかけて途中のコマを順に通す。
  - 腕の長さは下ろした腕と同じにする。角度ごとに手の位置を計算する（斜めで手が 1px 遠いだけで長く見える）。
  - 上げるのは水平まで。水平に出す分、絵の左右に余白を足す。
  - 太さは下ろした腕のまま、腕の向きに傾ける（1px 幅だと小枝に見える。袖のふくらみは 3px のまま）。
  - 振袖は腕から長く垂らして追わせる（短いと振袖に見えない）。裾は下ろした振袖と同じ色の段にする。
  - 手を振るのは、水平の腕で手首を 1px 起こした絵と交互に出す。
  - 肩の支点は胴の中に埋める。袖の根もとを胴の肩の上まで重ねて描く。胴の外の縁から生やすと、腕が貼り付けに見える。
- **振り付け**: 動きは歌詞の行ごとに意図を決めてから付ける（所有者「胸に手を当てて歌うとか、動きの意図を決めた方がいい」）。
  - ふだんは静かな身ぶりにする（胸に手を当てる・両手を胸に・遠くへ手を伸ばす・風を受けて両手を少し開く・語りの行は手を下ろす）。
  - 跳ぶ・手を上げるのはアクセントで、歌詞の山（靴が飛ぶ・指で飛ばす）にだけ置く。型を種で選んで替える振りは「ワンパターン」「忙しい」と言われた。
  - 胸に手を当てる絵も手描きにし、下ろした手からの途中のコマ（手がお腹の前）を通す。外へ上げる腕と胸へ寄せる腕は、下ろした腕を挟んで行き来させる。
  - 足は動かさず、膝を曲げる・跳ぶだけにする。正面の小さい絵で脚を外へずらす・斜めにする・曲げると、どれも「歪」「付け根の支点がおかしい」「欠損に見える」と言われた。
  - ジャンプは踏み切りの前と着地の後に膝を曲げた絵でため、宙では放物線で上がって下りる（約 7px）。高さはならさず放物線のまま使う。
  - 身ぶりのオンオフを声の大きさだけで決めると、音節の切れ目で腕が 1〜2 コマ上下して「痙攣」に見える。オフは 0.8 秒ほど待ってから戻し、A→B→A のすぐ戻りが 0 回か、コマごとに数えて確かめる。
- **体に遅れて動く部分**（しっぽ・耳・葉っぱ・ツインテール）: 体の動きに少し遅れて先がはねるようにする（所有者「動きに連動してはねる」）。付け根を支点に、先ほど大きく上下させる（2px まで。3px だと形が崩れた）。
  - 拍で体が沈んで戻った後に先が下がる。跳ぶと、上がる間は下に残り、下りる間は上へ振れる。
  - しっぽは体の絵の下に描き、根もとを腰の後ろに置く。体の外に根もとを描くと、手など別の所から生えて見えた。
  - 腕を上げた側は腕と重なるので、ツインテールを揺らさない（腕までたわんで震えて見える）。
- **着物の裾**: 脚の付け根は裾で隠す（イタコの裾を下ろした。所有者「スカート部分も描いて関節を隠す」）。

## 試した作品

- 海鬼月カバー（11-03）: 前髪・耳・カチューシャを 3〜4 回ずつ取り違えた。「3Dモデルよりあなたの画像認知能力が優れているわけはない」と言われ、3D の描き出しに切り替えた。

## はまりどころ

- 1px の濃い線（腰の線など）は、服のしわを地の色へ戻す「ならし」の処理で消えることがある。描いたら画素の値で確かめる。
- 小さく縮めた確認画像では形を取り違える。拡大した 1 枚と 3D の描き出しを並べて見比べる。
