# ドット絵のキャラを本物に似せる

- 東北系キャラ（ずんだもん・四国めたん・東北イタコなど）を数十 px のドット絵にするとき、形を記憶や小さな絵から推さず、公式 3D モデルと所有者の手本で確かめる。

## やり方

- **3D で確かめる**: 公式 3D（zunko.jp・BOOTH の pmx）を `scripts/otomad/tools/model_view.py` で正面・横・後ろから描き出す。Blender は要らない。

  ```bash
  .venv-speech/Scripts/python -I scripts/otomad/tools/model_view.py <pmx のパス> <出力 png>
  ```

  上段に全身、下段に頭の拡大が並ぶ。モデルは素材なので git に入れず、作業フォルダに置く。所有者の手本画像があればそれが正。
- **形の言葉は字どおりに描く**:
  - 「台形」は上が平らで、横がゆっくり広がる形。1 行に 2px ずつ広げると三角に見える。
  - 「扇形」は弧の帯。
  - 「下線の上に載せる」は重なりの順の指示。
- **色数**: 髪は地・明・濃の 3 色と輪郭まで。色を足すと「こてこてで髪の質感から離れる」と言われた。
- **立体**: 筒のように塗る（縁を濃く、芯を明るく）。下へ落ちる影を足す。首はあごの陰で暗くする。
- **左右対称**: 左半分を描いて鏡に写す。髪の色を後から塗り替える処理があるなら、髪以外の固定の色（カチューシャの白・飾り）には髪と別の字を使う。

## 確定した形（海鬼月で所有者が直したもの）

- **めたん**
  - 額は台形。
  - 前髪は分け目から外へ下がる 2 本の太い束。先は巻かない（巻くと「しっぽ」）。顔の横に垂らさない（垂らすと「もみあげ」）。
  - カチューシャは白いフリルの扇と、左右の白いハート。前髪の上端を帯の下の線の上に載せると立体に見える。
  - ドリルは巻きの段を分けて描く。
- **ずんだもん**
  - 前髪は真ん中がふくらんだ M 字。外は急で、先はとがらせない。真ん中の束は細すぎると M に見えない。
  - 耳は頭の左右へ張り出す枝豆のさや。
  - 胴と腰は細い。腰に濃い線を入れる。
- **イタコ**
  - 前髪は真ん中分けで、細い額が目の上まで同じ幅でのぞく。分け目の上に小さな髪飾り。
  - 耳は大きな三角の狐耳。横髪にぼんぼり。

## 試した作品

- 海鬼月カバー（11-03）: 前髪・耳・カチューシャを 3〜4 回ずつ取り違えた。「3Dモデルよりあなたの画像認知能力が優れているわけはない」と言われ、3D の描き出しに切り替えた。

## はまりどころ

- 1px の濃い線（腰の線など）は、服のしわを地の色へ戻す「ならし」の処理で消えることがある。描いたら画素の値で確かめる。
- 小さく縮めた確認画像では形を取り違える。拡大した 1 枚と 3D の描き出しを並べて見比べる。
