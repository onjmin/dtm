# ブロックの世界を本当に建てて壊す（voxel）

- マイクラのような世界を CPU の光線で描き、建物を時刻つきで建てて壊す。写真の背景を滑らせる舞台と違い、カメラはどこへでも飛べて、人物は建物の裏に隠れ、爆発は穴を残す。
- BB動画の 1 コマを、そのままブロックの立体（巨人）にして毎コマ差し替えられる。

## やり方

コードは [scripts/otomad/lib/voxel.py](../../../scripts/otomad/lib/voxel.py)。numba が要る（`pip install --target <SPEECH_PYLIB> --no-deps numba llvmlite`。numpy の版を動かさないよう `--no-deps`）。720p で 1 コマ約 0.3 秒、13 並列で全編（約 7 分）を十数分で書き出せる。

- **世界は時刻の関数にする**。1 マスに「いつ現れて（on）、いつ消えて（off）、消えたあと何になるか（after）」を持たせる。時刻を渡すだけでその瞬間の世界が描けるので、コマを順番に描かなくてよく、スローや先見せ（決戦の絵を頭で見せる）も時刻を変えるだけで済む。
- **建てる**: `World.build(cells, t0, t1, order="y")` で下から順に置く。空の時刻を早回しで動かすと、影が地面を流れる建築の早回しになる（`hour`）。
- **壊す**: `World.carve(x, y, z, r, t)` が球を消して破片と煙を足す。支えを失っても残りは浮いたまま（マイクラの理屈そのものがネタになる）。
- **人物は板**: `board()` が奥行きで前後を判定して重ねる。足元の丸い影も付く。
- **巨人**: `Giant.from_rgba(im, 高さ, 厚み, ...)`。絵の縁からの距離で厚みを決めるので、平たい板でなくふくらんだ像になる。色を丸めてブロックらしくする。絵の配列を毎コマ書き換えれば、穴を開けたり下から建てたりできる（`thick` を 0 にした所が消える）。
- **色**: 手続きで描いた 16×16 の絵（著作物を持ち込まない）。絵の色に光を掛けるだけで、0.8 より上だけ頭を丸める。ガンマを掛けると白っぽくなる。

## 試した作品

- bb19「まず屋上を建てたい☆」: 屋上だけが宙に建つ、豆腐ハウス、クソ建築の城、橋かけ、TNT の雨、野獣ラッシュの巨人 vs 現場監督の巨人、溶岩、落ちてくる豆腐。評価はまだ。

## はまりどころ

- `build()` の中の変数（`t`・`d`）を場面の関数が後から読むと、次の場面で書き換わった値を見てしまう（匠が消える、巨大になる）。`Show.shot` で閉じた変数をその時点の値に固定する（bb19 の `freeze`）。
- 1 マスの状態は 2 つまで。先に削った所へ後から別の物を置くと、削った瞬間に現れてしまう（溶岩が戦いの最中の穴に出た）。先に削られた所は飛ばすか、建て直す家は別の土地に建てる。
- 粗い格子を飛ばすときの面の向きは、どの境界で止まったかで決める。位置の差で決めると平らな地面が帯状に暗くなる。
- 夜は光を弱くすると何も見えない。早回しの間は露出を上げて、夜明けに戻す。
- たいまつの光は 1/距離² なので、地面に近いと白く飛ぶ。高めに置いて弱くする。
