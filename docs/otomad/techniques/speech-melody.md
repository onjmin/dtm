# 台詞イントネーション作曲

- 台詞の抑揚をそのまま主旋律にする。台詞を16分の格子へ置き、モーラ単位に音程を音階へ寄せ、和音は旋律から付ける。
- 使い方（セットアップ・build・録音・mix）は [scripts/speech-melody/README.md](../../../scripts/speech-melody/README.md)。根拠の実測は [research/speech-melody-method.md](../research/speech-melody-method.md)。

## やり方

作者（ももも味）の手順（「台詞イントネーション作曲、台詞からメロディーを作るのってどうやってる？」2021-12-24）:

1. BPM を決める（♩=100〜130。1拍に最大4モーラ＝16分）。
2. 普通の音MADと同じ台詞合わせ（タイムストレッチ）でリズムを先に済ませる。
3. モーラ単位に音程を補正して十二平均律へ合わせ、採譜してシンセで確かめる。音階はペンタ（ヨナ抜き）を多用し、**台詞の最後の音を主音にしたスケール**を選ぶ。半音が欲しければヘキサトニック。抑揚に厳密に従わなくてよい。リードにグリッサンド・ポルタメント。
4. コードはメロディーから付ける（旋律の音が構成音に入る重みが最大の組を選ぶ。samson5 は Fm7–D♭M7 の2和音だけ）。
5. 構成（素材が少なければループで尺を伸ばす）。

セリフ合わせのコツ（scrapbox lec-a）: 長い子音（t/s/z）は格子の前後へ散らし母音を格子へ／強拍に強い音（間を埋めるときは弱拍）／息継ぎ後の母音は1単位後ろへ／繋ぎ目は強いドラムの位置／音程変更は ±3 半音が限度で上下の向きをそろえる／伸縮は言葉の区切りで切るとハキハキする／三連は多用しない。

作例の実測（めめめ・Okaeshi）: 台詞は元の 1.15〜2.05 倍に**不均一に**伸ばし、台詞ごとに 0〜+1.5 半音移調。音節の立ち上がりは16分に強くそろい、拍頭は偶然（25%）より多い 32〜34%（強い音節の上位25%では 50%）。伴奏の和音は声の音高に合わせ、句の下で保つ（1音ずつ追わない）。声はほぼ途切れない。

波形を残す音程補正: torch や parselmouth が無い環境でも、`pyworld` で f0 だけ測って TD-PSOLA を自前で組める。子音の頭 40 ms は伸ばさず、モーラの中の揺れを半分にすると音程が立つ（cm24 で ±50 セント以内 85%）。読みを手で書いてモーラ数を決め、音の変わり目の強い所で区切る。

コード: `scripts/otomad/lib/clip_grid.py`（16分へ置く配置 DP・調と移調）、`pitch_snap.py`（モーラごとの音を音階へ寄せる）。

## 測る値（目安。合否にしない）

句頭の拍頭率、強い音節（上位25%）の拍頭率、抑揚の上下（同じ／平らになった／逆）、整列図（align.png）。samson5 は 0.96 / 0.89 / 同じ32・平ら11・逆0。

## 試した作品

- v1〜v5（〜10-28）: 声を WORLD で音階へ固定・150 固定・全曲同じ型 → 作例と違うと分かり改めた（[research/speech-melody-method.md](../research/speech-melody-method.md) §2）。v2 は台詞を前の後ろへ並べただけで小節と無関係だった。
- quotes（試作2・3）: モーラ＝16分の機関銃、語録だけで物語。試作3で伴奏の密度を区間ごとに変えた。
- samson5: 同じ音の連打の主題＋2和音。
- dande1〜3: 掛け合いで主旋律を作る。dande3 は文字PV。
- cm24 第2版: 2号兄貴風の和音と4つ打ちの上で、4人の台詞 72 行を掛け合いの主旋律にした。シンセは声の隙間の合いの手だけ。評価待ち。

## はまりどころ

- 雑音の多い素材（淫夢の SP パックなど）は pyin がほぼ全部を無声と読む。モーラの音程は WORLD の harvest で取る。
- 長い台詞は整列が数モーラに潰れることがある。配置の結果が全部同じ位置になっていないか見る。
- 同じ build を2回流すと声の波形がわずかに違う（placement.json は同じ。原因未特定）。
- 「声に音程補正なし」はフレーム単位のセント分布では見分けられない（Melodyne は音の中心だけを動かす）。
