# 衝撃のコマ・揺れ・流し撮り・レンズ割れ

- 当たりの瞬間を強く見せる技。突然の強調として使い、すぐ収める。

## やり方

- **衝撃のコマ**: 赤や白の地に黒い影絵を2〜3コマ置き、閃光のあと止め絵にする（KNN塾）。
- **揺れ**: 拡大してすぐ戻す（イージング）。最初の数コマが一番強く、強さを時間とともに直線で下げる。ブラーも同じ減衰。当たりには揺れと斜めの構図（ダッチ）。
- **流し撮り**: 移る瞬間にブレの1〜2コマ。走る人には地を流して付いていく。
- **キックに合わせた拡大**で映像をリズムに乗せる。
- **光**: 地を暗くして青や橙の縁光、逆光の光の筋、色ずれ。
- **字**: 擬音（ド・ゴゴゴ）を斜めに大きく。ボスの登場は「WARNING」の札。技名は画面いっぱいのカットイン（bb6）。
- **レンズ割れ**: 被弾がカメラに当たる（bb7「カメラレンズ激突被弾」）。
