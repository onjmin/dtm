# カバーの伴奏を原曲の質に寄せる

- カバーの伴奏を、原曲の歌なし音源と区間ごとに数値とスペクトログラムで並べて確かめる。差は音色より先に「欠けているパート」から埋める。
- 所有者に渡す前に、この確かめと直しを済ませておく。所有者に聞き比べてもらう前にやる仕事で、聞き比べページを渡しても代わりにならない。

## やり方

### 1. 時刻を合わせる
- 原曲の歌なし音源（`ref/orig_inst.wav` など。測るためだけに使い、git には入れない）を手元に置く。自分の版の小節が原曲の何小節にあたるかを、区間ごとに決める。
  - 前置きや延長で小節がずれる時は、ずれる所ごとに書く（例: 原曲 0〜43 小節は +17、44 小節から +25）。
- 残りの秒のずれは、和音の chroma の相互相関で測る。ずれの向き（＋か−か）を一度確かめる。向きを逆に取ると、拍の中の形の比較が全部くずれる。

### 2. 区間ごとに数値で並べる
- `scripts/otomad/analysis/check_vs_orig.py --orig 原曲.wav --ours 伴奏.wav --bpm … --sec "A1=8-28,…" --map "0:17,44:25"`
  - demucs（htdemucs_6s）で両方を分ける。区間ごとに次の 4 つを原曲との差で出し、±3 dB・±3 音を超えた所に ★ を付ける。
    - 6 帯の割合（40–250・250–500・500–1k・1–2k・2–4k・4–16k Hz）
    - 同時に鳴る音の数（C3–C6 で、いちばん大きい音から 15 dB 以内の音の数）
    - 和音−ドラム
    - ベース−ドラム
- 大きさに依らない比で比べる。帯域は「全体に対する割合」、釣り合いは「stem どうしの差」で見る。
- 全区間で ★ が消えるのを目安にする。消せなかった所は、渡す時に表にして伝える。

### 3. スペクトログラムを目で見る
- 同じスクリプトが、区間ごとに原曲と上下に並べた図を書く。2 枚は大きさをそろえ、同じ基準と同じ色の幅（−75〜0 dB）で塗る。基準を 1 枚ずつ取ると、薄い所が濃く見えて比べられない。
- 見る所:
  - 中域（250 Hz–2 kHz）に線が詰まっているか、すかすかか。
  - ベースに倍音の線が何本あるか（128–512 Hz）。
  - 2–4.5 kHz に拍ごとの縦の筋（キックの頭・ハット）があるか。
  - 8 kHz より上が途切れず続くか。
- 数値で合っていても、図で穴が見えたら直す。所有者は図で差を見つけた（ぽぽりん穴「真ん中がすかすか」）。

### 4. 欠けたパートを先に探す（音色はその後）
- 原曲の stem（other・guitar・piano）を basic-pitch で採譜し、手元の MIDI に無いパートを探す。
  - 耳コピ MIDI には、和音の刻み（低い根音を伸ばし、上の音を裏で刻む・サビは 16 分のシンコペーション）が入っていないことが多い。
- 足す時は、すでにあるトラックと同じ音（同じ音名が 70 ms 以内に始まる音）を外す。そうしないと、イントロのプラックやオブリガードを二重に鳴らしてしまう。
- 和音の音域が原曲より高い時（C#5–B5 しか無い等）は、1 オクターブ下に重ねる。

### 5. 帯域と拍の穴を直す型
- **中域の穴**: 4 の欠けたパートと低い和音で埋める。足りない帯域は和音の側にだけ EQ を当てる（350 Hz・1.4 kHz を上げ、700 Hz を下げる、など）。
- **ベースの倍音**: 基音だけの音色を、倍音のあるもの（例: SGM 87）に替える。左右には広げず、真ん中に置く。
- **2–4.5 kHz の拍ごとの穴**: 原曲のキックには「カチッ」という頭がある。15 ms のノイズを 2–5 kHz の帯域に通して、キックに足す。裏のハットを 3.2 kHz で持ち上げ、平らに鳴り続けるシェイカーは下げる。
  - 圧縮が原因に見えても、まず打楽器の頭を疑う（比を 1.0 にしても穴は残った）。
- **ポンピング**: キックで和音を引っ込める処理は Suno 由来なので外す。
- **伴奏全体の EQ の基準**: 原曲に合わせる。Suno に寄せた版を基準にしない（2–16 kHz のシャリ感が移る）。
- **200 Hz 以下の左右**: 側成分は 200 Hz より上だけに残す。

### 6. 大きさを変えずに直す
- 曲全体で大きさを合わせ直す段は使わない。決まった値に固定する（ぽぽりん穴の `freeze.py`）。替えた楽器の段だけ測り直す。
- 直した版は、基準の版と 4 小節ごとに大きさを比べる。直したあとで全体が小さくなっていないかを、必ず確かめる。
  - パートを足すと圧縮が強くかかり、ほかの所が沈む。全体を戻す時は、ミックスの前の伴奏で dB を足す。
- 所有者が前の版のほうを気に入った区間は、その区間だけ前の版から差し込む。大きさは A1 との比を保ち、継ぎ目は 8 分ぶん重ねてつなぐ。

### 7. 渡す時
- 直した所と、残った差（区間・帯域・dB）を表にして伝える。わざと原曲から離した所（所有者の好みで残した区間など）は、そう書く。

## 試した作品

- ぽぽりん穴（ヤツメ穴のカバー、A49）
  - A48 で所有者がスペクトログラムを見て「真ん中がすかすか」と指摘した。原因は、和音の刻みのパート（ギター）が無かったことと、和音の音域が高すぎたこと。
  - 直した結果（原曲との差）:
    - サビの 250–500 Hz: −6.9 → −3.8 dB
    - A1 の 1–2 kHz: −4.5 → −0.4 dB
    - 4–16 kHz: +3.7 → ±1 dB
  - 残った差:
    - サビ系の 250–500 Hz: −2〜−4 dB
    - サビ系の 1–2 kHz: −3 dB
    - 同時に鳴る音の数: 4〜6 少ない
  - 所有者の評価待ち。

## はまりどころ

- 自分の版にギターがあると、demucs は和音の大半を guitar に入れる。stem ごとの割合で音量を判断しない。和音は other・guitar・piano を足してから比べる。
- 足したパートが大きすぎると圧縮を叩き、ドラムとベースが 7〜9 dB 沈む。それで足したパートの音量を変えても、差がほとんど出なくなる。
- 評価用の AI（CLAP の距離・Qwen2-Audio の点数）は、所有者の判断と合わなかった。上の比と図は、所有者の 3 つの指摘と一致したので、こちらを使う。
- 図の正規化のせいで、低域の左右にもやがあるように見えることがある。数値で確かめる。
- 区間を聞き比べるページを作っても、聞く仕事を所有者に戻すだけになる。自分で測って直してから渡す。
