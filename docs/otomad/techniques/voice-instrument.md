# 声を楽器に作り替える・音節を刻む

- 台詞を文として流さず、叫び・息・音節を音程つきのシンセ、太鼓、ベースに作り替える。音節は16分に1粒ずつ置いてリズムの部品にする。2号式の核。
- 根拠: [research/nigo-mad-analysis.md](../research/nigo-mad-analysis.md)。

## やり方

- 叫びなど1音を音程つきのシンセにして、1〜2小節のリフを最初から最後まで弾かせる（TECHNO MUSIC先輩の「ンアッー」）。
- 「ぷはー」をリム・スネアに、ほかの声をベースや笛に（andesite）。伴奏側に分かれるほど原形を残さない。
- 刻み: 声の立ち上がりの間隔を16分1〜2個分に（実測 0.63〜0.69 回／16分）。
- 生の台詞は数か所に絞り、「ん？」とためてから最後や区切りで原液のまま落とす（[genres/nigo.md](../genres/nigo.md)）。

コード: `scripts/otomad/lib/voice_inst.py`（声のシンセ・音節の粒・子音の打楽器）。
