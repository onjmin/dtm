# 声を楽器に作り替える・音節を刻む

- 台詞を文として流さず、叫び・息・音節を音程つきのシンセ、太鼓、ベースに作り替える。音節は16分に1粒ずつ置いてリズムの部品にする。2号式の核。
- 根拠: [research/nigo-mad-analysis.md](../research/nigo-mad-analysis.md)。

## やり方

- 叫びなど1音を音程つきのシンセにして、1〜2小節のリフを最初から最後まで弾かせる（TECHNO MUSIC先輩の「ンアッー」）。
- 「ぷはー」をリム・スネアに、ほかの声をベースや笛に（andesite）。伴奏側に分かれるほど原形を残さない。
- 刻み: 声の立ち上がりの間隔を16分1〜2個分に（実測 0.63〜0.69 回／16分）。
- 生の台詞は数か所に絞り、「ん？」とためてから最後や区切りで原液のまま落とす（[genres/nigo.md](../genres/nigo.md)）。

コード: `scripts/otomad/lib/voice_inst.py`（声のシンセ・音節の粒・子音の打楽器）。

## 試した作品

- samsonnigo1: 台詞を合いの手 49 か所で文のまま置いた → 2号兄貴と逆だった。
- techno1: 野獣の抑揚から起こしたリフを「アアッ」のシンセに弾かせ、元の台詞と顔は41小節目まで隠す。
- samson2go1r: 声の楽器はそのまま、生の台詞を14→28か所に増やした（伏せていた空耳を解禁）。

## 台詞の語尾をシンセにする（桔梗☆、11-08）

- 有名な語尾（「わたしも食べさせるぅ＾～」の「る～」）を切り、頭の子音を残したまま、伸ばしの高さをフレームごとに平らにする。長い音は、いちばん平らな所を繰り返す。
- 切れ目は有声の区切りだけで決めない。BGM が乗った素材は「させ」の摩擦の間も有声に読めてしまう。10ms 刻みで 4 kHz 以上の比を見て、摩擦が終わる所から切る（最初は 1.82 秒で切って「べさせ」が入り、所有者に指摘された。正しくは 2.14 秒）。
- 切り出したものだけを書き出して、聴いて確かめてもらう。
- かすれ（所有者 11-08「『る～』がかすれている」）: PSOLA で高さを平らにすると息っぽさが増す（HNR 14.8 → 12.4 dB）。WORLD で響き（sp）と息（ap）に分け、音符ごとに目標の高さで組み立て直す。息を ×0.25、響きを時間方向に 5 フレームならし、4.5 kHz より上を 8 dB 下げて HNR 約 16.7 dB。再生速度で高さを変えると響きも動くので使わない。繰り返しは行って戻る形にして、継ぎ目で響きが跳ばないようにする。
- オクターブ（桔梗☆、11-08）: 旋律を声の音域へ寄せるとき、1音ずつ折り返すと音型の頂点だけ1オクターブ落ちる。区間ごとに1つの移動量を決める。音高の検査は音名（12 で割った余り）だけでなく、隣の音との差が楽譜どおりかも見る。
- 桔梗☆（11-08）で、語尾のシンセ（る～）と区間ごとの声の旋律を全編に使い、所有者「素晴らしい」で投稿された（sm47024472）。

### 素材の選び方

- 癖のある声から選ぶ（所有者 11-08「もう少し特徴的な声質　YMNなどの母音を使ったほうがいい」）。素直な「あー」は伴奏に溶けて、誰の声か分からない。
- その作品の題材の台詞から取る（所有者「YMNの声は『甘い』等、初代クッキー☆の台詞から」）。有名な語尾ほど、聴いて元の台詞が浮かぶ。
- 伸ばしが 0.2 秒以上あり、BGM が薄い所を選ぶ。平らな所が短くても、繰り返すので 0.2〜0.3 秒あれば足りる。

### 作りの数値（桔梗☆の YMN「るぅ＾～」で決めた値）

| 手順 | 値 | 理由 |
|---|---|---|
| 切る所 | 2.14〜2.72 秒（「る」の子音から伸ばしの終わり） | 頭の子音を残すと、声の正体が分かる。前の「させ」の摩擦は 4 kHz 以上の比で見て外す |
| 繰り返す所 | 2.32〜2.61 秒（半音以内で平らな所） | 行って戻る形で繰り返し、継ぎ目で響きを跳ばさない |
| 高さの読み取り | WORLD harvest、下限 150 Hz（男声は 60 Hz） | 高い声で下限を下げると、2オクターブ下と読み違える（ダイナモ） |
| 無声のフレーム | 近くの有声フレームの響きで埋める | 子音の所で高さを当てると、雑音が音程を持つ |
| 息（ap） | ×0.25 | かすれの元。HNR 12.4 → 約 16.7 dB |
| 響き（sp） | 時間方向に 5 フレーム（25ms）ならす | 震えを抑える |
| 高い所 | 4.5 kHz から上を、3 kHz かけて 8 dB 下げる | 歯擦の残りを抑える |
| 鳴らし方 | 目標の高さで組み立て直す。立ち上がり 4ms・減衰 0.1 秒で 0.85 へ・切れ 50ms | 再生速度で高さを変えると響き（声色）も動く |

### サンプラー用に書き出す

- 道具: `scripts/otomad/tools/voice_synth_export.py`。上の作りを1本にまとめ、C3〜C6 を短3度ごとに 2 秒ずつ書き出す。元の高さで 4 秒伸ばした物と、加工前の切り出しも添える。ピークは −1 dB で、24bit / 44.1 kHz。
- 書き出した後に、各ファイルの高さを測って表示する。名前の音とずれていたら、高さの読み取りの下限か、繰り返す所を見直す。
- 動かすには pyworld・scipy・soundfile が要る（`.venv-speech` には pyworld が無い。`pip install pyworld` を入れた Python で動かす）。
- 例（桔梗☆の YMN）:

  ```bash
  python -I scripts/otomad/tools/voice_synth_export.py "<素材>/★クッキー☆/立教大学前まで/YMN/SIK「わたしも食べさせるぅ＾～」.wav" --cut 2.14 2.72 --loop 2.32 2.61 --name YMN_ru --out tmp/YMN_るぅシンセ
  ```

- 1本に1つの高さを入れる（多くて短3度おき）。1本を大きく引き伸ばすと、声色の動きは抑えても、高い所で細く、低い所で濁る。
- 声の素材から作った音なので、公開の asset リポジトリには入れない。git に入らない `tmp/` に置く。
- 11-09、所有者に「シンセ用に加工したYMN音源をください」と言われ、この形で 15 本渡した。桔梗☆で鳴らした音と、波形の差は 1e-7 以下。

- 素材は、桔梗☆で各人の旋律に使って所有者に通った声にした。候補は平らな所の長さで比べた（UDK「あああ…忘れてた」は 0.17 秒、MUR「そうだなぁー」は 0.19 秒で短い）。
- 音域: C2〜C6 を短3度おきに 17 本。いちばん上の音は C6 より上へ広げる。C7 まで作ると声が細すぎ、高さも読めなかった。
- ループ: 1本 0.85 秒。0.25 秒から 0.75 秒あたりまでを前向きに繰り返す。ループの長さは、周期の整数倍が標本の整数に近くなる回数を選ぶ。終わりの 30ms を、ループの頭の手前と sin² でクロスフェードする。SF2 の決まりで、ループの後ろに頭の写しを 64 標本付ける。WORLD の中の繰り返し（行って戻る）は書き出した音には残らないので、ループはこちらで作る。
- 大きさ: ループの所の RMS を楽器の中でそろえ、いちばん大きいピークを −1 dB にする（dtm は読み込み時に楽器ごとの大きさをさらにそろえる）。
- 32 kHz・16bit。4.5 kHz から上は下げてあるので足りる。.sf2 は 3.2 MB、JS は1音色 1.1 MB。
- SF2 の中身: 音色ごとに楽器を1つ。ゾーンごとに鍵盤範囲・立ち上がり 4ms・離した後 0.12 秒・鳴らしている間ループ。
- WebAudioFont: dtm のバンクの形（`PPPV_<バンク>.js`）にそろえて `sound/0800_Inc_sf2_file.js`〜`sound/0830_Inc_sf2_file.js`。変数は `_tone_0800_Inc_sf2_file`。ゾーンは `sample`（16bit PCM の base64）で、ループ点は標本の番号。圧縮した音（`file`）は使わない。MP3 は頭に無音が入りループがずれる。Safari は Ogg を読めない。
- 確かめ方（道具が最後に表示する）:
  - ループを回して 2 秒鳴らし、高さを測る。全部 ±0.05 半音以内。
  - 継ぎ目の段差を、ループの中の隣どうしの差の 99% 点と比べる。全部 1 以下で、最大 0.83。
  - dtm の `parseSf2` で 80〜83 番の 17 ゾーンとループが読めた。
  - JS は node で読み込み、ループ点が音の中にあることを見た。
  - 耳ではまだ聴いていない。`check/` の C 音階の wav で聴く。
- 配り方: 公開は [onjmin/inc-sf2](https://github.com/onjmin/inc-sf2)（https://onjmin.github.io/inc-sf2/ 。試し弾きのページつき。dtm と同じ Actions の Pages）。.sf2 は dtm で `#sf2=https://onjmin.github.io/inc-sf2/inc.sf2` を書いて今でも鳴る（[docs/guide/external-soundfont.md](../../guide/external-soundfont.md)）。WebAudioFont の JS は `#t<n>font=Inc` で選べる（11-09、所有者「Inc を選べるようにする」）。バンクに読む先（`baseUrl`）と持っている楽器（`programs`）を持たせ（`src/instruments/soundfont-banks.ts`）、80〜83 番以外は FluidR3 へ落とす。デモの DAW で、80・83 番が onjmin/inc-sf2 から読まれ、ピアノが FluidR3 に落ちたのを確かめた。
