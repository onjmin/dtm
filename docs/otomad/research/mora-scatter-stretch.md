# 台詞をモーラで散らす・伸ばす（2026-11-07）

所有者 11-07: じゅーけーさんの sm46506771（あずまんが大王のちよ父 ×「APT.」、148 BPM）には「モーラで区切って分割してまばらに配置するパターン」と「伸縮したものを配置するパターン」がある。ネットでも技法を調べて取り入れる。

## 手本を測った結果（sm46506771）

測り方: Demucs（htdemucs_ft）で声を抜き、faster-whisper large-v3 で言葉の時刻を取り、声のスペクトログラムに16分の格子を重ねた（手元の `scratch/arcana/ana_ref.py`・`spec.py`・`grid16.py`）。小節の頭 0.815 秒、1小節 1.622 秒。

### モーラで散らす

- 1行（「トマトも食べろよ」）をモーラ（ト・マ・ト）に切り、**2拍で1周する型**に並べる。型は「短い落ちる音（ト）→ 山形の音（マ）→ 平らに伸ばした音」で、間に16分の空きがある。
- 同じ型を3〜4小節そのまま繰り返す（3〜6小節、58〜61小節）。書き起こしは「ト（4.72 秒）… マ（6.84 秒）… ト（11.63 秒）」のように、1語の中に5秒近い空きができる＝ばらしたモーラが何度も鳴っている。
- **4小節ごとに元の速さの1行で締める**（2.8 小節目・6.6 小節目に低い元の声の「トマトも食べろよ」）。ばらしたものと、元のままのものが交互に来るので、ばらした音が何の言葉か分かる。
- 原曲の「아파트（アパトゥ）」の3音節に「トマト」の3モーラを当てている。題材の言葉と原曲の掛け声の音数・母音をそろえるのが芯。

### 伸ばす

- 1つのモーラの母音を1拍〜1拍半に伸ばす（59 小節頭。倍音が真っ直ぐ平らに続く）。子音の立ち上がりは元のまま。
- 散らす型の3つ目の音も、母音を16分2〜3つぶんに伸ばしている（短い音・短い音・長い音で、リズムに長短がつく）。
- 伸ばした音は音量を下げて裏に敷く区間もある（36〜41 小節、−30 dB 前後で A#4 付近が続く）。

### そのほか

- 区間ごとに「元の速さで言う」「散らす」「伸ばす」を替え、全編同じにしない。ゲームの場面（52〜84 秒）は別の素材の声と場面の音に替わる。
- コメント（13件）は「普通に歌わせたり音程合わせもできるようになったら輝けそう」「私はこのままの作風で作り続けてほしい」。音高を合わせない作りが作風と受け取られている。

## ネットの技法（セリフ合わせ）

- 一音ずつ切り、次が母音なら別のブロックにする。「です」のような無声化した「す」は2ブロック扱い（[irotuynt のセリフ合わせ](https://scrapbox.io/irotuynt/%E3%82%BB%E3%83%AA%E3%83%95%E5%90%88%E3%82%8F%E3%81%9B)）。
- 連母音・撥音（2拍）を真ん中できっちり切り分けると「セリフ合わせっぽさ」が増す。合わせ方には「点（ドラムに合わせる）」と「幅（フロウに乗せる）」がある（[lec-a のセリフ合わせ](https://scrapbox.io/lec-a/%E3%82%BB%E3%83%AA%E3%83%95%E5%90%88%E3%82%8F%E3%81%9B)）。
- 言葉として聞こえるかは「前の母音から次の母音までの距離」で決まる。子音は 64 分の長さで前後 128 分ずつ取る。か行・た行の前の無音も一緒に縮める（lec-a・irotuynt）。
- 無声化した音（つ・ち・す・し）は 1/64 くらい前に出す（irotuynt）。母音が無声化したら前後の母音を合わせ、両端から伸ばして中間で切る（lec-a）。
- 促音・撥音・長音・二重母音の2モーラ目（「かっ」の「っ」、「かん」の「ん」）は前の音に付いていて弱い。強拍に置くと歯切れが悪い（[miyaryu「自分のセリフ合わせ論」](https://note.com/miyyyya/n/ndabdee30abe4)）。
- 基本は16分で詰め、そこに変則のリズムを足す。合っているかは「始点と終点」「文節と拍が一致しているか」で見る。セリフの一部を8分・12分・24分刻みにするのも手（miyaryu）。
- ハキハキ喋っている素材でないと引き伸ばしに耐えない。ピッチ変更は ±3 半音くらいが限度（lec-a）。
- 優先して合わせる所: サビ前のフィル → イントロ・アウトロ → 歌の頭と終わりの拍（lec-a）。

## 作りに入れること

1. **散らす**: 1行をモーラに切り、区間の旋律の打点から2拍か1小節の型を作って、そこにモーラを順に置く。子音は元の長さ、間は空ける。同じ型を区間の中で繰り返す。
2. **締める**: 4小節（または区間）の終わりに元の速さの1行を置き、何の言葉だったかを明かす。
3. **伸ばす**: 型の中の長い音符・区間の頭の伸ばしには、子音を残して母音だけを伸ばす（rubberband で母音の区間だけ）。1拍半までにとどめる。
4. 撥音・促音・長音の2モーラ目は強拍に置かない。
