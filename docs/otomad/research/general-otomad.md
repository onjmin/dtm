## 測った値

- 拍のそろい: 声の立ち上がりの、16分の周期に対するそろい（vector strength。1 で格子にぴったり、偶然は 1/√N ≒ 0.05）。立ち上がり＝子音を含む 300〜8000Hz、母音＝有声の 150〜1200Hz。±20ms 以内の割合も出し、偶然の値を並べた
- 歌わせ: 有声のフレームの音高が平均律の音から ±15 cent 以内の割合（偶然 0.30）。保ち: 60ms 続けて ±20 cent 以内に留まる割合
- 声の割合: 声が鳴っている時間の割合。繰り返し: 声の音量の並びの1・2小節ずらしの相関

## 分かった差

### 1. 拍に合わせているのは「音の立ち上がり」で、母音の頭ではない

拍によくそろう5本（カンナ先進国・アイスばっかり・デデデ大王・ココロジョジョル・るるかポンポコリン）は、どれも子音を含む立ち上がりのほうが母音の頭よりそろっている（0.32〜0.59 と 0.25〜0.52）。立ち上がりは格子の **5〜12ms 後ろ** に来る。図（`scratch/genmad/d_all.png`）で見ても、リズム天国は「か」「は」の破裂の縦線がちょうど拍の線にある。

11-08 に作法へ足した「母音の頭を音符に置き、子音は前にはみ出させる」は、この作り方と逆だった。out4 の B・C は立ち上がりが格子より 17〜18ms 早い。前の版（out3）がずれていたのは、子音を拍に置いたからではない。切り抜きの頭に無音が残っていて、立ち上がりが 0〜90ms ばらばらに遅れたため。out3 A の立ち上がりは −31ms で、±20ms 以内は 19%（偶然 42%）しかなかった。

→ 切り抜きは声が鳴り始める点（子音の破裂・摩擦の頭）ちょうどで切り、その頭を格子の 0〜10ms 後ろに置く。

### 2. 一般の音MAD は2つの型に分かれる

| | 人力・切り貼りの型 | 喋らせの型 |
|---|---|---|
| 作品 | カンナ先進国・アイスばっかり・デデデ大王・ココロジョジョル・るるかポンポコリン | リズム天国・ｲﾀｽﾞﾗ…ｻﾚﾀ?・ブロリー・じゅーけー |
| 声の割合 | 0.84〜0.97（ほぼ埋める） | 0.49〜0.71（じゅーけーは原曲の歌を含めて 0.95） |
| 16分のそろい | 0.32〜0.59 | 偶然と同じ（台詞は語りの速さ。合わせるのは句の頭だけ） |
| 音高 | 平均律に寄せる（歌わせ 0.35〜0.48、アイスばっかりは保ちも 0.35） | 寄せない（0.28〜0.38） |
| コメント | 「しっとりした人力好き」「人力いいな」（アイスばっかり）、「ここすき」 | 「かわいい」「はむはむ」（リズム天国）。拍に合わせた語を一緒に打つ |

再生数の上位（ココロジョジョル 548 万・ブロリー 526 万・ほむほむ 431 万）は両方の型にある。今年の名探偵プリキュアの音MAD は3本とも人力・切り貼りの型だった。

### 3. 自分のループとの差

- **立ち上がりの位置**（上の1）。いちばん大きい差。
- **声で小節を埋めていない**。out4 A の声の割合は 0.66 で、切り貼りの型の 0.84〜0.97 より少ない。「まばらに置く」とは、切り貼りの型の中で、ところどころ空けることだった（手本のじゅーけーも声の割合 0.95）。
- **音高を合わせていない**。散らす型も伸ばす型も元の高さのまま。一般の人力の型は、切ったモーラの高さを旋律の音へ移している（アイスばっかりの保ち 0.35。伸ばした母音が音符の高さで止まる）。所有者は md1 で「シンセ化はやめる」と言ったが、それは母音を合成音で作り替えたことへの話。元の声のまま音高だけ移すのは、一般の音MAD の基本の型。
- **繰り返しの単位**。ブロリー（0.72）・デデデ大王（0.69）は1小節の型をそのまま回す。自分のループは2小節の型で、1小節ずらしの相関はマイナス〜0.3。

### 4. 同じだったこと

- 絵の切り替えは、どの作品も 1.2〜2.6 回/秒で、自分のループ（1.2〜2.7）と変わらない。
- 打楽器の頭は格子から ±3〜4ms。格子の取り方（16分、打楽器に BPM と位相を合わせる）は合っていた。

## 作りに入れること

1. 切り抜きの頭を、声が鳴り始める点ちょうどにする（前の無音を残さない）。その頭を格子の 0〜10ms 後ろに置く。置いたあと、立ち上がりのそろい（`scratch/genmad/attack.py`）が 0.3 を越え、ずれが 0〜+12ms になるかを測る。
2. 散らす型も、小節を声でほぼ埋める（声の割合 0.8 以上）。空けるのは句の終わりの1〜2拍。
3. 伸ばすモーラ、旋律に当てるモーラは、元の声のまま音高を旋律の音へ移す（±3 半音を越えるならオクターブで逃がす）。
4. 型は1小節を単位にして、そのまま回す。
