# のえぢゆ（NEL姉貴と DIYUSI）の設定と素材（2026-11-02）

bb16 を作る前に調べた。ニコニコ大百科・ピクシブ百科事典・クッキー☆解説Wiki（atwiki）の記事と、関連動画（オフッside:DIYUSI.0・.23、【Rimworld】NELとぢゆしの廃墟ぐらし.noediyu1、DIYUSIvs野獣先輩.mp1）のコマとコメントから。

## ぢゆし（DIYUSI）

- クッキー☆（2010）の大妖精。CV は HNS姉貴（アリスと同じ）。本編の出番は 4:43 からの数秒で、台詞は「隣の垣根に囲いが出来たんですって！」（寒いダジャレ）と「あっ！…どっ、どうも（ぺこり）」だけ。
- 作画が下書きのままだったので、糸目・無表情・眠そうな目（糸目は本来は笑顔の表現）。翅は省かれ、サイドテール〜ポニーテール。
- 持ちネタ: 交通整理（「交通整理DIちゃんPB」2014 から。誘導棒・ホイッスル・安全ベスト）。オフッside:DIYUSI（2017〜2018、あんこう鍋氏、全24話）で「警備員」の主役になり、交通標識を操って戦う、感情を出さない、プレイヤーの導きに忠実、という形が定まった。
- 内なるHNS（腕から鎌）、シユヂ（黒いぢゆし、子供用の傘とハザードの印）などの派生がある。定番のコメントは「ぢゆしすき」。
- 台詞が2つしかないので、音MAD より静画・BB劇場で人気。喋る場面ではコメントが「喋った！？」「ぢゆしが喋ってるの珍しい」で沸く（noediyu1）。

## NEL姉貴（のえる）

- クッソー☆（2014）で霊夢を演じた声優。浣腸相撲の行司で、ただ1人うんこを漏らしていない。名言は「うんこの量が多すぎる！」。ほかに「はいは～い、みなさーん」「浣↓腸↑」「オムツチェック！」「痛みに耐えてよく頑張った！感動した！」（小学生並みの感想）「次回の開催に御期待下さい」。台詞は本編の 92 本だけ（Pandora's Box の ★クッソー☆/NEL姉貴(霊夢役)）。
- 物怖じせず嬉々として浣腸相撲を仕切る演技から、読めないお姉さん・黒幕・サイコパスとして描かれやすい。NEL目（どす黒い目）。浣腸が持ちネタで、パイルバンカーや貫手も浣腸の手段になる。
- オフッside では「曖昧なる商人、傍観者」。プレイヤーを認識でき、さらに高次の存在まで認知するのでメタな発言が多い（noediyu1 のコメント「メタ発言に定評のあるNEL」）。

## のえぢゆ

- オフッside:DIYUSI 発祥の組み合わせ。本人同士の面識も出演作も無い異色の二人組。過酷な運命を背負う寡黙な幼女と、手助けしながら観測する気さくなお姉さん。相思相愛とも利害の一致とも取れる関係。
- 身長差・胸囲差、赤と緑（補色）で凸凹コンビにしやすい。作品は「観察者と対象」の暗い話と、仲の良い凸凹コンビの明るい話に二極化している。
- 名作のコメントの山: オフッside.23 は「ｵﾌｯ」の合唱（780 秒、103 件/20 秒）、「は？」（320 秒）、「ひでいきろ」の合唱、最後に「めいさく」「ありがとナス！」。DIYUSIvs野獣先輩は作画への「！？」（131 件）と「ここすき」「88888888」。

## 手元と落とした素材

- 手元: クッキー☆の正規化済み静画パックに DIYUSI の face・icon・scene が 17 枚（本編の開眼・隣の垣根・どうも・赤面など）。NEL の絵は手元に無い。
- 落とした BB（`AI/クッキー☆/BB/`）: 歩く新クリ風DIYUSI.BBセット sm32252421（歩く・走る・蹴る・待機・誘導棒を掲げる・寝転ぶ、開眼と交通整理の差分。シアンの地）、ぢゆしBBセット sm31908997（棒立ち・二刀流・方向を指す）、DIYUSI BB素材.ぢゆし sm33988618、自転車に乗るNEL姉貴BB sm32270183、歩くNEL姉貴BB sm31740204（普通・いつものポーズ）、風に揺れるNEL姉貴BB sm31734860、NEL姉貴BB×3 sm31753705（浣腸を取り出す・手を振る・走る）、パイルバンカー浣腸 sm32253003、NEL姉貴のGB素材（本編のみ）sm31058380、寝るNEL姉貴CB sm35667746、スマホをいじるNEL姉貴.GB sm32279579、揺さぶるNELと揺さぶられDIYUSICB sm40171599、歩くトレンチコートNEL姉貴とぢゆしPB sm33883538。
- 抜くときの注意: ぢゆしの青い服・緑の髪は地（シアン・青・紫）に近いので、にじみ消し（despill）を全体にかけると色が死ぬ。縁だけにかける。BB セットの動画は区間の境目に字幕の札（「ぶん殴る」など）が挟まるので、区間を少し内側に取る。

## 扱いの線

ぢゆしは幼い見た目の人物なので、浣腸・下ネタの的にしない。性的な BB（シコを踏む NEL など）は使わない。
