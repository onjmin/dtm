# 音MADの作り方（工程順のノウハウ）

界隈曲を淫夢・クッキー☆の素材でカバーする音MADを、選曲から渡すまで順に書く。ENU☆（11-05〜11-07）で所有者から受けた指摘と、参考動画を測って分かったことをまとめた。

- 守る基準は [rules.md](rules.md)、技の中身は [techniques/](techniques/README.md)。ここは「どの順に何をするか」と、そのときの数値の目安を書く。
- 数値は ENU☆ で測った値で、決まりではない。曲と素材ごとに測り直す。

## 0. 全体の流れ

1. 曲を選ぶ
2. 手本の動画を落として測る
3. 素材を集める（声・打楽器・伴奏・絵）
4. 歌を作る（語録・ロイド）
5. 伴奏とドラムを素材で作る
6. ミックスする
7. 映像を作る
8. 最後のサビで一転攻勢
9. 確かめて渡す

指摘はたいてい、作る途中で手本や原曲を測らずに決めた所から来る。迷ったら先に測る。

## 1. 曲を選ぶ

- 候補は配布 MIDI のある曲から選ぶ。カバーでは配布 MIDI を使ってよい。配布者ごとの条件だけ確かめ、投稿欄にクレジットを書く。
- ニコニコにまだ音MADが無い曲を選ぶ（題名とタグで検索する）。
- 題名は原曲をもじる（エヌ → ENU☆）。クッキー☆の人物が出るなら「☆」を付ける。題名は動画の中に出さない。
- 主役は題材に絡む人物にする。声の無い人物（INU）は絵と字だけで出す。

## 2. 手本の動画を落として測る

知らない手法は説明文だけで作らない。タグの動画を数本落として測る。

- 道具: `python -m yt_dlp`（exe は止まる）。コメントは `--write-subs --sub-langs comments` で取れる。
- 測るもの:
  - コマの一覧（`ffmpeg ... fps=40/長さ,tile=8x5`）と、境目の前後を細かく並べた帯
  - コメントが集まる位置（10 秒ごとの数、「ん？」「一転攻勢」などの語）
  - 5 秒ごとの音量、帯域ごとの音量の割合
- 一転攻勢は 8 本測って、終盤 15〜40% で替わる、5〜10 秒前に前触れがある、同じ作りのまま中身を替える、と分かった（[techniques/ichiten-kousei.md](techniques/ichiten-kousei.md)）。
- 伴奏の作りは LAB=01☆（sm32354228、タグ「原曲不使用」「MGRoid」）を見て、全部を素材で鳴らすと決めた。
- 原曲の PV も測る。構図は真似ないが、配色は合わせる（エヌは地 `#131313`、ほぼ白の線と字、信号の赤と緑だけ）。

## 3. 素材を集める

- 先に手元を探す: `C:\_own\音MAD素材\地図.md` → 人物ごとの `<名前>まとめ/<名前>素材` → パックの zip（名前は cp932）。無ければニコニコで BB を探して落とす。
- 台詞は全部を一覧にする。ファイル名から読みを作り（pyopenjtalk）、モーラ数と一緒に表にしておくと、歌メロの音数に合う台詞をすぐ選べる。
- 題材に絡む台詞を探す。犬の曲なら TNOK の「犬のまねしろよ」「ワンつってみろよ」、TDN の「ワン！」、YMN の「何か犬っぽくねえなあ？」。
- 絵:
  - アイコンも含め、文字の丸や空欄で済ませない。BB から切り抜く。絵が見つからなければ処理を止める作りにして、気づけるようにする。
  - BB は全コマを確かめる。題字だけのコマ、使用例の字幕、裸が大きく映るコマが混ざる。肩から上や服を着た区間を選ぶ。
  - 青背景・緑背景は、その色と他の 2 色の差で抜き、1 画素ぶん縮める。説明の字幕が入る区間は避ける。
  - OpenCV の `imwrite` は日本語のパスに保存できず、失敗しても黙っている。PIL で保存する。
- 打楽器はクッキー☆なら効果音（ナイフを投げる音、戸、床ドン、手を叩く、指を鳴らす、賽銭箱、風鈴、チーンなど）、淫夢なら `【INM】シンセ/ドラム加工`（センチュリーのスネア、車のドア、ビール、ピストルなど）。
- 伴奏の音色は、クッキー☆なら UDK「うー☆」「あー」や MGRoid などの母音、淫夢なら `シンセ化音声素材/淫夢シンセ`（DB ベース、TDN シンセ、イキスギター、ヌワンペットなど。音名付き）。

## 4. 歌を作る

### 4.1 行ごとに主役を決める

- 替え歌の行はロイドだけで発音させる。語録の行は原音を主役にする。同じ言葉をロイドと語録で重ねない（ちぐはぐになる）。
- 語録は歌メロの音数に近いものを選ぶ。0.9 秒の語録を 3 秒に伸ばすと異常な音になる。

### 4.2 語録を直してから乗せる（全部の語録に）

1. 環境音を引く。静かな所でノイズの形を測ってスペクトルから引き、言葉の間はゲートで切る。
2. モーラに分ける。音の変わり目と音量の谷に加え、カ・サ・タ行は有声から無声へ変わる所を手がかりにする。男声は高さの読み取りの下限を 55 Hz にする（90 Hz では読み違える）。
3. 伸ばすのは母音だけで、子音は元の長さで残す。語尾の無声音（「す」）は伸ばさない。
4. 音高はフレームごとに音符へ合わせる。読み違いの外れ値は補正に入れない。
5. モーラごとに音量をそろえ、飛び出す音節を抑える。

詳しくは [techniques/voice-cleanup.md](techniques/voice-cleanup.md)。

### 4.3 男声の語録

- 男声の語録はメロディより 2 オクターブ低く、質も低い。話す速さを保ち、伸ばすのは 1.3 倍まで。音の頭は 16 分にそろえ、余る長さは繰り返す。
- メロディは淫夢シンセとロイドで鳴らす。

### 4.4 声を前へ出す

- 子音を立てる、2〜5 kHz を足す、残響と付点 8 分の遅延、上下オクターブ（声に合う行だけ）。
- 目安は、言葉の聞こえる帯域（1〜4 kHz）で声が伴奏より +13〜15 dB。音声認識の一致も見る（ロイドを重ねると下がるので目安だけ）。
- 声を強くしすぎると打楽器が埋もれる。どちらを優先するかは所有者に聴いてもらって決める。

## 5. 伴奏とドラムを素材で作る

### 5.1 伴奏

- MIDI の全トラックを素材の声で鳴らす。合成音や原曲の音色は混ぜない。
- 役ごとに鳴らし方を変える。伸ばす音（コード・パッド）、はじく音（「ん」「ワン」を短く）、歪ませる音、低音（下げて高域を削る）。
- 音高は名前や推定を信じず、鳴らして測って合わせる。UDK「うー☆」は 1 半音ずれていた。高さが動く音（「ドン！」）は音階の楽器に使えない。
- パートごとに、鳴っている所の音量を目標値へそろえる（コード −20 dB、低音 −15 dB、はじく音 −24 dB など）。

### 5.2 ドラム

- 場面ごとにキットを替える（1番は戸とナイフ、2番は雨、風景は足音）。
- 一打ずつ立ち上がりの 1.5ms 前から切り、長さを決めて減衰させる（胴 .24 秒、スネア .2 秒、ハット .07 秒）。胴は素材を下げて低い正弦波を足す。
- 大きさはピークではなく、40ms の音量でそろえる。ピークでそろえると、ピークより 19 dB も小さく聞こえる素材があった。
- 場面の変わり目の前 2 拍に 16 分のおかずを入れ、頭にシンバルを置く。
- 打楽器は声が鳴っている間も下げない。

詳しくは [techniques/material-drums.md](techniques/material-drums.md)。

## 6. ミックス

- 高音を削る。効果音の打楽器は高音が多い。ENU☆ はローパスを打楽器 6.5 kHz、声 9 kHz に入れ、8〜12 kHz の割合を手本と同じ −20〜−24 dB にした。
- 帯域ごとの割合を手本の動画と比べる（60〜250、250〜1k、1k〜2.5k、2.5k〜5k、5k〜8k、8k〜12k、12k〜16k Hz）。
- 盛り上がり（一転攻勢）は他より約 4〜5 LU 上げる。8 LU では潰れて声が埋もれた。仕上げの音量は `loudnorm` の動的処理を使わず、線形で下げて差を残す。
- 目安は全体 −11〜−13 LUFS、トゥルーピーク −1 dB。

## 7. 映像を作る

- 原曲の PV は再現しない。図形移動・文字PV・音MADの見せ方で組み直す。配色だけは原曲に合わせる。
- 字はモーラごとにマスクからせり上げる。言葉の途中で改行しない（改行の位置を行ごとに決める）。字のはみ出しは全編を描いて検査する。
- 鳴っている声と素材のアイコンを、音ごとに跳ねさせる。音の高さの位置に置かず、決まった場所でリズムに合わせて揺らすだけでよい。声だけでなく、伴奏とドラムの素材も出す。
- ドット絵:
  - 描き出しの倍率を測って 1 点へ戻す。ENU☆ の素材は 5 倍だったのに、4 倍のつもりで縮めて歪んだ。
  - 全コマを同じ枠で切る。コマごとに切ると高さが変わり、同じ高さへ伸ばすと歪む。
  - 拡大は整数倍だけにする。画面全体を拡大するカメラの動きも点を崩すので、縦に整数ぶんずらす揺れに替える。
- 新しくドット絵を描かない。所有者の素材と BB を使い、風景に置くときは場面の光に合わせて色を補正する。
- 人物と乗り物は向いている方向へ動かす（車が前を向いたまま後ろへ走っていた）。
- 高速の色替えや点滅をしない。

## 8. 一転攻勢（最後のサビだけ）

- 最後の盛り上がりだけを淫夢に替える。2 番ごと替えない。
- 前の場面と同じ地・同じ配置のまま、中身だけを替える（サビの 3 枚の窓が TNOK と DB になる）。
- 6 小節ほど前から前触れを入れる。遠くの人影、小声の語録、裏で鳴るスネア、通り過ぎる車。
- 配役は題材に絡む俳優を優先する（犬の曲なら第一章の TNOK・DB・TDN。野獣先輩・MUR より優先）。
- 淫夢の打楽器を打つたびに、対応する BB が跳ねる（車のドアならドアの BB、拳銃なら銃の BB）。
- 音圧を上げ、赤い信号の光で画面を埋める。
- 終わりは「幸せなキス」（TDN と HTN の夜景のキスに `幸せなキスの音` を合わせた）。少女の見た目のキャラ同士では描かない。

## 9. 確かめて渡す

- エージェントは耳で聴けないので、測れるものは全部測る。
  - モーラごとの音量の飛び出しと、音符からの音高のずれ（オクターブ違いは除く）
  - 帯域ごとの割合、区間ごとの LUFS、トゥルーピーク
  - 音声認識の一致（ミックス全体）
- 映像は一覧 1 枚と、境目の前後を細かく並べた帯で見る。動きのある所（車・人物の移動）は連続したコマで確かめる。
- 音だけ直したときは、映像を描き直さずに音を差し替える（`ffmpeg -c:v copy`）。
- 渡すときは、変えたこと・測った値・確かめられなかったこと（耳で聴いていない、動きは止めたコマだけ）を分けて書く。

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 声が伴奏にかき消される | 子音・帯域・残響・オクターブで前へ出し、1〜4 kHz の差を測る |
| 語録が異常な音・耳障りになる | 引き伸ばさない。環境音を引き、モーラごとに直してから音高を合わせる |
| アイコンが空欄・文字の丸 | BB や手元の絵から切り抜く。無ければ止める |
| ドット絵が歪む | 倍率を測って 1 点へ戻し、整数倍で拡大。全コマ同じ枠 |
| 一転攻勢が長すぎる | 最後のサビだけ。手本を測ってから作る |
| 伴奏が合成音のまま | 全トラックを素材で鳴らし、鳴らして音高を測る |
| 打楽器が小さい・高音が痛い | 40ms の音量でそろえ、ローパスを入れ、手本と帯域を比べる |
| 消したつもりの無いパートが消える | 構成を変えたら、前の版にあった場面を一覧で照合する |
