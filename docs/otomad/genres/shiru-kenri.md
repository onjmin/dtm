# 知る権利シリーズ（○○先輩BB＋使用例）

淫夢の BB 素材を切り貼りして新しい BB 素材（物と化した先輩）を作り、その作り方を見せ、使ってみせる型。ニコニコのタグ「知る権利」が付く BB先輩シリーズ・蠢くBBシリーズの作品群（2026-11-08 に検索と手元の `知る権利シリーズ/` で調べた）。

## 作法

- **題材は先にあるか検索する**（`bb_fetch.py search <物> 先輩BB`）。扇風機・信号機・時計・鏡餅・雪だるま・洗濯機・ハンバーガー・パトカーは既にある（11-08）。
- **部品を物の形に並べ、部品ごとに単色を被せる**（所有者 11-08「BBは配置した後単色で塗ってますよね？」「もっと色濃くしたほうがいい（だから私は単色という表現を使った）」）。ビッグマック先輩BBはパティ＝顔の列を茶、レタス＝体を緑、バンズ＝体を橙に塗っている。塗りはほぼ一色にし、陰影はわずかに残すだけ。光沢・頬紅・模様を描き足さない。物の細部（ゴマ・目・文字）は塗りの上に描いてよい。斑やひげのような細部も、別の部品（小さい顔・腕）に色を被せて作る。
- 部品は手元の野獣先輩BB作成キット（`一軍その１/野獣先輩まとめ/野獣先輩素材/野獣先輩BB作成キット/`）に、顔・拳・手・胴・腿・すね・足の甲・尻・水着の透過 PNG がある。
- **BB素材の区間**は単色の地（青か緑）で、物をループで動かす。部品を少しずつうごめかせる（別々の BB を並べた感じ）。差分（向き・手・止め）は札で区切って並べる。
- **種明かしは塗りを外すだけ**（所有者 11-08「単に単色を外すだけであって、構成素材を丁寧に分解したりしませんよね」）。その場で元の肌の色に戻し、また塗る。部品をばらして並べ直したり、札を付けたりしない。
- **使用例は劇にする**。合成の見本を並べるだけでは「つまらない」（所有者 11-08）。物の役目（招く・走る・回る）で筋を作り、塗りが取れる（雨・水・汚れ）ことを筋の転にすると、種明かしが伏線になる。物の材料の人物の関係者を客や相手にすると、配役に理由が付く。
- 人物を動かす向きは絵の向きと合わせる（[rules.md](../rules.md) §3）。茶碗の欠片式の立ち絵は左向きのものがあるので、置くたびに確かめる。
