# 知る権利シリーズ（○○先輩BB＋使用例）

## 作法

- **題材は先にあるか検索する**（`bb_fetch.py search <物> 先輩BB`）。扇風機・信号機・時計・鏡餅・雪だるま・洗濯機・ハンバーガー・パトカーは既にある（11-08）。
- **物は手元の部品で組む**。野獣先輩BB作成キット（`一軍その１/野獣先輩まとめ/野獣先輩素材/野獣先輩BB作成キット/`）に顔・拳・手・胴・腿・すね・足の甲・尻・水着の透過 PNG がある。色を塗り替えて物に見せる（肌を陶器の白に焼く、水着を赤に、尻を金に）。部品そのものを描き足さない。
- **BB素材の区間**は単色の地（青か緑）で、物をループで動かす。差分（向き・手・止め）を札で区切って並べる。
- **種明かし**は部品をばらして元の色へ戻し、「小判 ＝ 尻」のように一つずつ札を付ける。意外な部品ほど笑いになる。最後に組み直す。
- **使用例**は合成の見本を数秒ずつ（物が似合う場所に置く）。
- **BB劇場**は物の役目（招く・走る・回る）で筋を作り、最後は物が壊れて部品へ戻ると種明かしが伏線になる。物の材料の人物の関係者を客や相手にすると、配役に理由が付く。
