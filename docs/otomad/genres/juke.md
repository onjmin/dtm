# じゅーけー式（アニメの台詞を曲の拍で繰り返す音MAD）

アニメの1キャラの台詞と場面の音を、既成曲（ゲーム曲・クラブ系）の拍に乗せて繰り返す型。手本はじゅーけーさんの3作で、根拠の測定は [research/juke-sync.md](../research/juke-sync.md)。

## 型の芯

- **2小節の型を作り、区間の中で4回まったく同じに繰り返す**。同じ切り抜きが同じ位置に戻ってくることがノリになる。2小節ごとに台詞を替えると「適当に配置しただけ」に聞こえる（所有者 11-07）。
- **偶数小節の頭で台詞を1つ、語りの速さのまま言う**。モーラを16分へ1つずつ合わせない。速さも変えない。
- **奇数小節は語尾を旋律の音で連打する**。語尾は台詞の最後の語（「何?」「来るの」「見て」）。
- **効果音をスネアとキックに置く**。奇数小節の頭にパンチ、2・4拍目（スネア）にピストルのように、キャラが映っている場面の音を打楽器にする。効果音は台詞を切らずに上から重ねる。
- **絵は音ごとに2つの場面を交互にする**。台詞の場面と、同じキャラの別の場面（相方）。同じ構図どうしだと替わって見えないので、寄り・全身・別の回から1つずつ取る。
- **8小節（区間）ごとに台詞を替え、筋を通す**。主演回の筋をそのまま追う（例: 運動会って何? → 小林、来るの → 明日行くよ／本当? → よーい → ここから逆転する → 小林大好き → うん 頑張る → 最後に別のキャラのツッコミ）。

2小節の型の例（161 BPM、16分で1マス、「‖」が拍）:

```
偶数 | 運動会って何? → 小節いっぱい
奇数 | パンチ | ・ | 何? | ・ ‖ ピストル | ・ | 何? | 何? ‖ 何? | ・ | ・ | ・ ‖ ピストル | ・ | 何? | 何?
```

## 置き方の細かい決まり

- **語尾は言い切れる長さの所にだけ置く**。次の音まで16分1〜2つしかない所に0.5秒の語を置くと「ぎゃ」「み」で途切れ、耳心地が悪い（「逆転」で指摘、所有者 11-07）。語の長さを測り、次の声までに収まる位置（旋律の音のうち、間が空いている所）を選ぶ。
- **声の切り抜きは最初のモーラの頭から鳴らす**。書き起こしの区間の頭に 0.3〜0.4 秒の無音が入っていることがあり、そのまま使うと絵より声が遅れる。声の大きさで頭と終わりを詰める。
- **1小節より長い台詞は、息つぎの間を抜いてつなぐ**（「小林、」＋「来るの」）。語尾の伸ばし（「行くよー」）は短く切る。速さは変えない。
- **語の切れ目は書き起こしの時刻を信じすぎない**。声の大きさの谷（子音）で切る。前の語の終わり（「から」の「ら」）が混ざらないか確かめる。
- **語尾の連打の位置は区間の旋律の型から取る**。区間（8小節）の偶数・奇数小節ごとに旋律の音の頭を平均し、毎回鳴っている16分だけを使う。曲が奇数小節で同じでも、毎回同じ位置になる。
- **16分の走句と休みの小節は別の扱い**。走句は小節の頭に短い言葉（「かけっこ」）、残りは足音などの効果音で詰める。休みの小節は「おー」「任せて」と、キックの位置に水しぶきなど。
- **イントロとフィルで筋の頭を作る**。先生「もうすぐ運動会です」→ フィルの小節で「よーい」→ 主旋律の頭でピストル。

## 素材

- **そのキャラの主演回から取る**。Wikipedia の話数一覧で主演回を確かめ、その回の場面の切り抜きを探す。YouTube に本編が無くても、回ごとの場面の切り抜きは残っていることが多い（「〜の回」「Kanna's sports festival」など英語でも探す）。
- **公式以外のアップロード（転載）も所有者の判断で使ってよい**（11-07）。英語字幕が焼き込まれた切り抜きは、上 78% を 16:9 のまま切り出して字幕を落とす。左右反転・色変えされた転載は使わない。
- **効果音はキャラが映っている場面の音から取る**。Demucs で声を抜いた残り（no_vocals）で、声が小さく、直前より 12dB 以上跳ね上がる所を探し、その時刻の絵を見て選ぶ。投稿者のロゴの音（0.5 秒おきの同じ跳ね上がり）は除く。
- **絵が台詞の主と違うことがある**（台詞の主が画面外、別のキャラの寄り）。台詞ごとに絵を1枚見て、主が映っていなければ別の場面を当てる。脚・スカート・胸の寄りは使わない。

## 作る順

1. **曲を測る**: テンポ、小節の頭、30〜32 小節の周期、区間（主旋律・第2旋律・走句・休み・フィル）。Demucs の4分離で旋律（other）とドラムを分け、小節ごと16分の格子に出す。
2. **8小節のループを作り方違いで2〜3本作って、所有者に聴いて選んでもらう**。16分の配置表を添えて、位置で直しを受けられるようにする（エージェントは音を聴けない。数字で合わせても音楽になるかは分からない）。
3. **選ばれた型で全体へ広げる**。区間ごとの配置表を書き出して一緒に渡す。
4. **直しは区間ごとに**。直さない区間は前の版と波形が同じことを差分で確かめる。

## やらないこと

- **エフェクト（拍の拡縮・周波数グラフ）は付けない**（所有者 11-07「エフェクトはやはり不要」）。
- **台詞を旋律の音高に合わせる声シンセ（人力歌わせ）にしない**（11-07 に試して「シンセ化はやめる」）。サビを声で鳴らすなら母音を伸ばす方向。
- 題名・字幕・題字を画面に入れない。題名は投稿時に付ける（じゅーけーさん風なら「台詞【曲名】」、キャラ名のもじり「カンナカムサニー【SUNNY】」など）。
