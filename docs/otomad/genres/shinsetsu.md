## 何が受けるか（2026-11-22、タグ全 2974 本を snapshot API で集計）

## 型の作法

- 語りは合成音声でなく字幕窓（画面下の帯）。字幕窓は題材の見た目に寄せる。
- 字幕窓には「野獣のメッセージウィンドウBB」（sm22671105、野獣の目元が透ける窓。ピンキー・GO・クッキーの版と薄い版もある）を使う（所有者 11-19）。`bb_fetch.py get sm22671105` → `key sm22671105 野獣メッセージウィンドウ --ss 0.1 --to 4.0`（濃い版は 0〜4 秒、窓は 640x480 の 331 行目から下）。窓の左上の見出しに区間の名（序論・根拠①…・結論）を出す。字は白に黒のふち。
- 導入のあとに題「野獣先輩○○説」を画面いっぱいに出す（所有者 11-19。rules.md の「題名を入れない」の例外）。書体は【INM】フォントの創英角ポップ体。
- **導入は毎回変える**（所有者 11-22「導入がいつも同じ。1919人とか」）。「延べ 1919 人の学者・114514 の説」＋インタビューの絵は電卓説・幽霊説で使ったので、もう使わない。題材の側から入る（例: 不動産屋説は本編の門の前で「この家の門を覚えているだろうか」、ジャイロ説は「1890年。アメリカ大陸横断レース」）。
- **SE・BGM も作品ごとに替える**（所有者 11-22「いつも使っている SE は多少変えろ」「グルメレースも多用し過ぎ」）。使う前に `grep -rl <ファイル名> scripts/otomad/songs` で使った回数を数え、2回以上のものは避ける。避けるもの（11-22 時点）: 殿下のカーン・バァン！・デデドン・チーン・インタビューのシャッター・野獣亭ドア、BGM は激突！グルメレース・Sandstorm・潮風とベンチ・緊張・祭り・飛翔。題材に寄せた SE を探す（内見ならノックとインターホン、ジャイロなら金属音と銃）。
- **題材の作品で今話題の曲は、頭から前面に出す**（所有者 11-22「死ぬか生きるかは人気なので初手から使って前面に」）。ジャイロ説は ED『死ぬか生きるか』で始まり、歌の決まり文句（「スティール・ボール・ラン」×3）に題を 1 語ずつ合わせ、結論で画面を止めて ED のサビへ入れた。間の根拠も歌を抜いた伴奏で敷き、歌詞そのものを根拠に使う。スタンド名の元ネタの曲は最強点に。
- **擬音は素材を使う**（所有者 11-22）。手書きの書体で「ゴゴゴ」を打たない。字だけの擬音は JOJO風文字入れツール（web.save-editor.com）のフォント Bizareadventure（素材フォルダ AI/ジョジョ/font。カナは JIS かな配列の位置、ゴは別形が 24 個）で描き、見せ場は動く素材を重ねる: アニメ戦闘潮流のゴゴゴ GB（sm37378277）、ジョジョ風文字の BB（sm26543695 のドドド白・ゴゴゴ黒など）。コモンズ nc217023（ドゴドゴ GB）は利用許諾に同意して落とす。
- **本編の秒数表示は出さない**（所有者 11-22「不要」）。
- **枠・小さい説明書き・根拠の一覧は出さない**（所有者 11-22「AI 臭い」「基本的に枠とか不要」）。札は大きい字だけ（「ED テーマ（千葉雄喜）」のような見出しや副題を足さない）。終盤に根拠①〜⑤を並べ直さない。字幕窓（野獣のメッセージウィンドウ）は別。
- **説明の途中で予防線を張り、急に暴言を吐く**（所有者 11-22）。「『こんなステハゲが○○な訳ないだろいい加減にしろ！』という視聴者もいるかもしれないが、」→ 黒地に赤い太字で「黙って最後まで見ろ！」。真顔の論文調の中で口調が崩れる所が笑い所。根拠の途中で1〜2回。
- 根拠は黒地に「根拠①」の札で区切る。1つの根拠は「題材の事実 → 野獣先輩の事実（その台詞の場面）」の対。
- 野獣先輩側の「事実」は、素材と界隈の本当のことから取る。絵を加工して作らない（所有者 11-19）。例: インタビュー BB には元から足が映っていない（＝幽霊は足が無い）、声の素材は増えず同じ台詞が使い回される（＝同じ言葉を繰り返す）、野獣先輩に見える物の写真（ヤジュミエール症候群。大百科の定義で「創作されたもの」は除く）。四章の絵に赤丸を付けても顔には見えない。
- 山は2つ: 数字・文字のこじつけ（アナグラム・計算）と、「よって野獣先輩は○○である（Q.E.D. 証明終了）」。コメントは「は？」「草」「ファッ！？」「有力」「やったぜ。」で、終盤（アナグラム・証明）に集まる。
- 終わりは題材の結末の場面か爆発。そのあとに一言の二段オチ。

## 安全の線

- 四章は 3:00 より前（帰り道・玄関・ソファの会話・屋上の遠景）だけを使う。飲み物以降の場面とその台詞（アイスティー・暴れんな など）は使わない（[rules.md](../rules.md) §5）。
- 実在の事件・人物と結びつけて詮索する説（三億円事件・政治家など）は作らない。物や架空のものにする。
