# 2号式（2号兄貴の型）

素材だけ借りて曲は自作する。面白さの核は落差: 汚い・下品な淫夢素材の裏で、セブンスの効いたおしゃれなテクノが鳴る。所有者の言葉:「淫夢の汚い素材で裏に流れている曲がいいのが2号スタイル」。

根拠: [research/nigo-kousatsu.md](../research/nigo-kousatsu.md)（作風）・[research/nigo-mad-analysis.md](../research/nigo-mad-analysis.md)（音）・[research/nigo-video-research.md](../research/nigo-video-research.md)（映像）・[docs/research/kaiwai-lineages.md](../../research/kaiwai-lineages.md)（界隈曲の実測）。

## 曲

- テンポ 140〜180（中央145）、4つ打ち＋裏8分ハット、ベースは8分オクターブか 3:3:2。
- 和音はほぼ全部セブンス、2拍ごと。ⅣM7 が最多、2-5 とその連鎖、ⅣM7–Ⅲm7 の往復。
- 旋律はペンタ中心、16分と3連、広い音域。リードは休まず鳴り続け、4小節の動機を ABAB で回す。最後に全音上へ転調することがある。
- 層は同時4〜5（リード・セブンスの刻み・パッド・ベース）。
- 見本: `scripts/speech-melody/build_example.py`。
- 音色の物差し（[research/nigo-cookie-frames.md](../research/nigo-cookie-frames.md)）: 左右の相関 0.3〜0.6、波高率 14〜16 dB、山は 800〜1600Hz。旋律は高い音域のまま鳴らす。サイドチェインと長い残響は使わない。

## 声

- 大半は楽器に作り替える（[techniques/voice-instrument.md](../techniques/voice-instrument.md)）。音節を16分に1粒ずつ刻む。
- ただし**シンセに寄せすぎると素材の良さが消える**（所有者 11-05、cm24 第1版「シンセによりすぎて元の素材の良さが失われてる」）。母音だけの楽器を主役にせず、台詞のイントネーションを旋律として多く聴かせる。
- 生の台詞は数か所。きれいに始め、「ん？」とためて、後半や最後に原液で落とす。
- 音量は曲が上（声 −5〜−12 dB。[techniques/audio-mix.md](../techniques/audio-mix.md)）。
- 台詞を旋律に抜擢してもよい。そのときは [techniques/speech-melody.md](../techniques/speech-melody.md)。

## 映像

- 中央に1つの窓か対象、周りは模様・万華鏡・幾何学の地。色は1曲ほぼ1系統。
- 地と窓は曲の構成に合わせて増え、人や台詞の主は最初は隠し、後半で出す（音の「隠してから落とす」と同じ）。
- 素材の映像がほとんど無くても成り立つ。文字と図が主役でよい。
- 動きは小さく、絵の替わりと層の増減で構成を見せる。崩し（砂嵐・熱画像）は終盤に一度だけ。最初の少なさへ戻るか、小さな形へ閉じて終わる。切り抜きの縁は白くギザギザでよい。
