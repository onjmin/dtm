# 譜面の全パートを素材で鳴らすカバー音MADの作り方（[ ]☆）

界隈曲の耳コピ MIDI を、初代クッキー☆の台詞・声・効果音だけで鳴らし直したカバー音MAD（作品ID kakko1、題の案「[ ]☆」、11-13）の作り方を工程順にまとめる。曲は所有者の耳コピの譜面、MV は所有者の注文「映像科の学生が作ったような前衛的で挑戦的に」。

- 守る基準は [rules.md](rules.md)、工程の全体は [how-to-make.md](how-to-make.md)。ここはそれに足すことを書く。
- MV の仕掛け（括弧の中を時間の軸にして、鳴った位置にだけ場面を刷る）は [techniques/time-axis-print.md](techniques/time-axis-print.md)。
- 作品のスクリプトと台帳は手元だけにある（git に入れない決まり）。ここには、それが無くても作り直せるだけの手順と数値を書く。使った部品のうち git に入っているものだけにリンクを張る。

## 0. 骨組み

| 層 | 中身 |
|---|---|
| 譜面 | 所有者の耳コピ MIDI（歌3声部・ベース・和音・裏の刻み・ピアノ・オルゴール・掛け声・モールス・ドラム）。128 BPM、16分はシャッフル |
| 台詞 | 初代クッキー☆の冷蔵庫の場面（材料が無い）の台詞だけ。台詞イントネーション作曲で旋律にする |
| 歌メロ | 譜面の歌を声のシンセが歌う（YMN「るぅ＾～」、UDK「あーっ」） |
| 伴奏 | 譜面の全トラックを、初代クッキー☆の声と効果音で鳴らす。合成の波形は使わない |
| 映像 | 紙の白と1組の括弧。括弧の中が時間の軸で、鳴った位置にその音の本編の場面を網点で刷る |

作りの流れは他の作品と同じ（[video-making.md](video-making.md) の「0. 作りの骨組み」）。曲を組む側が、鳴った時刻と誰の何の音かを一覧（placement.json）に書き出し、映像はそれだけを見て描く。音だけ直したときは映像を描き直さず、音を差し替える（`ffmpeg -c:v copy`）。

## 1. 振り切る軸を決める

作る前に台帳へ書いた軸は2つ（AGENTS.md「Making an otomad video」・[rules.md](rules.md) §1）。

1. **言葉は1語へ痩せていく。** 台詞は本編の1場面の中だけから取る。前半は文のまま旋律にし、サビは合いの手も刻みもその1語の2モーラだけにし、最後はその1語の台詞で音を全部止める。
2. **余白。** 画面は紙と括弧だけ。鳴っていない所には何も描かない。

題が記号（「[ ]」）の曲は、その記号を画面の唯一の図形にすると、題名の字を出さずに題を見せられる（[rules.md](rules.md) §3「動画の中に題名を入れない」）。

台詞を1場面に絞ると、配役も物語も自然に決まる。登場人物は、その場面の共演者だけになる。物語は場面の順のまま（起: 冷蔵庫を開ける → 承: 材料が無い → 転: 使ったのは別の人物で、伴奏を止めて決め台詞を原音で → 結: 1語の合唱 → 二段目のオチ → 1語で終わる）。

## 2. 譜面を読む

- 16分（192 ステップ）に量子化してから読む（生の tick で読むと結論が逆になることがある）。トラックごとに音数・音域・最初と最後の小節を出し、小節ごとにどのトラックが鳴っているかの表を作る。区間の切れ目はこの表で分かる。
- 小節 0 は音源の設定だけ（音の無い小節）なので落とす。マーカー（Start など）も見る。
- **シャッフルを確かめる。** 音の頭が 16分の格子の 1/3・2/3 にあれば、8分を 2:1 に割るシャッフル。台詞と打楽器も同じ格子に置く。曲頭からの 16分の番号 `s` から秒へ: `((s // 2) * 2 + (s % 2) * 4/3) × 16分の長さ`。真っ直ぐの 16分に置くと、裏の音が全部 1/3 早く聞こえる。
- 後奏が長い曲は、映像の尺に合わせて詰めてよい（この作品は後奏 16 小節を 8 小節にした）。

## 3. 台詞を置く

台詞の置き方の基本は [techniques/speech-melody.md](techniques/speech-melody.md)。この作品で足したこと:

- **調は小節ごとの和音から決める。** ベースの根音から、その小節で使うペンタ（短調の主・下属・属）を表に持ち、台詞の真ん中が落ちる小節のペンタへ寄せる。移調は ±3 半音まで、句の最後の音が根音か5度に落ちるものを選ぶ。
- **置き方を句ごとに3つから選ぶ。**
  1. 強制整列（[scripts/speech-melody/voice.py](../../scripts/speech-melody/voice.py) の `place`・`render_voice`）: 長い句。
  2. 言葉の区切りごとの一様な伸縮: 強制整列が数モーラに潰れた句。無音（0.12 秒より長い）で句を切り、区切りごとに一様に伸ばして、区切りの頭をシャッフルの 16分へ置く。音程は区切りの中のモーラごとにペンタへ寄せる。モーラの境目が怪しい句は、句全体の移調だけにする。
  3. 原音のまま頭だけ格子へ: 加工すると言葉が崩れる短い句（「作れない」「遊んでポイか」）。話す速さが 16分にほぼ合うものだけ。
- **選ぶ前に聞き取りで確かめる。** 原音と加工後をそれぞれ whisper-small で書き起こし、文字列の一致（difflib の比）を句ごとに出す。0.4 以下は置き方を替える。初版では 9 句が 0〜0.4 だった（「どれどれ？」が「うぅぅぅ…」になる、など）。直した後は要の句が 1.00、長い句が 0.6〜0.9。
- **1語の2モーラを切り出すときは、切り位置を聞き取りで決める。** モーラ境界の推定で切ると「この」「はい」「ん」に聞こえた。句の後ろから 0.03 秒ずつ頭を動かして書き起こし、「ない」と読めた範囲の真ん中で切る。台詞によっては、どこで切っても読めない（「つくれない」の「ない」は「ん」になった）。そのときは別の台詞から切る。
- 1語の合いの手は、譜面の掛け声のトラック（hey）の位置に置き、人を順に替える。後半は1小節おきに減らして層を引く。

## 4. 伴奏を全部素材で鳴らす

所有者の指摘（11-13「ベースもクッキー☆素材にしていますか？」→「全部クッキー☆素材にしたい」）で、初版の鋸波・矩形波の伴奏を全部替えた。基準は [rules.md](rules.md) §4「伴奏も全パート素材で鳴らす」と [techniques/material-drums.md](techniques/material-drums.md) の「伴奏も全部素材で」。**音MADのカバーは最初から全部素材にする。**

### 4.1 楽器にする声を選ぶ

- 同じ作品（初代クッキー☆）の台詞を 20 ほど候補にして、WORLD の harvest で高さを取り、**半音以内で平らに続く区間**の長さと高さを測る。長いものから選ぶ。0.2 秒あれば繰り返して伸ばせる。
- 癖のある声、場面が浮かぶ声を選ぶ（[techniques/voice-instrument.md](techniques/voice-instrument.md) の「素材の選び方」）。
- 鳴らし方は桔梗☆で通った声のシンセ（[scripts/otomad/tools/voice_synth_export.py](../../scripts/otomad/tools/voice_synth_export.py) の `VoiceTone`）。WORLD で響きと息に分け、目標の高さで組み立て直す。再生速度で高さを変えないので、2オクターブ下げても声色が保てる。

| パート | 素材 | 平らな所 | 元の高さ | 鳴らし方 |
|---|---|---|---|---|
| ベース | 魔理沙「うーん・・・」 | 0.84 秒 | A#3 | D#1〜B2 まで下げる。下の 4.2 |
| 和音 | パチェ「あー」 | 0.52 秒 | C4 | 立ち上がり 60ms で伸ばす。右だけ 11ms 遅らせて広げる |
| 裏の刻み・ピアノ | ルーミア「そーなのかー」の「そー」 | 0.42 秒 | F4 | 頭の子音を残してはじく（減衰 0.16〜0.22 秒）。音ごとに左右へ散らす |
| オルゴール | 咲夜「からしの～霧～」の「の～」 | 0.29 秒 | C5 | 1オクターブ下で鳴らす（C7 近くは声が細くなった） |
| モールス | お空の場面のアラームの効果音 | — | C#4 | 1オクターブ上げて刻む |
| 歌（主旋律） | YMN「わたしも食べさせるぅ＾～」の「るぅ＾～」 | — | C5 | 桔梗☆と同じ切り方 |
| 歌（長い音の区間）・刻み | UDK「あーっ・・・」 | — | A#3 | 1オクターブ下げて小さく |

- 鳴らした後に全部の音の高さを測る。楽器ごとに 4〜6 音を鳴らして ±0.02 半音以内、ベースの長い音 233 個は全部が音名どおりに読めた。

### 4.2 ベース

声を2オクターブ下げると、高さは合っても基音が弱く、音程が聞き取りにくい。次を足した。

- 160 Hz から下を 7 dB 持ち上げ、3.2 kHz で落とす。
- スラップ風: 700 Hz より上の成分だけを、頭で 1.85 倍 → 50ms で 0.25 倍まで落とす。頭に指パチンの効果音（1.5 kHz より上、14ms）を薄く足す。
- 1オクターブ上の同じ声を、減衰を短くして 0.32 倍で重ねる（150 Hz〜1.8 kHz）。音程はこの層で聞こえる。
- 圧縮（閾値 −20 dB、比 4、立ち上がり 8ms）。

### 4.3 ドラム

キットは [techniques/material-drums.md](techniques/material-drums.md) の作りで、場面に出てくる効果音から組んだ。

| 打楽器 | 素材 |
|---|---|
| キック | 「ドンッ」を1オクターブ下げ、3 kHz で落とし、120 Hz より下を 12 dB 持ち上げる。**合成の正弦波の胴は足さない** |
| スネア | 冷蔵庫を開ける音（場面の最初の音）＋ナイフを投げる音 |
| ハット | 指を鳴らす音 |
| シンバル | 「チーン」。区間の前の逆シンバルは、これを逆さにして区間の頭で終わらせる |
| フィル | 「パチン」（1つは 5/4 倍の速さで高く） |

- 場面の最初の音（冷蔵庫）をスネアにすると、頭の物音が全編で鳴り続けて最後に同じ音で閉じる（伏線になる）。
- ドラムの束にも圧縮（閾値 −14 dB、比 3）。

## 5. ミックス

- パートごとに、鳴っている所の RMS を目標値へそろえてから足す（ベース 0.15、ピアノ 0.085、刻み 0.07、和音 0.06、オルゴール 0.055、ドラム 0.2）。
- パートごとの EQ: 和音は 180 Hz より下を切り 2.8 kHz を −2.5 dB、刻みは 230 Hz より下を切り 3 kHz を −2 dB と圧縮、オルゴールは 400 Hz より下を切る。
- 区間ごとに伴奏の量を変えて段を付ける（起 0.8、承 0.95、歌1 1.0、歌2 0.75、サビ 1.35、後 0.9、終 0.8 倍）。止めの所と最後の1語の後は伴奏を無音にする（20ms で落とす）。
- 台詞は伴奏より +5.5 dB。台詞が鳴っている間だけ、伴奏の中域（280 Hz〜6 kHz）を 3 dB 下げる。
- **声のシンセの主旋律は、伴奏より上げない。** サビで主旋律を伴奏より上（−10.3 dB）にしていたら、所有者に「1:45〜の SIK の主旋律がうるさい」と言われた。主旋律を −5 dB、オクターブ上の重ねをさらに −4 dB して −16.2 dB（伴奏は −12〜−13 dB）にした。サビの強さは伴奏の量で出す。
- 原曲への帯域合わせ: 所有者の仕上げの書き出し（mp3）を、11 帯（35 Hz〜16 kHz を対数で等分）の割合で比べ、差の 9 割・±6 dB までを FIR で3回寄せる（[techniques/ust-cover.md](techniques/ust-cover.md) の参照 EQ と同じ）。原曲の頭に設定用の1小節があれば、その分ずらして同じ区間どうしで比べる。
- 仕上げ: −14 LUFS に線形で合わせ、ffmpeg の `alimiter` で天井を押さえる（[techniques/audio-mix.md](techniques/audio-mix.md)）。

測った値（第3版。目安で、合否にしない）:

| 区間 | 起 | 承 | 歌1 | 歌2 | 止め | サビ | 後 | 終 |
|---|---|---|---|---|---|---|---|---|
| mix の RMS（dB） | −17.4 | −15.3 | −16.2 | −15.1 | −16.2 | −13.5 | −16.0 | −19.1 |

- 仕上げ −14.1 LUFS、ピーク −0.5 dBFS、LRA 5.1。
- 帯域（全体比）: 20–80 Hz は合成の伴奏の版 −12.7 → −8.9 dB（原曲 −7.8）、1–2.5 kHz は −6.1 → −11.5 dB（原曲 −12.6）。6 kHz より上は −18.5 dB で、原曲（−13.8）よりまだ暗い。補正が ±6 dB の上限に4帯で当たっている。高い所を上げすぎると「耳が痛い」と言われた過去がある（[rules.md](rules.md) §4）ので、そこで止めた。

## 6. 映像

仕掛けの作り方は [techniques/time-axis-print.md](techniques/time-axis-print.md)。区間ごとの見せ方:

| 区間 | 音 | 絵 |
|---|---|---|
| 起 | ベースとドラム、2小節に1句 | 小さく閉じた括弧が、台詞のモーラが進むぶんだけ開き、その幅だけ場面が見える |
| 承 | ＋和音・刻み、台詞の旋律を4小節で回す | 1小節を括弧の幅にして、モーラごとに場面の帯を刷る。4小節ごとに網点の種類を替え、3周目から朱の版ずれを足す |
| 歌1 | 声のシンセが歌う | 2小節の幅。歌の音を朱の横棒（音の高さの位置）で刷る |
| 歌2 | 2人の会話 | 括弧を2組並べ、話す人ごとに左右へ刷る。1語の台詞で向かいの括弧を3つに割って消す |
| 止め | 伴奏なし、決め台詞を原音で → 1拍の無音 | 小さい括弧に本編のコマが1枚、全編で唯一の色。言い終わると紙だけ |
| サビ | いちばん強い | 地を黒に反転。1語の合いの手ごとに、その声の場面を白で刷る |
| 後 | 層が減る | 白へ戻る。刷った帯が穴あきになり、最後は横の万線に替わる |
| 終 | ベースとドラム → 1語で全部止まる | 括弧が1小節ごとに縮み、最後の1語の間だけ小さな閉じた括弧、言い終わると紙だけ |

- 上と下の帯に、伴奏の楽器を刻む。上はドラム（キックは墨の四角、スネアは冷蔵庫の場面の小さなコマ）と、刻み・オルゴールの声の場面。下はベース（魔理沙）と和音（パチェ、伸びている間は線を引く）。所有者の基準「今何の素材が鳴っているのか表示する」（[video-making.md](video-making.md) §1 柴又系）を、余白の画面の中で満たすための置き方。
- 本編との照合で当たりが弱かった効果音（相関 0.16〜0.49）は、場面を出さず図形だけにした。
- 字・題・字幕は出さない。本編のコマの下の台詞枠は切り落とす（止めの1枚だけ枠が残る）。
- サムネは専用のコマ（[techniques/thumbnail.md](techniques/thumbnail.md)）。前半の2人の顔を 5.2 倍に寄せて彩度 1.7 倍、真ん中に太い括弧。字は入れない。

## 7. 確かめる

- 台詞: 原音と加工後の書き起こしの一致を句ごとに（§3）。
- 声の楽器: 全部の音の高さ（§4.1）。オクターブ違いと 0.3 半音以上のずれを数える。
- 区間ごとの音量（mix・伴奏・シンセ・台詞を別に）と、止めの所の伴奏が無音か。
- 原曲との帯域（7帯の全体比）。
- 本編との照合: 台詞ごとのコマを一覧1枚に並べ、本編の台詞枠の文が台詞と一致するか（20 句とも一致）。
- 映像: 区間ごとのコマを一覧1枚と、止めの前後を 0.25 秒おきに並べた帯。6秒ごとの明るさ・墨の割合・動き。この作品では動きが「後」でいちばん大きく、サビは2番目だった。サビの強さは反転と音量で付けている。
- 耳では聴いていない、と渡すときに書く。

## 9. 残っていること

- 台詞と伴奏の和音の合い方（こすれ）は測っていない。
- 6 kHz より上が原曲より約 5 dB 暗い。
- 配役の確かめ（`scripts/otomad/analysis/cast_check.py`、AGENTS.md「Casting」）は、この作品の後にできた決まりで、まだ通していない。本編の役どおりの声だけを使っている。
- 使い回せる部品（言葉の区切りごとの伸縮、1語の切り位置を聞き取りで探す道具、平らな伸ばしの調べ、原曲への帯域合わせ、括弧と網点の描画）は、まだ作品のスクリプトの中にある。次に使うときに `scripts/otomad/lib/` へ出す。
