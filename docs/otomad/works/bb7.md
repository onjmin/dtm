# シネマティック・バトルクッキー☆『THE COOKIE☆ 宿命の決戦篇』（bb7、2026-11-01）

## 狙い（1文）
戦いに至る日常・事件のストーリー（前説明）から始め、決戦でシネマスコープへ移行し、最大山場でIMAX全画面解放するアスペクト比演出と、3D透視投影・Z軸立体アクション（奥への吹っ飛び・手前飛び出し）、ムーンウォークの完全撲滅を徹底する。

## 振り切る軸
1. **場面連動アスペクト比（黒帯の意図的運用）**:
   - 日常・事件発生のストーリーパート（前説明）は 16:9 フルスクリーン（黒帯なし）。
   - 決着へ赴く決意の瞬間、上下から黒帯がせり出して 2.39:1 シネマスコープへ突入。
   - クライマックスの最大打撃（DIVINE IMPACT）の激突瞬間、黒帯が上下に吹き飛んで **IMAX全画面解放（フルスクリーン爆発）**！
   - エピローグのオチで日常の 16:9 へ戻る。
2. **完全な3D Z軸アクションと正確な向き（ムーンウォーク撲滅）**:
   - 奥から手前への巨大化ダイブ、手前から奥のビルへの立体キリモミ吹っ飛び、鍔迫り合いの3Dオービット旋回、高度連動の立体床シャドウ。
   - 素材の左右向き（RU 80=左, RU 81=右, YJ_rush=左など）と移動方向ベクトルを論理的に完全一致させ、後ずさりムーンウォークを徹底排除。
3. **快適なラウドネス（EBU R128 準拠）**:
   - -16.0 LUFS / True Peak -1.5 dBTP で耳に刺さる高域・過大低音をカットし、突発的な音割れをゼロ化。
