# バトルクッキー☆「野獣先輩を倒しに行くRU姉貴」（bb6、2026-11-01）

## 狙い（1文）
台詞をすべて淫夢とクッキー☆の語録にして、語録をそのまま格ゲーの超必殺技のような技名として画面いっぱいにカットイン表示し、戦いの間は 33/分の速い割り、とどめの前だけ無音とピアノで完全に止める。

## 振り切る軸
1. **語録の技名カットイン化**: 「ホラホラ百裂拳」「暴れんな斬り」「第二形態」「最終奥義 イキスギ」「奥義 ケツ相撲」など、全編で技名演出を画面いっぱいに打ち出す。
2. **高速カット（戦闘）と極端な引き算（真顔）のコントラスト**: バトルパートは 28〜33 カット/分の速いテンポで割り、屋上の無音登場（30%地点）とUDKが倒れる場面（54〜70秒）はピアノのみの長回し（8秒以上切らない）で徹底的に音と動きを抜く。

## 物語と構成
- **登場人物**: RU姉貴（霊夢・主人公）、UDK姉貴（魔理沙・相棒）、MUR（門番・閣下化）、KMR（門番・逃走）、野獣先輩（ラスボス）。
- **変化**: 街の崩壊 → 門番突破 → 屋上での対峙 → 激しい肉弾戦 → 相棒の犠牲による絶望・静寂 → 覚醒と決着。
- **伏線とオチ（二段オチ）**:
  - 冒頭でRUが何気なく口にする「必殺技は何ですか？うーん…ケツ相撲かな？」を、クライマックス（76秒）で「奥義 ケツ相撲」として回収し、野獣を爆破・星にする。
  - 決着後、UDKは「気絶していただけでした」で安心させた直後、這い戻った野獣が「お前のことが好きだったんだよ！(迫真)」と突然告白してRUに蹴り飛ばされる二段オチ。

## 緩急計画
- **題字・下北沢（0〜14s）**: 低密度。2人の軽い会話、行進曲。
- **門番戦（14〜29s）**: 中密度。技名カットイン、MUR変身・吹っ飛び、KMR逃走。
- **屋上の登場（29〜41s）**: **引き算**。無音、背中を向けた野獣の佇まい。
- **ラスボス戦（41〜58s）**: 高密度。BGM高速化（168 BPM）、激しいラッシュ・斬撃のぶつかり合い、爆発。
- **真顔・静寂（58〜74s）**: **極小（引き算）**。BGM停止、ピアノ独奏、倒れたUDKと涙を流すRUの長回し。
- **とどめ（74〜88s）**: **最高密度（後半の山）**。覚醒、全音上がったBGM、「奥義 ケツ相撲」、吹っ飛び・爆発・星。
- **決着・告白（88〜100s）**: 間を置いた告白オチ、蹴り。
