# 音MADの音楽の作り方（桔梗☆・柴又系クッキー☆）

2本の音MADの音を作って所有者から受けた指摘と、測って分かったことを工程順にまとめる。映像は [video-making.md](video-making.md)。

- 桔梗☆（11-08〜09）: 界隈曲「桔梗」（Speder2）を初代クッキー☆と淫夢の素材でカバー。配布 MIDI（耳コピ）を土台にした。所有者「素晴らしい」で投稿（sm47024472）。
- 柴又系クッキー☆（11-15）: 柴又（2号兄貴）の型で新しく書いた曲を、クッソー☆3期の「お菓子の材料屋さん」の台詞とレ淫棒の音色で鳴らす。第7版まで直した。

共通の工程は [how-to-make.md](how-to-make.md)（ENU☆）、全パートを素材で鳴らすカバーは [material-cover.md](material-cover.md)。ここはそれに足すことを書く。守る基準は [rules.md](rules.md)、声のシンセの中身は [techniques/voice-instrument.md](techniques/voice-instrument.md)。数値はこの2本で測った値で、決まりではない。

## 1. 手本を測ってから決める

- カバーは配布 MIDI の区間（どのトラックが鳴っているか）を表にして、それを構成の骨にする。桔梗は 132 BPM・128 小節で、ドラムだけ → ベース → A → サビ1 → 間 → サビ2 → 終わり。
- オリジナル曲は、参考の配布 MIDI（柴又・金町・vecolite）からキック・ベース・刻み・和音・主題の作りを数値で取る。柴又は 192 BPM、キック 16分の 0・6・10、スネア 4・12、裏拍ベース 2・6・10・14、飴切りは 16分を全部埋めて2つ目だけ遅らせる。
- 先駆者の動画があれば、配役・コメントの山・帯域を測り、**同じにしないこと**を先に書き出す（桔梗☆の先駆者は遠野が主役。こちらは野獣先輩にした）。
- 原曲の音源も同じ物差しで測る: LUFS、左右相関、波高率、7帯域（60〜250／250〜1k／1k〜2.5k／2.5k〜5k／5k〜8k／8k〜12k／12k〜16k Hz）、20 秒ごとの音量の流れ。

## 2. ループを数本作って選んでもらう

全体を作る前に、サビの8小節を作り方違いで3〜5本作り、所有者に選んでもらう（[rules.md](rules.md)）。2本とも「台詞を頭に」の型が選ばれた。

| 型 | 作り |
|---|---|
| 台詞が主旋律 | 2小節ごとの頭に台詞を語りの速さで置き、残りの旋律の音へ語尾を連打 |
| ロイドが主旋律 | ロイドが替え歌。合いの手に台詞（桔梗☆では「替え歌にしなくていい」と言われた） |
| シンセが主旋律 | 声のシンセが旋律。台詞は2小節の頭と刻み |
| 柴又型 | リード（声のシンセ）が旋律。声は合いの手と決め台詞だけ |

- ループごとに配置表（小節.16分: 台詞（音高））を書いて渡すと、所有者が直す所を言いやすい。
- 測る: 声の立ち上がりと16分の格子のずれ、語尾の音高のずれ、声の割合。

## 3. 曲の型を借りても、旋律とベースは借りない（オリジナル曲）

- 柴又の型（長い音2つ＋16分2連の連なり＋終わりの駆け上がり、根音を頭で伸ばすベース）をそのまま使ったら、所有者に「柴又に似すぎている」と言われた。借りてよいのはテンポ・キックの並び・裏拍ベース・刻みの役まで。
- 主題は題材の見立てから別の運びを作る。京都の題材では、都節（レ・ミ♭・ソ・ラ・シ♭）だけの七五調の数え歌（8分で7つ言って伸ばし、次の小節で5つ言って伸ばす）にし、伸ばしの後ろに箏の「コロリン」（16分で3音下りる）を挟んだ。和音はミ♮を避けて ♭II（E♭M7）を軸にした。
- ベースも自前のリフにする（頭で踏んで 16分でオクターブへ跳ねる、0・3・4・6）。
- **サビは平歌より明らかに上げる**。「全編、B メロ程度の盛り上がりが上限」と言われた。直し方:
  - 平行調へ開く進行（IV–V–iii–vi）
  - 平歌の音階から明るい音階へ替える（都節 → ヨナ抜き）
  - 平歌より1オクターブ高い所、3-3-2 の食い込むリズム
  - 2小節の合言葉を何度も繰り返し、2小節目で最高音へ跳んで伸ばす。7小節目で最高音を張り、8小節目は導音で頭へ戻す
- 構成は「イントロ → A → サビ → B → Cメロ → Dメロ → 一転攻勢 → 二転攻勢 → 終わり」まで広げた（168 小節・211 秒）。所有者「CメロやDメロ等の新しい展開も」。
- 楽器はレ淫棒（声の SF2）の音色だけで鳴らした。自前の SF2 の読み込みで、バンクとプログラムを選んで鳴らす（[docs/guide/external-soundfont.md](../guide/external-soundfont.md)）。鳴らして高さのずれを測り、セントで打ち消す。

## 4. 区間ごとに主役の声を替える

両方で効いた作り。区間ごとに表を作り、主役（台詞）・旋律の声・低音・裏拍・和音・刻みを誰の声で鳴らすか決める。所有者「パートごとに主役となる声は変えたほうがいい」。

- 桔梗☆: 前奏 RU → A HNS → サビ1 YMN → 間 UDK → 一転攻勢 野獣 → サビ2 MUR → NSDR → KMR → 最後のサビは3人。
- 柴又系: intro ICG・NYN → A1 ICG → A2 NYN → B SZ → Cメロ 美鈴・咲夜 → Dメロ 幽香 → 一転攻勢 淫夢 → 二転攻勢 RRM。
- 主役の声が薄いと「層が薄い」と言われる。本編の台詞だけで足りなければ、同じ人物の素材フォルダ（持ちネタの語録）から足して2小節ごとに置く。
- 歌っている人物以外の声で下回りを足すと豪華になる（桔梗☆: サブベース・左右のパッド・高い飾りを別の人物の伸ばしで）。所有者「下回りを支えるトラックや効果音は歌手以外にも採用で」。
- 楽器音より声を使う（所有者「できるだけ全部、楽器ではなくキャラの声を」）。ドラムも声のドラム（レ淫棒の声のドラムキット）にし、BGM から切ったキックは使わなかった。

## 5. 素材の縛りと筋

- 一転攻勢の前は初代クッキー☆だけ、後は淫夢だけ、のように**区間で素材を縛る**と、どこで世界が替わったか分かる（桔梗☆、所有者の指示）。ロイドやほかのシリーズの効果音も外した。
- 一転攻勢は最後の盛り上がりの位置に置く。所有者が位置を言えばそれに従う（桔梗☆は 1:42〜）。
- 筋は本編の1場面から取り、一転攻勢で淫夢の似た場面へ読み替える。
  - 桔梗☆: 初代のホワイトデー（「わたしも食べさせるぅ＾～」）→ 第四章（「アイスティーしかなかったけど良いかな？」）。食べさせる → 飲ませる。
  - 柴又系: 材料屋で ICG の注文に NYN が「ないです」→ 一転攻勢で GO「ビール買ってきて」に淫夢の各人が「〜ないです」。
- 視聴者が知っている前振りを入れる。「アリスのつくるブラウニはうまいな」の UDK 詠唱は一転攻勢の前振りとして知られているので、語りの速さ・元の高さのまま置き、伴奏を −7 dB・打楽器を −3.5 dB 下げ、刻みを止めた。
- 決め台詞の区間（NSDR「みんな踊れー！」「ダイナモ感覚」）は初登場の台詞を所有者に確かめる。
- 一転攻勢の後に、元の作品へ戻る「二転攻勢」を置く形もある（柴又系）。
- 一転攻勢の直前は決め台詞 → 2拍の無音。

## 6. 台詞の置き方（台詞を頭に・語尾を連打）

- 2小節（または4小節）ごとの頭に台詞を語りの速さで置き、残りの旋律の音へその台詞の語尾を連打する。台詞は8小節ごとに替える。
- 注文と返事のような掛け合いは「頭で注文、次の小節の頭（注文が長ければその後の8分）で返事、残りは返事の語尾」の1組にする。組の長さを 4小節 → 2小節 と詰めていくと畳みかけになる。
- 語尾は台詞の最後の有声の所（〜0.22 秒）を切り、旋律の音に合わせて WORLD で高さを付ける。オクターブは区間で1つに決める（1音ずつ折り返すと音型の頂点だけ落ちる）。
- 長い音の旋律は 8分ごとに打ち直す位置へ語尾を置くと、その人物の声で小節が埋まる。
- 叫びは他の台詞より 5〜7 dB 大きく、そのままだと「うるさい」と言われた。台詞ごとに下げる。
- 目立たせたい声（NSDR）は +4 dB 上げ、その区間の伴奏を −3 dB 下げる。1〜4 kHz で声が全体の −2 dB 前後になった（ほかの台詞は −10〜−13 dB）。
- 二転攻勢のように旋律の声を主役にする区間は、台詞を控えめにする（「こんなもの」3回だけ）。

### 拍への置き方

- 切り抜きの頭を声の鳴り始めにして拍に置くのが基本（[rules.md](rules.md)）。
- ただし鼻音（な）や摩擦で入りが長い声は、子音の頭を拍に置くと母音が遅れて聞こえた（「NYN の『な』が拍から微妙にずれている」）。**母音が立つ所（頭 0.3 秒の山の −8 dB）が拍の後ろ 30ms 以内**に来るよう前へ出した。直した後の語尾の母音の位置は拍の後ろ 中央 14ms・最大 32ms。
- 声の楽器（ベース・旋律のシンセ）も頭の空白を測る。音が山の 25% に届くまでが 135ms（RRM の声のベース）・59ms（パチュリー）あり、「ベースの拍がずれている」と言われた。全部 6ms 以内へ詰める。

## 7. 声のシンセ

詳しくは [techniques/voice-instrument.md](techniques/voice-instrument.md)。この2本で分かったこと:

- 素直な「あー」（KNN・RI・ICG）は伴奏に溶ける。YMN のような**癖のある声の母音**を使う。YMN の声は初代クッキー☆の SIK 役の台詞から選ぶ。
- 有名な語尾（「わたしも食べさせるぅ＾～」の「る～」）は旋律のシンセになる。切れ目は 10ms 刻みで高域の比を見て、前の音節の摩擦が終わる所から切る（1.82 秒で切ったら「べさせ」が入った）。
- かすれは PSOLA で悪化する（HNR 14.8 → 12.4 dB）。WORLD で響きと息に分け、音符ごとに目標の高さで組み立て直す（息 ×0.25、響きを5フレームならす、4.5 kHz より上を 8 dB 下げる）と HNR 約 16.7 dB に戻った。
- 平らな母音を探して伸ばす: 台詞の中で、有声が 97% 以上で高さのばらつきがいちばん小さい 0.24 秒を探し、WORLD で目標の高さ・長さに作る。
- **鳴らして測る**。入りで高さが揺れる音色（RRM「こ」）は短い音が半音〜全音高く測れたので、入り 85ms を飛ばして伸ばしの所から鳴らした。美鈴「ギャー」は 76 音中 17 音が 0.5 半音以上ずれたので、平らな母音の台詞へ替えた。
- 高さの読み取りの下限は声に合わせる。高い声（約 350 Hz）を男声用の下限 60 Hz で読んで2オクターブ下と読み違え、旋律を 48 半音下げていた。下限を 150 Hz にした。
- 声の SF2（レ淫棒）を鳴らすと、自分で WORLD のシンセを作るより楽なことがある（所有者「シンセはレ淫棒を使うほうが楽なことがある」）。
- **旋律は1本の声を元の高さに近い所で鳴らす**。叫びを再生速度で音程付けして歪ませた「音割れ許容」の旋律は、一度頼まれて作ったが撤回された。重ねすぎると「ごちゃごちゃして成立していない」と言われた。上のオクターブは薄く（0.25〜0.35）、和音に合わない固定の高さの刻み・弾く声のなぞり・アルペジオは外す。

## 8. 伴奏・効果音を足して豪華にする（桔梗☆）

所有者「もっと音作りを豪華に」。

- 区間の頭にドンッ（初代）／デデドン・銅鑼（淫夢。一転攻勢と最後のサビは銅鑼）。
- 区間の頭に掛け声（「え！？」「おーっ！」「ンアッー！」など）。
- 前の1小節に逆再生のシンバル、前の2拍に16分のおかず。一転攻勢の前は無音のため入れない。
- 旋律は左右に ±7 セントずらした複製を 12・18ms 遅らせて重ね、残響を足す。3 kHz より上を約 3 dB 上げる。
- 鐘のように高さを読めない音は、名前の音名を基音にする。

## 9. ミックス

- 区間ごとに LUFS を決めて持ち上げる。柴又の原曲は頭 −16.6 → 山 −10.6 LUFS。一転攻勢は前後より 4〜5 LU 上。
- パートごとに、鳴っている所の音量を区間ごとに目標へそろえる。区間で音色の人物が替わっても大きさが跳ばない。
- 左右の広がりは揺れる遅延（コーラス）で作る。読み出しの速さを変えて音高をずらす作りは、写しが曲の頭からの時間に比例してずれ（8 セントで 2:40 に ±0.74 秒）、エコーに聞こえた。
- 仕上げは全体を線形で目標の LUFS へ合わせ、−5 dB を超える山だけ tanh で丸める。丸める標本が 1% 前後なら潰れていない。
- 帯域は手本と比べる。ベースに使う声（YMN「うぇー」）は 250〜1k に響きが強いので、ローパスを 380 Hz まで下げた。
- 目安: 全体 −10.5〜−12.5 LUFS、ピーク −1 dB 前後。

## 10. 確かめる

- 耳で聴けないので、版ごとに測って書く:
  - 全体と区間ごとの LUFS、ピーク、左右相関、7帯域
  - 語尾の音高のずれ（中央と 0.5 半音以上の数、クッキー☆と淫夢を分けて）
  - 声の母音の位置の拍からのずれ、声の楽器の頭の空白
- 旋律は音名だけでなく、隣の音との差が楽譜と6半音以上ちがう所を数える（オクターブの折り返しの見落とし）。
- 指摘は時刻つきで来る（「0:40〜のベース」）。区間の表に時刻を書いておくと、どこを直すかすぐ分かる。
- 音だけ直したときは映像を描き直さず、音を差し替える。
- 渡すときは、変えたこと・測った値・確かめていないこと（耳で聴いていない）を分けて書く。

## よくある指摘と直し方

| 指摘 | 直し方 |
|---|---|
| 旋律・ベースが参考曲に似すぎ | 型（テンポ・キック・役）だけ借り、主題とベースは題材の見立てから書く |
| サビが盛り上がらない | 平行調へ開く、明るい音階、1オクターブ上、合言葉の繰り返しと最高音への跳躍 |
| その人物の層が薄い | 同じ人物の素材フォルダから持ちネタを足し、語尾で旋律を埋める |
| 「な」やベースが拍からずれる | 母音が立つ所を拍の 30ms 以内に、声の楽器は頭の空白を 6ms 以内に詰める |
| 声のシンセがかすれる | PSOLA をやめ、WORLD で響きと息に分けて組み直す |
| 声のシンセが誰の声か分からない | 素直な母音をやめ、YMN など癖のある声の母音にする |
| 旋律がごちゃごちゃ | 1本の声を元の高さ近くで。重ねは薄く、和音に合わない刻みを外す |
| 叫びがうるさい | 台詞ごとに 5〜7 dB 下げる |
| 左右の写しがエコーに聞こえる | 速さを変えた写しをやめ、揺れる遅延（コーラス）にする |
