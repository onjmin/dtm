# 歌詞の設計（界隈曲）

自動作曲が付ける仮歌詞を「くじ引きの単語の列」から「文になった歌詞」へ変えるための土台。
Web の考察と、所有者の耳コピ（UST）の**実測**を突き合わせて、規則として採れるものだけを並べる。

- 道具: `scripts/corpus/measure-lyrics.ts`（耳コピ側と生成側を同じ物差しで測る）
- 採用の基準は[自動作曲の引き継ぎ](handover-compose.md) §0 と同じ。**2曲以上**で出たものだけを規則にする。
  1曲だけの言い回しは、規則にも素材にもしない。
- **耳コピの歌詞そのものは git にもバンドルにも入れない**（[素材の出どころ台帳](dataset-provenance.md)）。
  この文書に載せるのは数と、文の形の名前だけ。

## 0. 何を測ったか

`Music/_own/自作/界隈曲` の UST 33ファイル。同じ曲の再保存とハモリは1つに畳み、
歌詞の違う層（裏歌詞）だけ別に数えて **16曲**。

| ことば | 意味 |
| :-- | :-- |
| 句 | 休符で切った一続き。息の単位 |
| 文 | 4分以上の休符で切った一続き。文の単位の代わり |
| モーラ | アプリの数え方（`normalizeLyrics`）。「きゃ」は1、「っ」「ん」「ー」は各1 |

注意: 文の切れ目は休符で代用しているので、長い文が途中で切れることがある。
下の「句末の形」で6割が「どれでもない」のは、その切れ目が混ざっているため。

## 3. 採らないもの（考察にあるが数で裏づかない）

- **「を」を「お」、「は」を「わ」と書く表音表記**。萌娘百科に慣習として書かれているが、
  実測では **11/16曲が「を」をそのまま書く**（中央値1回、最多16回）。一部の曲の癖で、ジャンルの規則ではない。
- **「〜てくる」で文を閉じる**。曲名には多いが、歌詞の文末では1/16曲しか出ない。**曲名の規則**として扱う。
- **伸ばしを多用する歌い回し**。1曲（りこりすめもりあ、8%）だけで、他は0%。

## 4. 流派（Web の考察と歌詞読みから）

1行ずつ読み解く本格的な考察はほとんど無く、萌娘百科・ニコニコ大百科に作風の慣習が短く書かれている程度。
歌詞を読んで共通点を取ると、書き方は3つに分かれる。**混ぜると「らしさ」が消える**ので、曲ごとにどれかを選ぶ。

| 流派 | 語り口 | 場面と異物 | 構成 |
| :-- | :-- | :-- | :-- |
| **A 報告型**（ころんば直系） | 子どもの作文のような「〜ました」「〜ので〜ました」。気持ちの語はほぼ無い | 公園・駅・階段・布団などの暮らしの景色に、海のものが方向違いで入る。語り手は驚かず生活の動作で受け流す。時間の線が切れる、体や感覚が欠けていく | 同じ報告文のかたまりを何周も繰り返し、2周目で悪化させる。裏の声が危険を予告する |
| **B 叙情型** | 文語・古い語をひらがなで書く。「もう戻れない」の類の決め句 | 夜が明けない町、神社、バス、雨傘、ラジオ。海や深い底は逃げ場、空は冷たい。生き物のすむ上下がひっくり返る | サビをそのまま3〜4回繰り返す |
| **C 内面・言葉遊び型** | 語呂合わせと韻、医学の用語。報告体のまま独白になるものもある | 死・病・壊れた人形・記憶の痛み | — |

- A: イワシ・ヤツメ穴・クラゲ・クロマグロ・次日朝夢・うれたリンゴ・さかながおよいだそうてんは など
- B: あさやけもゆうやけもないんだ・とべない深海魚・つちへとしずむカゲロウ・しずむゆうひをみていた・海鬼月
- C: ぺぽよの曲、とりぴよ3部作（ぺぽよの2曲は VOCALOID 曲で、界隈曲と明記した出典は見つからなかった）

3つに共通するのは、ひらがな表記・淡々とした語り手・まとまりの反復・隠し層（裏歌詞、行頭の縦読み、PV の暗号）。

出典: ニコニコ大百科「海鮮市場」「界隈曲」、萌娘百科「界隈曲」「ころんば」「海鮮」、
note の界隈曲まとめ2本、fukuyuru-note、謎歌詞.com、UtaTen のレビュー。
創始者が名前を出さないよう求めて活動をやめた経緯があり、界隈では作者名を出さないのが慣習。

## 5. 音と言葉の当て方（追加測定 2026-10-03）

歌詞が「歌える」かどうかは、どの音にどの母音が来るかで決まる。耳コピ 8015 音のうち
**4分以上の音符 1338 音**で、乗っている母音の比率が全体とずれる。

| 母音 | 全音符 | 4分以上 | 差 |
| :-- | --: | --: | --: |
| あ | 33% | **39%** | +6 |
| い | 21% | **25%** | +4 |
| う | 15% | 14% | -1 |
| え | 10% | **7%** | -3 |
| お | 16% | **13%** | -3 |
| ん | 3% | **1%** | -2 |

**規則として採れる**: 伸びる音には **あ・い** を置き、**え・お・ん** を避ける。
くじ引きだった頃の仮歌詞は、4分以上が あ25/い24/う24/え9/お18/ん0% で全体（あ26/い22/う21）と
**ずれなかった**——語を音符の長さと無関係に並べていたので、原理的にずれようがない。
今は候補を2本引いて、伸びる音に あ・い が来る側を採る（§12 の実測）。

## 6. 曲名と歌詞の関係（追加測定）

「曲名＝サビで歌う1文」という読みは、**半分の曲でしか成り立たない**。
曲名に3文字以上のかなの連がある10曲のうち、その連が歌詞に出るのは5曲（出現 1〜5回）。
漢字題（ヤツメ穴・拝啓・次日朝夢・±0）は測れない。

→ 曲名はフックの候補だが、「曲名の1文をサビで繰り返す」を規則にはできない。
採れるのは §2 の「曲名は生き物＋が＋〜てくる／〜てこない の1文」までで、歌詞側の規則ではない。

## 7. 反復する句と初出の句（追加測定）

セクションの区間は UST に無いので、**句の反復**で代わりに見る。
2回以上出る句（サビ候補）と1回だけの句（Aメロ候補）を16曲・830句で分けた。

| | 句の数 | モーラ 中央（p25/75） | 句末の形 |
| :-- | --: | :-- | :-- |
| 反復する句 | 334 | **5**（1/11） | どれでもない70% / 動詞(る・た)24% / 打ち消し4% / 報告体1% |
| 1回だけの句 | 496 | **9**（4/14） | どれでもない67% / 動詞(る・た)28% / 報告体3% / 打ち消し1% |

- **採れる規則**: 繰り返す側は**短く**（中央5対9）。サビは短い句の反復、初出は長い報告。
- **採れない**: 句末の形は反復側と初出側で**ほぼ同じ**。「サビだけ言い切りにする」のような書き分けは無い。
- 例外: とべない深海魚は逆（反復する句のほうが長い）。サビをまるごと繰り返す形。

## 8. 層の重なり方（追加測定）

歌詞の違う層を2つ以上持つ5曲で、主の層（音符が最多）との時間の重なりを測った。

| 曲 | 層の音符 | 主との重なり |
| :-- | :-- | :-- |
| さかながおよいだそうてんは | 466 / 218 | 43% |
| つちへとしずむカゲロウ | 692 / 193 / 195 / 200 | 89% / 89% / 24% |
| りこりすめもりあ | 582 / 304 / 91 / 99 | 84% / 44% / 40% |
| ±0 | 771 / 155 | 92% |
| とべない深海魚 | 485 / 294 | 82% |

- **重なる層は主より短い**（音符で 1/3〜2/3）。主の区間の 80% 以上に重なる層が4曲にある。
- ただしファイル名は `HARM` `Chorus_1/2` `sub` `MOT` で、**コーラス・ハモリが別の言葉を歌っている**形。
  イワシのような「表＝光景／裏＝予告」の裏歌詞そのものは、**手元の耳コピに入っていない**。
  2声を規則にするなら、原曲の調査（聴取か書き起こし）が別に必要。

## 9. 効かなかった物差し

- **2文字の連の多様性（異なり2連/総2連）**: 耳コピは中央 56%（29〜99%）、今の仮歌詞も中央 56%。
  **本物と区別しない**ので、語の使い回し（キャストの固定）の物差しには使えない。
  反復は句の単位で測る（§1 の「句の重複」「反復の単位」）。
- **「を」の表音表記**（§3）。
- **「〜てくる」の文末**（§3）。

## 10. 歌詞の層

歌詞を作る問題は1つではない。下の層ごとに、規則で作れるかどうかが違う。

| 層 | 中身 | 規則で作れるか | 今の状態 |
| :-- | :-- | :-- | :-- |
| ① 器 | 句ごとの音の数・句の割り方・息継ぎ | 作れる | できている |
| ② 表記 | ひらがなだけ・1音符1モーラ | 作れる | できている |
| ③ 音の当て方 | 伸びる音に あ・い、ん を置かない（§5） | 作れる | できている |
| ④ 文 | 文法の通った1文で言い切る | 作れる | できている |
| ⑤ キャスト | 1曲の登場物を固定して戻ってくる | 作れる（引いた語を曲で固定するだけ） | できている |
| ⑥ 筋 | 発見→接触→異変→悪化と進む。2周目で悪化させる | **規則では弱い** | できていない |
| ⑦ 声の層 | 表は光景、裏は予告。層ごとに別の歌詞 | 構造は作れる（中身は⑥次第） | できていない（原曲データも無い。§8） |

⑥は抽選では出ない（[抽選されないものが「らしさ」になる](handover-compose.md)のと同じ話）。

## 11. 仮歌詞に求める水準

**①②③④⑤までを規則で作り、⑥⑦は書かせる側（言語モデルか手書き）に回す。**

| 水準 | 作れるもの | 判断 |
| :-- | :-- | :-- |
| (i) 音数の器 | ①② | **今でも満たしている**。ここで止めるなら仮歌詞の改修は不要 |
| (ii) 読める文 | ①〜⑤ | **狙う**。ユーザーが語を差し替えれば直せる土台になる（くじ引きは全消しになる） |
| (iii) 筋のある歌詞 | ⑥⑦ | 規則では届かない。言語モデルに書かせ、規則で音数を検算する（§15） |

理由は、仮歌詞の役割が[編集の出発点](handover-compose.md)であること。
文になっていれば1語ずつ直せるが、語の羅列は消して書き直すしかない。
一方で筋は、規則を増やしても出ないうえ、当たり率が低い世界では評価が溜まらない。

## 12. 組み込んだあとの実測（2026-10-03）

`src/compose/compose-lyrics.ts`（文の型・キャスト・母音）と `composeLyrics` に入れ、
`--generate kaiwai --count 12 --seed 1` を同じ物差しで測った。

| 物差し | 耳コピ16曲 | くじ引き（前） | 文で組む（後） |
| :-- | --: | --: | --: |
| 伸ばし（2%以下の曲） | 0%（15/16） | 3%（4/12） | **0%（12/12）** |
| 句の重複 | 23% | 2% | **19%** |
| 反復の単位 | 4句 | 1句 | **4句** |
| 伸びる音の あ | 33→39% | 26→25% | **34→46%** |
| 伸びる音の ん | 3→1% | 0→0% | **3→1%** |
| 動詞の言い切りの文末 | 11/16曲・23% | 10/12曲・18% | **12/12曲・23%** |
| 報告体の文末 | 7/16曲・8% | 0/12曲・0% | **2/12曲・3%** |
| 名詞止め・切れ目 | 63% | 81% | **60%** |
| 主語の「は」 | 中央3回 | 中央3回 | 中央5回 |

**残っている差**:

- 伸びる音の あ が原曲より寄る（+12pt 対 +6pt）。候補を2本から増やすともっと極端になるので、
  2本で止めてある（8本で最良を採ると あ 53%・お 2% になった）。
- 「〜てくる・〜てきた」の文末が 6%（原曲は歌詞の文末では 1/16曲）。到来の動詞は界隈曲の核なので
  残した。原曲の 0% は、文の切れ目を休符で代用している測り方の影響もある（§0）。
- 反復する句と1回だけの句の長さの差（原曲 5対9）は出ない。句の長さは旋律の休符が決めるので、
  歌詞側では変えられない。

**UI の入口**: 「歌入り作曲」のほか、個別トラック設定の歌詞欄の「自動で作る」で、
**すでに置いてある音符**（読み込んだ曲も）へ歌詞を当てられる。和音のトラックは
1音符1文字に割り当てられないので非対応と出す（`isMonophonic`）。

**検算**: `scripts/test/check-compose-lyrics.ts`（`pnpm test` に入れた）。
1音符1文字（かつ1音節）・ひらがなだけ・伸ばし棒を置かない・読点は4小節の切れ目だけ・
文で終わる・伸びる音の母音が開く側へ寄る・登場物が3回以上戻る。

## 13. 評価の仕方

歌詞は**読めば判定できる**（音を鳴らす必要がない）ので、曲の評価より安く回せる。

- **単位は1曲ぶんの歌詞**。8小節や1行では差が出ない（[8小節の目隠しA/Bは鈍い](handover-compose.md)のと同じ）。
- 1回**5〜10曲**を並べ、**使う／捨てる**を付ける。捨てたものには理由のタグを1つ:
  **文が変／語が散る（キャストが固定されない）／話が進まない／音に乗らない／語彙が同じ**。
- タグの数が次に直す層を指す（文が変→④、語が散る→⑤、音に乗らない→③、話が進まない→⑥）。
- 本物と混ぜた目隠しはしない。固有名詞で当てられるので鈍い。追うのは**使う率**の変化。
- 自動の物差し（§1・§5 の数字）は**門**としてだけ使う。点数で曲を選ばない。
  門の案: 音数が合う／伸ばし 0%／ひらがな100%／句の重複 20〜40%／伸びる音の母音が あ・い 寄り。

## 14. 残っている問い

1. セクションの本当の区間との対応（§7 は句の反復で代用した）。同じ曲の MIDI の構成と突き合わせれば測れる。
2. 裏歌詞の原曲データ（§8）。手元に無いので、作るなら聴取か書き起こしから。
3. 語頭が強拍に来る率（①と③の間の層）。
4. 筋を言語モデルに書かせる経路の形。規則が器と句割りを出す → 言語モデルが筋とキャストを決めて埋める →
   規則が音数を検算して直させる、の3段が噛み合うかどうか。

## 15. AI に歌詞を書かせるとき

仮歌詞をそのまま渡すと、AI は文字数を気にせず意味の通る文を書くので音の数がずれる。
**句ごとのモーラ数を数字で渡し、数え方も書く**のが確実。

```
次のメロディに日本語の歌詞をつけてください。

ルール：
- 1行が1句。各行の「音の数」とぴったり同じ数のモーラにする
- 小さい「ゃゅょ」は前の文字と合わせて1つ（「きゃ」で1つ）
- 「っ」「ん」「ー」はそれぞれ1つと数える
- ひらがなだけで書く
- 「〜ました」の報告体で、気持ちの言葉は使わない
- 書き終えたら各行の数を数えて表にし、合わない行は直す

音の数：
1行目 12
2行目 13
（以下同様）

場面：公園のかいだんに、海のものがありえない方向から入ってくる
```

コツ:

- **最後に数えさせて直させる**。一度で合わせるより、表を作らせて合わない行だけ直させるほうが確実。
- **長い行は割る**。25モーラを1行で頼むより「12＋13」に分けると合いやすい。
- **足りない分は `ー` で埋める**（1音符を使う）。ただし原曲はほぼ使わないので、1〜2モーラまで。
- アプリ側は**1文字＝1音符**で読む。渡す前に `src/voice/lyrics.ts` の数え方と合っているか確かめる。

## 16. やらないこと

- 耳コピの歌詞・言い回しを、素材としてリポジトリやバンドルに入れる（[台帳](dataset-provenance.md)）。
- 1曲だけに出る言い回しを規則にする（[§0 の基準](handover-compose.md)）。
- UI の表に作者名を出す（文書の中で流派をたどるために書くのは既存の [kaiwai-lineages.md](kaiwai-lineages.md) と同じ扱い。§4 の慣習）。

## 17. 報告体の語り手（追加 2026-10-03）

§12 の報告体は、光景の文の動詞を「〜ました」にしただけだった。流派A（§4）の核は
**語り手自身が動くこと**と、**異変を「〜ので」で受けて暮らしの動作で受け流すこと**なので、
報告体の曲にだけ語り手の型を足した（`narrationShapesOf`）。

| 型 | 形 |
| :-- | :-- |
| 理由でつなぐ | 主語＋過去形＋「ので／から」＋語り手の動き |
| 移る | （時間）（場所＋へ・から）＋帰りました・行きました・逃げました… |
| とどまる | （時間）（場所＋で・に）＋待ちました・眠りました・隠れました… |
| 何かをする | （時間）＋〜を＋見ました・拾いました・数えました… |

- 主語は書かない（日記と同じく語り手は省く）。場所の助詞は動きに合わせる（「階段から眠りました」を作らない）。
- 報告体の曲では句の一部（§18 で 2 割）で語り手の型を先に試し、そのうち半分は「〜ので」の型を先頭に置く
  （長い句でしか組めないので、等分だと報告体の曲の半分に届かない）。
- 1曲だけの言い回し（特定の曲の理由と動作の組み合わせ）は語彙に入れていない。

実測（本文のどこに出るか。`measure-lyrics.ts` の「語りの形」）:

| 形 | 耳コピ16曲 | 生成40曲（後） |
| :-- | --: | --: |
| 〜ました（文中も含む） | 6/16曲・17回 | 15/40曲・423回 |
| 〜たので | 3/16曲・4回 | 7/40曲・32回 |
| 〜たから | 2/16曲・4回 | 17/40曲・58回（「からだ」を拾う。目安） |

- 報告体の曲の割合は合っている（耳コピ 6〜7/16、生成 15/40）。
- 「〜ので」は報告体の曲のおよそ半分に出る（耳コピ 3/6〜7、生成 7/15）。
- 報告体の曲の中の「〜ました」の密度は §18 で直した。
- 「〜てみました」（語り手が試す）は耳コピで0/16曲なので採らない。

## 18. 「〜ました」の密度（追加 2026-10-03）

§17 の時点で、報告体の曲は句のほぼ全部が「〜ました」で終わっていた。

**耳コピ側の数え直し**: UST だけで数えると報告体の曲は1000字あたり中央4（1〜7）だが、
ヤツメ穴の UST はマッシュアップ版で「〜ました」を含まない。歌詞テキストのある曲で数えると:

| 曲 | 「〜ました」/1000字 | 普通体の動詞（目安） |
| :-- | --: | :-- |
| ヤツメ穴 | 42 | 「〜ました」の約1.6倍 |
| unnamed_155 | 20 | 約2.8倍 |
| 海鬼月 | 12 | 約2倍 |
| とりぴよ3曲・次日朝夢 | 4〜5 | — |

最も報告体の強い曲でも、普通体の動詞のほうが多い。→ **報告体の曲でも光景の文は普通体で書き、
「〜ました」は主に語り手の型が受け持つ**。

変えたもの:

- 報告体の曲の光景の動詞は、8個のうち1個だけ「〜ました」、残りは普通体から引く（`REPORT_SCENE_VERBS`）。
- 語り手の型を先に試す句を 5 割から 2 割へ（`NARRATION_SHARE`）。

| 物差し（生成40曲） | 前（§17） | 後 |
| :-- | --: | --: |
| 「〜ました」/1000字（出る曲の中央・範囲） | 83（66〜99） | **31（18〜55）** |
| 報告体の曲 | 15/40 | 15/40 |
| 「〜たので」が出る曲 | 7/40 | 7/40 |

検算（`check-compose-lyrics.ts`）: 1曲ぶん（約300字）で、報告体の曲の密度の中央が 15〜45、
「〜ので／から」が半分以上、語り手の動きがほとんどの曲に出る。
